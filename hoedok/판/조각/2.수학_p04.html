수학 학습 이론

1. 스켐프

1) 도구적 이해

규칙이나 공식의 적용 방법은 알지만 이유·원리를 모름

2) 관계적 이해

규칙이나 공식의 적용 방법과 이유·원리를 알고 있음
⇒'이유·원리'뿐 아니라 방법도 알아야 함

2. 브루너

1) EIS 이론

행동적 표상(E) : 조작 활동·행동으로 표현
영상적 표상(I) : 그림·도식으로 표현
기호적 표상(S) : 문자·기호로 표현

3. 피아제

1) 인지 발달 이론

개념 : 학습 = 인지 구조(도식)의 변화
과정
동화 : 도식 변화 X, 자극을 도식에 맞춤
조절 : 도식 변화 O, 도식을 자극에 맞춤

2) 인지 발달 단계

감각운동기 (0~2세)
전조작기 (2~7세)
구체적 조작기 (7~12세) ⇒ 논리적 사고에 있어 구체물의 물리적 조작 필요
①논리-수학적 사고
②가역성의 원리 → 보존 개념 획득 ; 수, 양(특히 넓이 등적변형)의 보존
형식적 조작기 (12세~)

3) 추상화의 유형

경험적 추상화 : 물리적 속성에 대한 스키마
반영적 추상화 : 사람의 행동을 추상화 (논리-수학적 추상화)
의사-경험적 추상화 : 반영적 추상화와 같은 스키마 형성하되, 확인을 위해 구체물이 반드시 필요

4. 프로이덴탈

1) 현실적 수학 교육, 수학화

맥락적이고 학습자 내부에서 구성 수학 학습 이론
수학화 : 현상을 본질(수학적 수단)에 의해 조직
수평적 수학화 : 현실 상황을 수학적으로 표현 (현실 → 수학)
수직적 수학화 : 수학적 표현을 형식화·추상화 (수학 → 수학)
응용적 수학화 : 수학적으로 도출한 내용을 현실에 적용 (수학 → 현실)

2) 수학화 교수·학습의 원리

안내된 재발명 : 교사의 안내에 따라 수학적 내용 재발명
반성적 사고 : 수준 상승의 원동력
현실과 결부된 수학 : 세 수학화의 순환으로 수학-현실 연결

3) 국소적 조직화

성질 나열 후 정의 → 나머지 성질 증명 (≒ 반 힐레, 관계적 수준)

5. 베르트하이머

⇒이해 방법 (cf. 기계적 방법) → 생산적 사고 (→ 전체-부분에 대한 구조의 개선적 변화) → 아하 경험

6. 오수벨

⇒ 유의미 수용 학습 이론 지도 원리
점진적 분화 : 일반 → 구체 (하위적)
통합적 조정 : 기존 내용과 학습 내용의 통합 (병위·상위적)
선행 조직자
설명 조직자 : 상위 개념 제시 ; 점진적 분화 (하위적)
비교 조직자 : 동위 개념 제시 ; 통합적 조정 (병위적)

7. 교수학적 변환론

1) 교수학적 변환

학문 수학 → 학교 수학 변환

2) 극단적 교수학적 현상

개인화/배경화
강조 : 메타-인지 이동 : 교수학적 보조 수단(e.g. 교구)에 학생의 사고 집중
간과 : 형식적 고착 : 수학 지식의 형식만 연습
탈개인화/탈배경화
강조 : 토파즈식 외면치레 : 학생의 학습 환경 X (e.g. 과도한 힌트 제공)
간과 : 조르단식 외면치레 : 학생의 사소한 행동을 보고 학생 과대평가

8. 수학 학습에 대한 관점

1) 객관주의

불변의 진리 존재

2) 구성주의

개인이 의미 구성
수학 수업 원리
조작적 활동
반성적 사고
토론
급진적 구성주의 : 수학적 지식은 개인이 구성 ⇒ 비객관적
사회적 구성주의 : 수학적 지식은 사회적 합의 ⇒ (상대적으로) 객관적
과정 : 공표 → 비판 및 재구성 → 합의
