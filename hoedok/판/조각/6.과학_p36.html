과학 교수·학습 방법

1. 실험 수업

1)의의
새로운 사실 발견 ⇒ 탐구적 실험 (학생 중심)
이미 알려진 지식 증명 ⇒ 예시적 실험 (교사 중심)
2)유형
문제방법결과
확인 탐구제시제시제시
구조화된 탐구제시제시개방
안내된 탐구제시개방개방
자유 탐구개방개방개방
3)형태
확인 ≒ 예시적 실험
탐색 ≒ 탐구적 실험
귀납 : 사실 → 일반화
연역 : 일반 → 현상
기능 개발 : 실험 활동 기능
과정 개발 : 문제 해결 기능

2. 시범 실험

1)장·단점
장 : 실제적, 경제적, 안전
단 : 수동적, 깊이↓

1)활동

4. 융합인재교육 (STEAM)

Science, Technology, Engineering, Arts, Math
1)준거틀
상황 제시, 창의적 설계, 감성적 체험
