단원 개발 - 단원 개발 도구

성취기준에서 출발할 수도, 학생 요구·사회 쟁점·학교 행사·기념일에서 출발해 성취기준과 연결할 수도 — 8종(각 절차 1~4 + 예시)

성취기준 출발형

뜻 : 세 교과의 성취기준으로 단원을 개발 — 활동·내용·시수는 교사가 배정
절차 : 성취기준 확인 → 얼개 → 보완 → 실행하며 완성 · 특징 : 대체로 교사가 주도 · 통상적 접근 · 예시 「생태」 01-04 체험학습 18차시

학생 요구형

뜻 : 학생의 흥미나 관심을 반영 — 요구가 먼저, 성취기준 연결은 뒤
절차 : 요구 수용 → 함께 설계 → 선택 제공 실행 → 성찰 · 특징 : 대체로 학생이 주도 · 학생 맞춤형 · 학생은 수업 내용을 제안하는 역할 · 교사는 학생의 학습 과정, 결과를 성취기준과 연결함으로써 학습을 더 의미 있게 · 그래도 무엇을 배우고 싶은지 학생에게 묻는 것도 중요 · 예시 「친구」 K-W-L

학습 기능 숙달형

뜻 : 학습 기능(범교과 기능)을 중심으로 교과 수업을 아우름 (= 실로 꿴 모형)
절차 : 기능 찾기 → 출발점(학생과 루브릭) → 교과 수업 꿰기 → 평가 · 특징 : 고등 사고·사회적 기능·핵심 역량 가능 · 교과 학습 확산(≒ 전이) · 예시 쓰기 기능 · 진단 주간 2주

문제 해결형

뜻 : 학생이 겪고 있는 문제를 해결해 나가는 과정을 수업으로
절차 : 문제 찾기 → 계획 → 과제 수행 → 성찰 · 특징 : 문제 해결 능력 · 협업·창의성 등 역량 · 예시 쓰레기 문제 · 환경의 날 캠페인

학교행사형

뜻 : 학교 행사(의식·학예·보건 체육·수련·안전)와 성취기준 연결
절차 : 행사 확인 → 설계 → 참여 → 돌아보기 · 특징 : 학교 행사를 반영한 수업은 현실성이 높다 · 행사와 수업 동시 진행 · 예시 「열매 축제」

이벤트형

뜻 : 특별한 날(한글날 등)과 세 교과 성취기준을 연결하는 수업
절차 : 특별한 날 확인 → 학습 경험 정하기 → 경험 → 돌아보기(전경 = 한글날 · 배경 = 교과) · 특징 : 교과 내용을 특별한 날과 맥락화 · 학생은 삶과 앎을 통합 · 예시 한글날(가획 · 몸으로 자모음)

장소 기반형

뜻 : 학생이 직접 경험하는 생활 세계(장소)에서 시작해 성취기준과 연결 — 교실 안으로 들이거나 마을로 확장
절차 : 장소 찾기 → 이해 → 장소에서 학습 → 태도 돌아보기 · 특징 : 지역 친화적 · 교육 내용의 지역화 용이 · 소속감 · 예시 「학교 옆 공원」

프로젝트형

뜻 : 학생이 제안하는 최고조 활동(= 최종 목표)을 설정하고 그 과정에서 필요한 것을 배움
절차 : 제안 → 학습 계획(세부 과제 · 성취기준 연결) → 관찰·독려 → 돌아보기 · 특징 : 학생 주체성 강화 · 예시 「토마토 수확하기」
