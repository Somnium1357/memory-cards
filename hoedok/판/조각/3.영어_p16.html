평가

1. 평가의 요건

실용도 : 방식이 실행 가능
신뢰도 : 평가의 일관성
타당도 (Validity) : 평가의 목적 부합성
진정성 : 평가와 실제 과업의 일치도
환류 (washback) 효과 : 평가가 교수·학습에 미치는 영향

3. 수행 평가

2. 평가의 분류

목적
숙달도 : 전반적인 언어능력, 교육과정 무관
진단 : 강·약점 진단
배치 : 반 배치
성취도 : 교육과정 근거, 학습목표 성취 평가
시기
총괄 (summative) : 수업·학기 끝나고, 포괄적. ∴ 결과 중심
형성 (formative) : 평가와 교수·학습 구분X ∴ 과정 중심
방식
직접 : 목표 과업을 실제로 수행
간접 : 과업 자체가 아닌 관련 과업 수행
분리 : 한 기능의 한 요소만 떼어 측정
통합 : 여러 언어 능력 동시 평가 (e.g. cloze)
Dictation : 오디오 자료·교사 낭독 듣고 받아적기 (구멍 09-22)
Cloze : 텍스트에서 일정 간격 단어 삭제·특정 언어 항목 공란 → 알맞은 단어 보충 (구멍 09-22)
