읽기 - 과정 중심 읽기 지도

⇒읽기의 과정을 강조, 각 과정에서 필요한 기능·전략 지도
cf.결과 중심 읽기 지도 ⇒ 결과 강조
기능 : 무의식적 작용, 사실·추론·감상·창의·비판적 읽기
전략 : 의식적 작용, 전략 학습을 통해 기능으로 전이.
= 읽기 활동, 전·중·후로 나뉨

1. 읽기 전 활동 전략

1) 읽는 목적 설정하기

⇒목적에 따라 글의 종류, 읽는 방법 달라짐

2) 미리 보기

⇒제목·목차·머리말 등 미리 보고 배경지식 활성화

3) 연상하기

⇒글 안 읽고 내용 떠올리기, 배경지식 활성화

4) 예측하기(cf. 추론하기)

⇒책에서 읽게 될 내용 (책에 써있는) 추측하기 ↔ 책에 없는 내용 추론하기

배경지식, 내용정리

5)KWL(Know, Want, Learned)
⇒읽기 전체 과정에서 활용, H(How)를 읽기 후 활동에 더하기도
6)SQ3R(Survey, Question, Read, Recite, Review)
⇒훑어보고 → 질문 → 읽기 → 암송 → 다시 읽기

7) 설문 조사

⇒배경지식 활성화

2. 읽는 중 활동 전략

1) 구조 파악하기

⇒글의 구조 파악, 도해 조직자 사용

3) 추론하기(cf. 추론적 읽기 기능, 예측하기)

⇒글에 드러나지 않은 내용 추측하기 (cf. 예측하기)
스키마 + 맥락의 실마리 활용

4) 중심 내용 파악하기

⇒문단 중심 문장 → 글 중심 내용

5) 협의하기

⇒교사-학생 간 / 학생 상호 / 자기 협의 (능숙한 독자)

6) 메모하기

7) 점검하기

⇒초인지(상위인지)에서 나옴, 읽기 과정 통제·조절
교사 : 읽기 과정 점검 질문 촉진

2) 질문하기

⇒교사 질문 / 학생 질문 생성 전략

사고 수준에 따른 질문 유형

사실적 질문 : 글에 답이 O
추론적 질문 : 글에 드러나지 X
비판적 질문 : 판단·평가
감상적 질문 : 정의적

사고 유형에 따른 질문 유형

폐쇄적 질문
인지·기억적 질문 : 단순 재생
수렴적 사고 질문 : 분석
개방적 질문
확산적 사고 질문 : 다양한 생각 자유롭게
평가적 사고 질문 : 비판·판단
