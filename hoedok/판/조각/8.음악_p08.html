6/8박자

박자에 따른 서양 악곡의 계통
3박자 → (3/4박) ; 마디가 반으로 안 나뉨
2박자 → 2/4박, 4/4박, (6/8박) ; 마디가 반으로 쪼개짐
∴3/4박 / 6/8박 구분도 계통 따라
지휘
빠르게 연주 = 한음 길이 ↓ → 2박자처럼 지휘 (1박=♩.) · 강-약
느리게 연주 = 한음 길이 ↑ → 6박자처럼 지휘 (1박=♪) · 강-약-약-중강-약-약

당김음

셈여림 규칙이 깨진다 = 당김음
리듬에 의해 : 센박 길이 < 여린박 길이
붙임줄에 의해 : 여린박 선율 → 앞으로 선율이 당겨짐
악센트에 의해 : 악센트 명시
쉼표에 의해 : 센 박 자리에 쉼표

화음

화음 : 두 개 이상의 음이 동시에 울림
주요 3화음
1)으뜸화음 (Ⅰ): 으뜸음 (=음계의 첫음 = 이동도법 도) 위에 3, 5음
2)버금딸림 (Ⅳ): 근음 (=음계의 4번째 음 = 이동도법 파) 위에 3, 5음
3)딸림 (Ⅴ): 근음 (=음계의 5번째 음 = 이동도법 솔) 위에 3, 5음
Ⅰ도미솔
Ⅳ파라도
Ⅴ솔시레
화음 문제 풀이 순서
1.이동 도법으로 계이름 변환
2.어울리는 화음 찾기 (음계 수 애매하다 → 강박 음 기준)
3.오선지에 그려보기 → 고정도법으로 연주 (화음의 자리바꿈 유의). 조표 주의
옥타브 달라도 화음 가능 (도미솔, 미솔도, 솔도미…)
