## 언어 습득 이론

### 모국어 습득 이론

- 행동주의 (→ ALM 연결)
	- 자극(stimulus) → 반응(response) → 강화(reinforcement), 수정
		- (위 전체를 묶어) 습관 형성의 과정 (habit) = 조건화 (conditioning)
	- → 언어습득의 창조성 설명 불가 (조건화되지 않은 구문은 어떻게 응용해서 쓰나?)
	- 환경이 인간 형성
- 생득주의 (→ NA 연결), Chomsky(Universal Grammar)
	- 인간은 LAD(Language Acquisition Device)를 가지고 태어남, 언어의 UG 학습
	- 인간이 환경을 처리
- 구성주의 / 기능주의
	- 맥락 강조
	- 구성주의 : 지식은 학습자 안에서 구성된다 ⇒ 학습자 중심
		- Piaget, Vygotsky
	- 기능주의 : 언어는 form이 아니라 function을 위한 것 ; 맥락 중요

### 제2언어습득이론

#### five hypotheses (Krashen) ≒ input hypotheses

- Acquisition – Learning hypotheses
	- Acquisition : 무의식적 (subconscious) / 직관적 (intuitive) / 의미 (meaning)
	- Learning : 의식적 (conscious) / 명시적 (explicit) / 형태 (form)
	- Acquire된 언어만이 의사소통시 사용
		- Learned가 Acquired로 전환 X. (no-interface position)
		- ∴ 문법 지도 필요 없음(zero option)
- Input hypotheses
	- comprehensible input
	- 습득의 과정 : 이미 습득한 i → 이해 가능한 입력 i+1 을 습득
		- 교사의 역할 (realia, picture, context …  + c.i. 제공)
	- 발화 X 침묵기(silent period) 존재 ⇒ 발화 강요 X
- Monitor hypotheses
	- 학습된 언어 ⇒ Monitor로만(→ Learned 언어 쓸모없음) 사용됨
		- W,R 상황같이 처리 시간 있을 때만
- Affective filter
	- c.i.를 받아도 습득으로 이어지기 전 A.f. 통과 ; 동기, 자신감, 불안감 등이 영향
		- 교사의 교실 분위기 조성 필요
- Natural order hypotheses
	- 언어 규칙 습득의 순서는 자연적으로 결정되어 있음
	- → 교사가 명시적으로 i+2 단계의 언어 규칙을 지도할 수 없음

#### Noticing hypotheses

- input ≠ intake
	- input : 입력 일반
	- intake : 학습자가 언어 규칙을 notice한 입력

#### Output hypotheses

- input : 의미만 처리 (semantic processing)
- output : 통사 구조 처리 (syntactic processing)
- ∴ 통사 학습을 위해 output 필요
- output이 안 나오면 pushed output 사용

#### interaction hypotheses

- 학습은 상호작용의 과정이다 ≒ 사회적 상호작용, 의미 협상
- 의미 협상
	- L2 학습자의 상호작용에서 나타나는 특징적 현상
	- 상호작용을 통해 interlanguage의 의미 불일치 해소 (발화자 – 청취자 간)
	- 의미 협상 전략 : 3C
		- 많이 일어나도록
			- comprehension : 발화 → 청취 (이해하고 있어?)
			- confirmation : 청취 → 발화 (이게 맞아?)
			- clarification : 청취 → 발화 (다시 말해줘)
	- input 측면 : modified input (≒ c.i.) 형성  ( i+2 → i+1 )
	- output 측면 : f.b. 제공. modified output 형성

#### Sociocultural Theory (Vygotsky)

- 혼자서도 할 수 있는 영역(i)과 혼자 할 수 없는 영역(i+2) 사이에 "도움을 받으면 할 수 있는"(→ ZPD (zone of proximal development)) 영역(i+1)이 있다
	- 어떻게? 비계 (scaffolding)
	- ∴ 사회적 상호작용 (social interaction) 중요

### DM (Direct Method) ↔ GTM

- → GTM 반대로
	- L2, L/S, grammar X, 오류 수정 X. fluency…

### ALM (Audio Lingual Method)

- 행동주의 기반 : stimulation → response → reinforcement 통해서 habit 형성. form 중시(pattern 학습)
	- 반복적인 (Drill) (반복 중요) ; dialogue 사용 ~ ALM에서
	- accuracy 강조 (습관 고치기 힘듦)
	- 즉각적인 강화·오류 수정 (reinforcement)
- 교수요목 : 구조 중심 (복잡성 기반)
- Drill 기법 中 1 → 최소 대립쌍 연습 (minimal pair drill)
	- 발음기호 갯수 같은데
	- 오직 하나만 다르고
	- 다른 하나의 위치가 같은 쌍
- 실제 언어 상황에서 사용 X

### TPR (Total Physical Response)

- 생득주의 기반
- 학생들은 언어가 아니라 행동으로 입력 ⇒ 교사도 행동으로 입력 제시 ; imperative 사용
- form < meaning
- 구어 능숙도 (oral proficiency) 지도가 목적
- 오류 수정 X
- 정의적 요인 고려
- + pros
	- 교사 : 행동으로 명료하게 전달, 즉각적인 평가
	- 학생 : 동기유발, 흥미, 발달단계, 우뇌발달, 불안감↓
- - cons
	- 말로 해야 할 내용은 어떻게?

### CLT (Communicative Language Teaching)

- 의사소통 중심 교수법의 umbrella term
- → "의사소통 능력" (Communicative Competence) 지도
	- 문법(grammatical) 능력 : 문법적으로 올바른 문장 이해, 표현, 문법성 판단
	- 담화(discourse) 능력 : 응집성(cohesive) 있고 통일성(coherent) 있는 담화에 대한 지식
	- 사회언어(socio lingual)적 능력 : 맥락에 맞는 적절한 언어를 사용하는 능력
	- 전략(strategic) 능력 : 의미를 전달하기에 언어 자원이 부족한 때 의미를 전달하는 방법에 대한 지식
- 학습이론 : 의사소통 중심, Task-based, fluency…
- 교수목표 : 개념,기능 → 기능 중심 교수요목
	- 기능: 언어가 성취하고자 하는 목적
	- 형태 1:1 대응 X. (기능 - 다형태, vice versa)
- 교사 역할 : 촉진자 (facilitator)
- 학생 : communicator
- + pros
	- 실제 언어 상황
	- 자주적 학습자
	- 의사소통
- − cons
	- 학습자 기대와 배우는게 다름
	- EFL → 시간 부족, 교사 역량 부족

### TBLT (: Task-Based Language Teaching)

- 과업 중심의 교수법
	- 과업: 언어 학습이 아닌 실제 목적을 가지는 활동
	- Real-world Task / Pedagogical Task(우리가 다루는거)
		- Nunan
			- Real-world : 실생활 연관 O
			- Pedagogical : 실생활 X, 교육 목적으로 인지적
		- Pica
			- Jigsaw (= 양방향 정보차)
			- Information-gap (= 단방향 정보차)
			- Problem-solving (단일 결론, 정답 O)
			- Decision-making (단일 결론, 정답 X)
			- Opinion exchange (다중 결론)
	- Pre → Task → Post
		- Pre : 예시, 설명
		- Task : task(실행) → planning → report
		- Post : language focus → Accuracy
	- + pros
		- 학습자가 자기 말
		- 능동적 → 동기유발
	- − cons
		- 어려움

### WLA (Whole Language Approach)

- 언어는 총체적 ; 분해·환원 X ↔ phonics
	- top-down ↔ bottom-up
- ∴ Authentic한 자료(학생이 작성한 글) 사용, 네 가지 언어 기능 integration 강조
- + pros
	- 실제적
	- 삶과 연결
	- 모든 기능
- − cons
	- 기호도 모르는 학생?

### 이해

#### 듣기 - 읽기 공통 내용

##### 이해 처리 과정

- Bottom-Up : 상향식 이해 처리. 언어 기반 decoding 중심. form 위주. schema 사용 X
- Top-down : 하향식 이해 처리. 전체적 이해 중심. meaning 위주. schema 사용
- Interactive : 상·하향 모두 사용

##### 과정 중심 지도

- 전(Pre) - 어휘 지도(상향식) / 배경지식 활성화(하향식) / 동기 부여, 목적 안내
- 중(While) - 이해에 도움을 주는 활동 (과다한 듣·읽기 X) ⇒ 읽기 shared reading
- 후(Post) - 이해 확인 / 상향식 언어 지도 / 기능 통합

#### 듣기 지도의 특성

##### 교실 듣기의 유형

- Reactive, Responsive, Selective, Intensive, Extensive, Interactive
	- 이름 그대로

#### 읽기 지도의 특성

##### 읽기 단계

- Literal comprehension → Interpretive → Critical → Creative
	- (문자 그대로 내용 파악)   /   (추론·행간의 의미)   /   (비판적)   /   (감상·감정)

##### 읽기 유형

- Intensive - 한 부분에 집중적 → 문법·구문구조 분석 등 (⊂ 수능 영어)
- Extensive - 전체적인 이해 → 주로 흥미로 (⊂ 다독가)
- Reading aloud - 실제성↓ (실제로 소리내지 못함), 학생들 주의가 발음으로 감
- Silent reading - 어려움. 실제적

##### 읽기 전략

- Skimming - 요지 파악. 전체적. 특정 부분 X. (요약)
- Scanning - 특정 내용 찾기. 부분적. 목표 O. (사전)
- Guessing/Inferencing - from context
- Semantic Mapping - Graphic 자료
- Think Aloud - 교사가 ※(↔ 나머지 전략은 학생이 주체 — 2026-08-20 동하 확인)

#### 음철법, 일견 어휘. (Phonics & Sight-Word)

##### 음철법 (Phonics)

- 철자와 소리 관계 지도를 목적으로 함 ⇒ 상향식 언어 지도
	- 자음이 일대일 대응 명확하므로 자음부터
		- 발음(=음절) 단위 지도
- 음절 = 어두자음군 + 각운 (= onset + rhyme)
- 음소 → 단어 → 어구 → 문장 순 지도
- 사용 자료 - Decodable text → Phonics 지도의 사용. 철자 패턴/소리-철자 관계 통제 (bat, cat, hat…)
	- Predictable text → 해당 구문 반복. phonics X (ALM drill 생각)
	- Trade-book text → Phonics 동기 부여

##### 일견 어휘 (Sight-Word)

- Decoding X, 한눈에 알아보도록 지도
	- how? flash card 사용. Look-and-say

### 표현

#### 말하기

##### 특성

- 정보 공백, 상호작용 필요 (= 정보차)

##### 연습 단계

	- O : 정보차가 있는가?

##### PPP (Presentation - Practice - Production)

- ⇒ ALM에 대한 보완. TBLT는 유창성 → 정확성, 순서 다름
- Presentation
	- Dialogue 사용해서 문맥화. 새롭게 배울 표현 제시
- Practice
	- Controlled Practice : Accuracy 중심. 제창, 대치 연습 등
	- Guided Practice : Fluency 중심 + Accuracy. ≒ Communicative Practice. (정보차)
- Production
	- 자유 발화, 의사소통에 문제 없는 오류는 정정 X. 의미 표현

##### Interlanguage

- L2 학습자가 형성한 언어
	- backsliding : U-shaped learning
	- Fossilization : 학습자 내부에 굳어진 오류

##### 말하기 오류 지도

- 유형
	- 의사소통이 주는 영향
		- Global : 의사소통 방해
		- Local : 의사소통 지장 X
	- 원인
		- Interference : 언어 간 오류, 간섭
		- developmental : 언어 내 오류, overgeneralization
- 오류 처리 유형
	- Input-providing
		- Explicit correction : 명시적으로 수정
		- Recast : 교사가 올바른 표현으로 재발화
	- Output-prompting
		- Metalinguistic feedback : 문법 지식 제공
		- Repetition : 억양 다르게 반복
		- Clarification request : 명료화 요구
		- Elicitation : 중단, 질문 등을 통해 유도

## 요소별 언어 지도

## 평가

### 평가의 요건

- 실용도 : 방식이 실행 가능
- 신뢰도 : 평가의 일관성
- 타당도 (Validity) : 평가의 목적 부합성
- 진정성 : 평가와 실제 과업의 일치도
- 환류 (washback) 효과 : 평가가 교수·학습에 미치는 영향

### 평가의 분류

- 목적
	- 숙달도 : 전반적인 언어능력, 교육과정 무관
	- 진단 : 강·약점 진단
	- 배치 : 반 배치
	- 성취도 : 교육과정 근거, 학습목표 성취 평가
- 시기
	- 총괄 (summative) : 수업·학기 끝나고, 포괄적. ∴ 결과 중심
	- 형성 (formative) : 평가와 교수·학습 구분X ∴ 과정 중심
- 방식
	- 직접
	- 간접
	- 분리
	- 통합

### 수행 평가

- 학습자 → 학습 과제 직접 수행 / 평가자 → 수행 과정/결과 관찰
- 주체
	- 관찰 평가 (교사)
	- 자기 평가
	- 상호 평가
- 수단
	- 인터뷰
	- 포트폴리오
