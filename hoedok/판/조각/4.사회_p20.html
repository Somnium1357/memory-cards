5-2 각론은 영역 특성상 (역사) 나중에

1. 통일, 민주화, 산업화 (내용 조직 다름 - 단원 특성)

1) 1공 - 이승만 (48'~60')

통일 : X (6·25 전쟁기)
민주화 : 발췌 (직선제) → 사사오입 (중임제한 X) → 진보당 (56' 선거가 원인, 조봉암X) → 3·15 → 4·19
산업화 : 원조 경제, 삼백 산업 (면방직·제당·제분)

2) 2공 - 허정, 장면 (60'~61')

민주화 : 의원 내각제·양원제

3) 3, 4공 - 박정희 (61'~79')

통일 : 7·4 남북공동성명 - 남북조절위원회
민주화 : 5차(직선·단원) → 6차(3선) → 7차(유신, 긴급조치, 간선-통주국) → YH무역(신민당사) → YS 제명 → 부마항쟁 → 10·26
산업화 : 정부주도 5개년, 경공업(의류) → 중화학(포철) 공업, 사회간접자본(경부고속), 파독·파월

4) 5공 - 전두환 (79'~88')

통일 : 최초 이산가족 상봉
민주화 : 5·18 → 8차 (7년 단임, 간선-국보위)(→ 80') → 박종철 고문치사(→ 87') → 호헌조치 → 6월항쟁 → 6·29 민주화 선언 → 9차 (현행, 직선·5년단임)
산업화 : 3저 호황, 전자 산업 발전

5) 6공 - 노태우 ~ 이재명 (88'~)

통일 : 남북 기본 합의서 (노태우), 6·15 남북공동선언 (평양, 최초 정상회담, DJ), 4·27 판문점 선언 (3차 정상회담, 문)
산업화 : 첨단 산업, 한류

2. 민주주의와 시민 참여

1) [6사 08-01] - 민주주의, 선거

민주주의
의미 : 정치 체제(협의), 생활 양식(광의, 듀이 - 도덕과)
발전 : 직접 → 대의 +α : 참여(지방자치), 숙의(무작위로 추출된 소규모 공중)
원리 : 국민 주권, 권력 분립, 입헌주의
선거
투표와 선거 : 투표는 의사결정 방식, 선거는 대표자 선출 (주민투표, 숙의가 앞의 반례)
원칙
비밀 : 비밀 보장 (↔ 공개)
보통 : 누구나 투표 (↔ 제한)
평등 : 1인 1표 (↔ 차등)
직접 : 자기가 직접 (↔ 간접)
