읽기 - 사실적 읽기

1. 글의 중심 내용 확인하기

1) 용어 정리

화제 : 소재, 제재
문단의 중심 생각 (= 중심 내용)
글의 중심 내용 : 문단별 중심 생각의 요약 (≠ 중심 생각)
글의 중심 생각 : 주제

2) 각론

반드시 지문에 함께 드러나는 것은 X
설명문 중심내용 ⇒ (대체로) 제목에 화제, 대상의 특징 설명하는 문장이 중심 내용

2. 글의 중심 생각 파악하기, 내용 요약하기

1) 학습 독서

⇒학습을 목적으로 한 독서
전략
⇒밑줄 긋기, 메모하기, 개념망 그리기, 구조적 노트하기(→ 도해 조직자), 중요도 평정, KWL, 학습 일지

2) 요약

삭제 : 예시 등 중요도 낮은 정보 삭제
선택 : 중요한 내용 선택
대체 : 하위어 → 상위어 대체
구성 : 중심내용 X ~ 재구성

3) 중심 생각 찾기

⇒핵심어 → 중심 문장 → 중심 생각
