화음

화음 : 두 개 이상의 음이 동시에 울림
주요 3화음
1)으뜸화음 (Ⅰ) : 근음 (=음계의 첫음 = 이동도법 도) 위에 3, 5음
2)버금딸림 (Ⅳ) : 근음 (=음계의 4번째 음 = 이동도법 파) 위에 3, 5음
3)딸림 (Ⅴ) : 근음 (=음계의 5번째 음 = 이동도법 솔) 위에 3, 5음
Ⅰ도미솔
Ⅳ파라도
Ⅴ솔시레
화음 문제 풀이 순서
1.이동 도법으로 계이름 변환
2.어울리는 화음 찾기 (음계 수 애매하다 → 강박 음 기준)
3.오선지에 그려보기 → 고정도법으로 연주 (화음의 자리바꿈 유의). 조표 주의
옥타브 달라도 화음 가능 (도미솔, 미솔도, 솔도미…)

단조

단조/장조 구별⇒첫,마지막 음이 도미솔 / 라
장음계 : 3~4, 7~8 반음
단음계 : 2~3, 5~6 반음
자연 : 변경 X
화성 : 7음 반음↑
가락 : 6,7음 반음↑, 내려올 때는 자연
나란한조 : 다장조↔가단조 / 사장조↔마단조 / 바장조↔라단조 ⇒ 장조 으뜸음에서 3도 내림
단조의 주요 3화음 : Ⅰ(라도미), Ⅳ(레파라), Ⅴ(미솔시, 화성단음계인 경우 미솔♯시)
단조 판단 (실전) ; 다장조는 특히 의심
①일단 장조로 생각, 조표 기반으로 조 판단·이동도법 계이름
②첫음이 라 → 단조니 나란한조의 단조
③7음에 ♯? → 자연 / 화성 판단
④화음 판단 (여기서부터는 장조랑 같음)
