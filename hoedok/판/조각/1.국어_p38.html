문학 - 서정문학

1. 시

1) 개괄

개념 : 함축적·운율성 언어
구성
형식적 요소 : 행(줄), 연(의미 단위 ; 시적 대상과 화자의 태도·정서 변화에 따라 바뀜), 시어(시에 사용된 단어) (→ 운율, 함축, 회화성)
내용적 요소 : 소재(작품의 내용적 재료), 제재(중심 소재), 주제(중심 생각)
표현적 요소

2) 시의 내용

시적 화자 : 말하는 주체 (허구적 대리인, 시인 X)
정서 : 감정·생각
태도 : 마음가짐·대응
→ 반드시 일치 X
어조 : 말투 (by 종결어미)
시적 대상 : 화자가 주목하는 대상
시적 상황 : 화자의 상황
심상
⇒시어의 이미지
단일 감각적 심상
시각 : 색채·모양·동작·상태 (색모동상)
후각, 청각, 촉각, 미각
공감각적 심상 ⇒ 한 감각이 다른 감각으로 옮겨 감 ; 순서 판단 시 반드시 평서문화
(ex. 푸른 종소리 → 종소리가 푸르다 → 청각에서 시각)

3) 시의 형식

운율
개념 : 운 + 율격 ; 말의 리듬
형성
운(같은 위치의 소리 반복) - 음위율
두운(행 시작)
각운(행 끝)
율격(음성적 요소 반복)
음수율 : 글자 수(= 음절 수) 반복
음보율 : 음보(= 끊어 읽는 단위) 반복
시어의 반복
문장 구조의 반복
음성 상징어 : 의성어 + 의태어
시상 전개
시간적
순행적
역순행적
수미상관 : 첫·마지막 부분 유사 ⇒ 운율, 형태적 안정감(균제미). 강조
