## 도덕 수업 모형

### 역할놀이 수업 모형 (과정·기능)

- 실제 연습·사회 연습
- 단계
	- 준비
	- 선정
		- 너무 모범 답안 말하는 학생 X (다른 학생 학습 기회 X)
	- 무대
	- 참여적 관찰자로서 청중
		- 무관심 X(참여적), 과한 간섭 X(관찰자) ; 집중해서 듣고 이해, 주장·생각 등을 느끼고 생각·평가·판단
	- 시연
	- 토론 및 평가
		- 서로 견해 주고받으며 생각 명료·내면화
	- 재연
		- 다른 각도에서 다시 ; 역할놀이 특징적 단계
	- 공유·일반화
		- 역할놀이 → 자유 표현, 극본X / 역할극 → 정해진 표현, 극본O

### 개념 분석 수업 모형 (지식·이해)

- 도덕적 개념(=가치·덕목)의 이해가 부족 → 판단·행동으로 연결 ; 소크라테스의 산파법이 원형
- 단계
	- 가치 개념의 확인
	- 개념 명료화·깊은 이해
		- 전형적인 사례와 반례 탐구
		- 경계 사례 확인
		- 관련 개념 분석
	- 가상 사태 적용
		- 내면화
	- 수용 여부 검토 및 정리
		- 일상적 사용에 맞는지 검토 (ex. '용기')

### 가치 명료화 수업 모형 (지식·이해)

- 자신의 가치에 대한 명료한 인식이 부족 → 가치화 과정 중시
	- 개인적 가치에만 집중, 판단 기준 X
		- 가치 상대주의 우려
	- 가치화 과정
		- 선택 - 자유/여러 대안/결과를 생각하고
		- 존중 - 소중히 하기/공언하기
		- 행동 - 선택을 행동으로 나타내기/습관화하기

### 가치 분석 수업 모형 (지식·이해)

- 명료화에 대한 보완
	- 개인적 가치, 판단 기준 X
	- 합리적 가치 판단, 사실적(=경험적) 증거·가치 원리 정당화(→ 판단의 합리성에 초점)
- 단계
	- 문제 사태 제시
	- 가치 문제 확인·명료화
		- 용어·진술 모호성 해결
	- 입장 설정·사실적 타당성 탐색
		- 가치 선택·사실 문제 해결
	- 잠정적 가치 결정·가치 원리의 검사
		- 잠정적 가치의 정당화 by 가치 원리의 보편화 가능성 검사
		- 가치 원리의 보편화 가능성 검사
			- 새 사례 검사 : 다른 사례에 적용
			- 포섭 검사 : 일반적(상위) 도덕 원리 검토
			- 역할 교환 검사 : 심각한 영향 받는 사람·집단
			- 보편적 결과 검사 : 모두가 그렇게 행동한다면?
	- 입장 수정·의사 결정
	- 실천 동기 강화·일상 적용

### 가치 갈등 해결 수업 모형 (지식·이해)

- (정당한) 두 가치의 갈등 상황(→ 사실, 정의, 가치 문제에서 비롯됨)의 해소 → 재판관과 비슷한 역할, 법리적 모형과 연결
- 단계
	- 문제 제시
	- 규범 확인 및 의미 파악
		- 명료화(정의 문제)
	- 문제 상황 성격 분석
		- 사실 문제
	- 입장 선택·정당화
		- 가치 문제
	- 입장 수정·대안 숙고

### 합리적 의사 결정 수업 모형 (지식·이해, 과정·기능)

- 지식·가치 → 능력·품성 함양
- 규범 타당성 파악 : 연역 / 귀납

### 집단 탐구 수업 모형 (지식·이해→탐구/가치·태도→정착)

### 도덕적 토론 수업 모형

- 콜버그 이론 기준, 도덕적 딜레마에 대한 토론
- 단계
	- 도덕적 문제 사태의 제시
		- 가상적·학급이 직면한 문제 + 가치 갈등이 드러나는 문제
	- 도덕적 토론의 도입
		- 도덕적 문제 부각하기
		- "왜" 질문하기
		- 상황을 복잡하게 만들기 : 복잡성·인지적 갈등↑ / 도덕적 딜레마 회피 방지
	- 도덕적 토론의 심화
		- 도덕적 사고, 판단력 증진
			- 심층적 질문
			- 인접 단계의 논의 강조
			- 명료화·요약
			- 역할 채택 강조
	- 실천 동기 강화·생활에의 확대 적용 ※교재 p216 보강 2026-08-21(노트에 4단계가 빠져 있었다)

### 도덕 이야기 수업 모형

- 내러티브 접근법(=학생 중심의 도덕 이야기하기) ↔ 전통적 도덕 이야기
- 단계
	- 학습 문제 인식·동기 유발
	- 도덕 이야기 제시·주요 내용 파악
		- 좋은 이야기 제시, 문답(폐쇄형 질문) 사용
	- 도덕 이야기 탐구·자신의 도덕 경험 공유
		- 개방적 질문 사용, 자기 연관성↑, 내면화
	- 자신의 도덕 이야기·유사한 상상의 이야기 구성
		- 저자 의식, 도덕적 권위↑
	- 정리·확대 적용, 실천 생활화

### 경험 학습 수업 모형

## 도덕 교육의 관점

### 도덕 사회화론

- 뒤르켐
- 사회
	- 종교 → 성스러움 → 금기 → 의무 → 규율 정신
	- 도덕      →      사랑 → 바람직 → 집단에 대한 애착
		- 표현 : 사회적 이해에 따른 동의 필요(신이 도덕의 근거 X) → 자율성(자기입법 X)
- 도덕은 사회규범 ; 정의상 권위가 필요, 침해되면 사회의 반응으로서 처벌(체벌X, 보상X)
	- 체벌 → 물리력
	- 보상 → 손익
	- 규범의 권위 치환
	- 사회규범으로서의 도덕을 지키는 행동을 하는 성향 = 도덕성
- 지도
	- 모범적 사례(e.g. 문학작품)
	- 과정(추론, 판단)보다 결과(규범의 내면화에 따른 행동 → 위 "성향 = 도덕성"으로 화살표)

### 도덕성 발달론

- 피아제
	- 상호
		- 행동을 통한 규칙 합의 → 준수
		- 자율성
	- 일방
		- 일방적 권위(→ 처벌이 회복하고자 하는 것)에 의한 규칙 준수
		- 타율성
- 콜버그
	- 전기 → 내용 <<<< 형식
	- 후기 → 내용 < 형식 (정의로운 공동체 접근)

## 도덕 교육의 이론적 기초

### 도덕 심리학

#### 프로이트

- ⇒ 도덕적 인간 : 사회 규범을 내면화·실천
	- 인간 : 비합리적 충동으로 움직임
	- 도덕 : 사회의 행위 규범
	- 사회 규범을 내면화하는 성향 = 도덕성
- 이드 → 자아(ego) ⇐ 초자아
- 현실
- 초자아
	- 양심 : 금지 ← 규범 내면화
	- 자아 이상 : 지향 ← 대상 동일시

#### 행동주의

- ⇒ 도덕적 인간 : 행위 규범 내면화
	- 인간 : 비합리적 힘(외력)에 의해 움직임
	- 도덕 : 행위 규범
- 행동 학습 = S-R-R
- 사회 학습 이론
	- 강화 이론 + 개인
	- 학습 = 관찰
		- 대상 : 모델
			- 모방 : 행동 답습
			- 동일시 : 내면적 가치 수용
	- 강화
		- 직접 : 외부 → 학습자
			- 강화이론 ※(스키너류)
		- 사회학습이론 ※원문대조 정정 2026-08-21(교재 p201 — 직접 강화는 관찰학습의 필수 구성요소가 아니다)
			- 간접 : 외부 → 모델 ※(= 대리 강화)

#### 인지 발달론

##### 피아제

- 타율적 도덕성(도덕 사실주의 → 도덕 규칙 = 사물, 불변)
	- 자기중심적 도덕 단계 : 도덕 규칙의 실재성
	- 권위주의적 도덕 단계 : 도덕 규칙의 외부성
- 자율적 도덕성(도덕 규칙 = 상대적, 가변)
	- 상호성 : 협동과 합의로서의 도덕 규칙 이해(법적·인습적 규칙)
	- 공정 : 연민과 공감에 따른 개인적 도덕 규칙(공감적·특수적 규칙)

##### 콜버그

###### 개괄

- 이론적 배경
	- 합리주의 전통 : 내면의 도덕성 끌어내기 → 소크라테스식 문답법, 칸트적 도덕 판단 지향
- 특징
	- 질적 차이 : 똑같은 딜레마에 단계별로 다른 반응
	- 불변적 계열·연속성
	- 구조적 전체 : 모든 상황에 같은 단계
	- 위계적 통합체 : 각 단계가 그 이하 단계를 포괄
	- 문화적 보편성
- 방법론
	- 도덕적 딜레마 제시 → 응답 분석
		- 응답: Y/N 아니라 도덕적 논거에 관심 ⇒ 토론을 통해 인지적 갈등 유발, 도덕적 변화 (= 도덕적 토론 수업 모형)

###### 단계

- 인습 이전
	- 처벌과 복종 정향 : 처벌 피하기 / 권위 복종
	- 도구적 상대주의 정향 : 이익=선 / 인간관계를 교환 관계로 인식
- 인습
	- 착한 아이 정향 : 타인(친구·가족·교사)을 기쁘게·승인
	- 사회 유지 정향 : 사회질서 유지, 법을 무조건적으로 따름
- 인습 이후
	- 사회 계약적 정향 : 법을 정당한 사회계약의 산물로서 준수 (사회계약 ⇒ 구성원들의 합의) ; 바뀔 수 있음
	- 보편적·윤리적 정향 : 윤리적 원리, 보편적 가치에 따라 행동 → 법은 이에 부합하면 따름

###### 비판

- 인지주의 문제 ; 행동과 판단의 불일치
- 케어 윤리 입장 비판 : 남성 중심적 ; 여성적 윤리 다름

- 행위는 선을 목적으로 한다
	- 최고선이자 궁극적 목적 = 행복(eudaimon)
- 덕 = 목적을 위한 기능의 탁월성
	- 인간의 행복에 필요
- 인간의 정신 = 이성(→ 인간의 특성) + 비이성
- 정신
	- 이성 (지적인 덕, 교육)
		- 인식 → 절대적 지식
		- 사량 → 가변적, 실천지(판단의 덕) ⇒ 이해, 판단으로 획득
	- 비이성
		- 욕구(이성에 귀를 기울임) → 도덕적 덕, 중용 ⇒ 습관을 통해 획득
		- 비이성 → 순수 욕구(영양생식 등)

#### 칸트 (자율적 도덕인)

- 의무의 윤리
- 실천이성의 자기입법 → 도덕 법칙(정언 명령)(→ 객관) → 선의지에 따른 법칙 준수(→ 주관) → 행동
	- 정언 명령
		- 보편성 정식 – 보편적 원리
		- 인간성 정식 – 수단X, 목적
- 연령에 따른 도덕교육
	- 양육 : 자연적 성장
	- 훈육 : 야성 → 인간성(강제, 타율) ⇒ 습관화
	- 도야 : 인간의 소질·자질 개발(자발, 내적)
	- 도덕화

#### 듀이 (민주적 인격인)

- 학교 = 작은 민주주의 공동체
- 학교에서의 경험 → 도덕적 성장 → 민주적 인격인 → 민주주의(정치체제 X, 도덕적 생활 양식) 실현
	- 사회 : 사회적 정신
	- 심리 : 교육적 경험

#### 프랑케나 (의무 윤리와 덕 윤리의 상보적 추구)

- 품성 없는 원리는 무력, 원리 없는 품성은 맹목
	- 품성 : MEY
	- 원리 : MEX

#### 피터스

- 타율·인습적 도덕(전통·습관의 뜰, 도덕 사회화론)
	- 도덕교육의 역설(자율을 목표로 하지만 습관에 의존)
- 자율·합리적 도덕(이성의 궁전, 도덕성 발달론)

### 동양 윤리학

#### 공자

- 인 (사람에 대한 사랑)
	- 예 : 인의 형식(규범)
		- 극기복례 (사욕(기)를 극하고, 예로 돌아감)
			- 소인 : 극기 실패
			- 군자 : 극기 성공 ⇒ 수기(나의 수양) → 치인(타인의 교화)
	- 효제 : 인의 근원
	- 충서 : 인의 실천

#### 맹자

- 천 (=선을 향하니 선함)
- 성선 (사람 안에 천이 있으니 성도 선함)
- 불인인지심 (성선의 증거)
- 사단과 사덕
	- 측은 → 인(사랑)
	- 수오 → 의(정의)
	- 사양 → 예(예의)
	- 시비 → 지(지혜)
- 사단을 갖춰 사덕을 완성
	- 수양 (내적)
		- 호연지기, 과욕
		- 인의의 실현
			- 상지 : 뜻을 고상하게 – 마음 보존
			- 지지 : 본성을 유지 – 본성 함양
	- 정치 (외부)
		- 왕도 : 덕을 통한 정치
		- 교육 > 선정 : 본성 회복을 위한 교육이 최우선

#### 순자

- 성악설 : 정에 의한 욕망이 무한하므로 성은 악하다
- ∴ 예를 학하여, 기를 통해, 화성한다
- 굽은 나무 비유
	- 성 : 굽으려는 성질, 위 : 곧으려는 습성, 예 = 곧은 형상이 된 나무가 스스로 만들어낸 곧은 틀(→ 성인)
	- 굽으려는 나무를(→ 악한 성), 예라는 틀을 대어(→ 예의 학·적) 곧으려는 습성을 세워(→ 기위) 곧게 자라게 하지만(→ 화성), 틀을 떼면 다시 굽어 자란다(→ 성은 여전히 악함)

## 도덕과의 기능

- 교과 통합 : 여러 교과의 단편적 도덕·인성 교육 내용 통합
- 가치 통합 : 개인적 가치가 기준·원리에 따라 건전하게 조직
- 사회 통합 : 사회적, 사회구성원들이 공유하는 규범·가치 형성

## 도덕과 교수·학습 방법

### 도덕과 학습 지도의 원리

- 정합성의 원리
	- 목표·내용·방법의 논리·실제적 일관성
- 인지화의 원리 → 지식·이해
- 심정화의 원리 → 가치·태도
- 행동화의 원리 → 과정·기능
- 통합성의 원리 → 통합
- 지적·도덕적 발달 단계 고려의 원리
	- 피터스, `도덕 교육의 역설' → 습관과 전통의 뜰을 지나 이성의 궁전으로
- 자율적 탐구 학습의 원리 → 학습자 능동성
- 주체적 자각화와 개별화의 원리 → 학습자 개별성
- 구체성과 현실성의 원리
- 능동적 참여와 토론 학습의 원리
- 반복과 계속성의 원리
- 집단 활동의 원리
- 학교·가정·지역 사회와 연계한 지도의 원리

### 도덕과 학습 지도의 방법 (설명 → 타이틀 인출)

- 직접적 가치 전수 방법 ⇒ 교과 중심(→ 사회화론)
	- 강의, (전통적인)도덕 이야기, 에듀테크, 모델 제시(→ 사회학습이론), 독서
- 간접적 가치 탐구 방법 ⇒ 학생 중심(→ 도덕성 발달론)
	- 토론·토의, 문답, 역할놀이, 집단 탐구, 글쓰기
- 실천·체험을 통한 가치 학습
	- 실습·실연, 현장학습, 덕목 실천 학습, 집단 수련, 참여적 실천 체험
