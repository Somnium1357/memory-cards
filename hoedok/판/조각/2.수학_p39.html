자료와 가능성

1. 통계의 기초

1) 통계의 과정 (5단계, 4단계 ⇒ 교육과정은 4단계 기준이지만 5단계로 생각한 뒤 매칭)

목적 확인 (→ 주제 정하기)
↓
자료 수집 (→ 자료 수집하기)
수치형 : 관측값이 수로 표현 ; 이산, 연속
범주형 : 범주 또는 항목으로 표현 ; 순위형(순서 O), 명목형(순서 X)
↓
분류 및 정리 (→ 자료 정리하기)
분류 : 일정한 기준에 따라 분할
정리 : 표, 그래프로 표현, 평균 등 대푯값 산출
↓
해석 (→ 결과 해석) : 객관적・공정하게 자료 해석 (의견 X)
↓
판단 (→ 결과 해석) : 해석 바탕 예상・예측・판단 (의견 O)

2) 각론

분류
성취기준 : 자신이 정한 기준 / 정해진 기준으로 분류
성적고 : 분명하지 않은 기준으로 분류하기가 어려움
↳이유 : 분류하는 사람마다 분류 결과가 다름
결과 수로 세어보기 → 비교 쉬움
표・그래프로 표현, 해석하기
주제 정하기
↓
자료 수집하기 ⇒ 조사하려는 내용에 방법이 알맞은지 생각
↓
자료 정리하기
표 : 수로 정리
장점 : 전체 수, 자료별 수 알아보기 편리
단점 : 한눈에 알아보기 어려움 → 그래프 필요
유의점
합계 확인
중복・누락 없이 세는 법 지도
그래프 : 시각적으로 정리
장점 : 한눈에 알아보고 비교
유의점
기호는 한 칸에 하나씩
빈칸 없이 순서대로 표시
기호의 크기와 빈도를 나타내는 수 무관

2. 여러 가지 그래프

1) 비교 그래프 : 양의 크기 비교

그림그래프
그리는 법 : 그림과 단위 결정 ; 자료 크기 클 경우 그림 가짓수↑ ⇒ 그림 개수 줄어 편리
특징 : 그림의 종류와 개수로 수량 비교
유의점 : 비비례 모델 사용 ⇒ 그림의 개수 많다고 수량 큰 것은 아님을 지도
막대그래프
그리는 법
눈금 한 칸의 크기를 적절하게 선택 + 눈금 수 결정 ⇒ 수량 차이 표현 위해 세로 눈금 한 칸 크기↓, 물결선 사용
양의 크기를 막대의 길이(폭 X)로 표현
특징 : 수량 비교 편리

2) 경과 그래프 : 양의 변화 표현

꺾은선 그래프
그리는 법
눈금 한 칸의 크기를 적절하게 선택 + 눈금 수 결정 ⇒ 변화 표현 위해 눈금 한 칸 크기↓, 물결선 사용
가로축에는 시간의 변화 나타내는 양을 표시 (⇒ 시간에 따른 변화 표현 그래프)
특징
선의 기울어진 정도로 변화 정도 파악
중간값 추측・미래 예측 가능
유의점 : 물결선이 최솟값 아래에 (선 가로지르면 기울기 왜곡)
