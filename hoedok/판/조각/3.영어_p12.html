기능별 언어지도 - 표현

1. 말하기

1. 특성

정보 공백, 상호작용 필요 (= 정보차)

2. 연습 단계

이해가 필요한가?
X : Mechanical Practice : 완전 통제, 단일 정답
O : 정보차가 있는가?
X : Guided Practice : 중간 통제 (내용상), 다양한 정답
O : Communicative Practice : 낮은 통제 (구조상)

3. PPP (Presentation - Practice - Production)

⇒ALM에 대한 보완. TBLT는 유창성 → 정확성, 순서 다름
1)Presentation
Dialogue 사용해서 문맥화. 새롭게 배울 표현 제시
2)Practice
Controlled Practice : Accuracy 중심. 제창, 대치 연습 등
Guided Practice : Fluency 중심 + Accuracy. ≒ Communicative Practice. (정보차)
3)Production
자유 발화, 의사소통에 문제 없는 오류는 정정 X. 의미 표현

4. Interlanguage

: L2 학습자가 형성한 언어
backsliding : U-shaped learning
Fossilization : 학습자 내부에 굳어진 오류
