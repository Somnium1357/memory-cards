## 조형 요소와 원리

### 조형 요소

- 점
	- 면적이 좀 있어도 점임 (↔ 기하학)
- 선
	- 직선 : 속도감, 긴장감
	- 곡선 : 유연성, 부드러움
- 면
- 형과 형태
	- 형 : 2d 이미지의 모양
	- 형태 : 3d 이미지의 모양
- 색
- 질감
	- 촉각적 : 만져지는거 ⇒ 표면에서 느껴지는 느낌
	- 시각적 : 보이는거
- 양감 : 부피감, 무게감. 평면도 가능

#### 색

##### 색의 속성

- 모두 가지면 유채색, 명도만 가지면 무채색
	- 색상 : 색의 독특한 성질
	- 명도 : 밝고 어두운 정도
	- 채도 : 맑고 탁한 정도

##### 10색상환

- 빨,노,파에서 시작, 서로 섞어서 기본색 5개(빨,노,초,파,보) 만들고 이웃한 색끼리 섞어서 10색
- 반대색(보색) : 빨강 ↔ 청록

![[도식_9.미술_10색상환.svg]]

##### 오방색

- 황색(황제)
	- ↑ 흑색(현무,겨울)
	- ↓ 적색(주작,여름)
	- ← 백색(백호,가을)
	- → 청색(청룡,봄)
- 음양오행의 원리 (적·청이 양, 흑·백이 음)

##### 색의 성질

- 주목성 : 한 색이 눈에 잘 띄는 정도 ⇒ 따뜻한 색, 명도·채도가 높을수록 높아짐
- 명시성 : 두 색이 대비되어 눈에 잘 보이는(=선명한) 정도 ⇒ 색상,명도,채도 차이 비례

##### 색의 대비

- 색상 대비 ⇒ 보색 잔상(배경색의 보색이 잔상으로 남는 현상)에 의해 생김
- 명도 대비 ⇒ 배경색의 명도가 낮을수록 명도가 높아 보임
- 채도 대비 ⇒ 배경색의 채도가 낮을수록 채도가 높아 보임(무채색 → 채도 매우 낮음)
- 보색 대비
- 면적 대비

##### 색의 혼합

- 가산 혼합 ⇒ 섞을수록 명도↑, 빛의 혼합 ; RGB(W) 기반
- 감산 혼합 ⇒ 섞을수록 명도↓, 물감의 혼합 ; CMY(K) 기반
- 중간 혼합 ⇒ 병치 혼합(점묘법), 회전 혼합(색팽이)

##### 대표작

- 인상파(모네) ⇒ 빛의 변화에 따른 색의 변화 표현. 혼색X, 원색을 나란히 칠해서 표현
- 신인상파(쇠라) ⇒ 인상주의의 발전·심화, 밝고 생생한 화면을 병치 혼합으로 표현, 혼색X
- 야수파(마티스) ⇒ 물체의 고유색 부정, 색채로 감정 표현

### 조형 원리

- 비례 : 크기 관계
- 율동 : 반복에서 오는 리듬감
- 동세 : 운동감
- 강조 : 선, 형, 색 강하게
- 반복
- 통일 : 형·색의 동일성 ⇒ 단조로우면 X ; 통일 속의 변화
- 변화 : 형·색·크기 변화 ⇒ 무질서 X ; 〃
- 균형
	- 대칭 : 좌우 대칭
	- 비대칭 : 좌우 다르지만 균형함
		- ex) 모빌
- 대비 : 상반되는 특징
- 대칭 : 선대칭
- 점증(gradation) : 점차 변화
- 조화 : 어울림

## 평면 표현

### 소묘

#### 종류

- 크로키 : 빠르게 그리는 그림
- 정밀 묘사 : 자세히 묘사 (양감↓)
- 데생 : 양감↑, 비교적 자세히

#### 재료

- 정착액 권장
	- 연필 : H(Hard), B(Black)
	- 콩테 : 중간 단단
- 정착액 필수
	- 목탄 : 무름, 잘 번짐 (+파스텔)

### 수채화

#### 성질, 재료, 용구

- 성질 - 사용법 간단, 건조 빠름 ⇒ 학교 수업에 적합
- 재료, 용구 : 유의점 — 물감을 미리 말려서 굳힘, 비슷한 색이 이웃하게, 붓 끝이 위로 가게, 혼색 시 채도↓

#### 투명/불투명 수채화

- 투명 : 물의 양으로 명도 조절, 경쾌 표현, 맑음. 밝은색 → 어두운색
- 불투명 : 흰·검으로 명도 조절, 질감 효과, 무거움, 순서 무관 · 과슈

#### 물감

- 아크릴 물감 : 접착성↑, 건조 속도↑, 물의 양에 따라 수채화/유화, 선명함. 도자기·유리 팔레트
- 포스터 물감 : 불투명 수채화

### 관찰 표현

- ※ 관찰 표현(풍경화, 인물화, 정물화)
	- → 시각적 사고 함양
- 방법 : 부분 확대, 절단, 규칙, 여러 방향, 질감

#### 풍경화

- 특징 ⇒ 원근감, 계절감
- 원근법
	- 서양
		- 투시 원근법(선 원근법) : 가까우면 크게, 멀면 작게
			- 앙시, 중심, 조감
				- 1점 투시 : 소실점 1개 (대각 구도, 집중감)
					- 물체의 외곽선을 연장한 직선들이 만나는 점
				- 2점 투시 : 소실점 2개 (웅장함)
		- 공기 원근법(색채 원근법) : 가까우면 진하고 선명, 멀면 연하고 탁하게
		- 중첩 : 겹쳐서 원근 표현, 거리에 따른 크기 변화 X
	- 동양
		- 삼원법(이동 투시법)
			- 고원법 - 아래에서 올려다보는, 세로선, 높이 (∴ 앙시)
			- 평원법 - 같은 높이에서 바라보는, 가로선, 넓이 (∴ 중심)
			- 심원법 - 위에서 내려다보는, 깊이 (∴ 조감)
- 구도 : 대각(집중), 수직(엄숙,높이), 수평(안정,너비), 호선(움직임)
- 단계 : 구도 → 스케치 → 채색 → 색채 원근

#### 인물화

- 표현 요소 : 비례, 균형, 동세
- 종류 : 자화상, 초상화, 캐리커처
	- 익살, 유머, 풍자 (= 만화)
- 동서양 — 동양 : 형상을 통해 정신까지 표현 ↔ 서양 : 과학적, 사실적 표현
- 대표작
	- 모나리자(다빈치) ⇒ 스푸마토 기법 ; 경계를 흐릿하게
	- 도라 마르의 초상(피카소) ⇒ 입체파 → 다시점

#### 정물화

- 시점 : 정물이 잘 드러나는 시점 선택
- 구도
	- 변화 → 단조로운 구도, 정중앙, 2등분 X
	- 통일 → 나열, 복잡, 산만 X
	- 균형 → 치우친 구도 X
	- 삼각형(안정,통일), 원형(통일), 마름모(변화,균형,통일), 역삼각형(긴장,불안)
- 명암
	- 양감 표현
	- cf) 질감 ⇒ 재료 선택 (펜 → 날카롭고 딱딱, 나머지 → 부드러움)
- 대표작 : 과일 정물(세잔) ⇒ 다양한 시점, 현대미술의 시작

#### 찰흙

	- 백자 : 처음부터 흰색 고령토

## 전통 미술

### 전통 회화

#### 특징과 종류

- 특징 : 정신적 측면 강조, 여백
- 종류
	- 수묵화 : 먹의 농담, 번지는 효과 중시 (담→중→농묵)(→ 얇은 한지)
	- 수묵 담채화 : 수묵화 + 옅은 채색
	- 채색화 : 색이 주가 됨 ⇒ 진하게, 여러 번 덧칠 (→ 두꺼운 한지)
		- 한지의 특성: 얇고 먹물이 잘 스며듦

#### 민화

- 주로 채색화, 주술적 의미(소망·염원), 소박·익살
- ex) 호작도, 책거리·책가도

#### 용구, 용필법

- 용구
	- 종이 : 한지 - 매끈한 면
	- 붓 : 수묵화 → 선, 붓털 긺 / 채색화 → 색칠, 붓털 짧음
	- 물감 : 한국화 전용
	- 문진·연적 : 누르개, 물담는곳
- 용법
	- 직필법 : 수직, 중봉
	- 측필법 : 기울여서, 편봉

#### 표현법

- 전통 회화
	- 구륵법 → 윤곽선, 색칠
	- 몰골법 → 윤곽선 X
	- 백묘법 → 먹선 농담·굵기
	- 삼묵법 → 한 붓에 삼묵, 채색 가능
		- 전체 담묵, 중간 중묵, 붓끝 농묵
	- 발묵법 → 먹 튀기기
	- 적묵법 → 쌓아 그리기
	- 파묵법 → 농묵으로 담묵 깨기
	- 운염법 → 엷게 펴서, 구름·안개
	- 갈필법 → 물기↓, 거칠고 메마른 느낌
- 풍경 표현
	- 미점준 → 쌀알같이, 수목 표현
	- 수직준 → 내리긋기, 높이
	- 부벽준 → 도끼자국, 산·바위
	- 절대준 → ㄱ,ㄴ,ㄷ / 바위산
	- 피마준 → 같은 방향·구불구불, 흙산
	- 하엽준 → 연잎 줄기

### 서예

#### 자세

- 완법 (팔의 자세)
	- 현완법 - 큰 글자, 팔꿈치 들고
	- 제완법 - 중간 크기의 글자, 팔꿈치 살짝 대고
	- 침완법 - 작은 크기의 글자, 손목을 다른 손으로 받침
- 집필법
	- 쌍구법 - 큰,중간 글자 , 엄지,검지,중지
	- 단구법 - 작은 글자, 엄지, 검지

#### 용어

- 서예 지도 단계 : 용필(점획) → 자형(글자) → 장법(배자)
- 전체
	- 점과 획을 쓰는 방식
		- 운필법
		- 용필법(동의어)
- 점획
	- 기필 : 처음, 장봉(=판본체, by 역입과 회봉)/노봉(=궁체)
	- 행필 : 중간
	- 수필 : 끝
	- 전절 : 획이 꺾이는 부분, 전(휘도록, 모나지 않게) + 절(꺾어서, 모나게)
	- 접필 : 점획을 붙여 쓰는 것
- 서명
	- 낙관 : 이름, 도장
	- 전각 : 도장 파기 (양각-배경 파내기 / 음각-이름 파내기)
- 기타
	- 중봉 : 붓끝이 획 중앙으로, 세워서. 권장
	- 편봉 : 〃 가장자리로, 눕혀서. 서예 X
	- 배자 : 글자 배치
	- 집자 : 예시 글자

| 중심     | 가운데                     | 살짝 오른쪽 (구궁 오른쪽 세로선) |

## 디자인과 매체

### 디자인

- 쓰임새에 맞게 아름답게 형태 계획. 심미성, 경제성, 실용성, 독창성

#### 시각 전달 디자인

- 그림 문자
- 마크
- 픽토그램 (모든 사람이 이해 ⇒ 상징,시각,단순화)
- 인포그래픽 (색, 이미지, 글자)
- 광고
- 포스터
- 캐릭터
- 이모티콘 (emotion + icon) ⇒ 감정, 생각 표현
- 편집
- 간판 ⇒ 단순명료, 환경과 어울리게
- 심볼

## 미술 교육론

### 로웬펠드 & 가드너

#### 로웬펠드 - 표현 능력, 발달 단계

- 난화기 (2~4세)
	- Scribble
- 전도식기 (4~7세)
	- 두족인, 자기중심적
- 도식기 (1,2학년)
	- 도식적 표현 (같은 대상에 대해 반복되는 표현, 색상) 나타남
	- + 기저선, 중앙원근법, 투영법, 전개도법 등
- 또래집단기 (3,4학년)
	- 사실적 경향과 도식적 표현 혼재
	- 교사가 오감을 사용한 관찰로 사실적 표현 촉진
	- + 중첩, 원근 영향
- 의사실기 (5,6학년)
	- 시각형 (사실형) - 객관적, 사실적
	- 촉각형 (감각형) - 주관적, 감정적
- 결정기
	- + 중간형 (복합)

#### 가드너 - 감상 능력 발달 단계

- 사실기 (3~4학년)
	- → 사실지향적 ; 주제에 대한 관심
	- ∴ 교사가 다양한 자료로 사실중심적 편향을 깨야
- 탈사실기 (5~6학년)
	- → 다양한 미적 특성 ; 재료나 기법에 관심

### 미술교육의 일반이론

#### 로웬펠드 vs. 아이스너

- 로웬펠드 → 자유로운 자기표현을 통한 창의성
- 아이스너 → 미술이해·감상교육

#### 학년군별 학생 특성

- 가드너, 로웬펠드 이론 참고

#### 미술교육 사조

	- 반복훈련, 미술 기능 향상, 결과 중심
- 창의성 중심 (로웬펠드)
	- 자유로운 자기표현, 과정 중심
- 학문 중심 (아이스너)
	- 체험·감상 영역 확대

		- (→ 속 시각 이미지를 바르게 이해·활용 → 비주얼 리터러시)
- 다문화

### 미술 수업모형

#### 직접 교수법

- 교사가 설명·시범, 실험하거나(판화), 새로운 용구(서예, 전통 회화)
- 문제 인식 → 설명·시범 → 질의응답 → 연습 활동 → 작품 제작 → 정리·발전

#### 반응 중심 학습법

- 학생 반응 극대화·반영, 감상·미적 체험 영역
- 반응 형성 ⇒ 경험, 배경지식 자극
- 반응 명료화 ⇒ 대화·토론 등 상호작용
- 반응 심화 ⇒ 관련 작품 탐색, 새로운 시각, 간단한 표현 활동
- 정리, 발전

#### 창의적 문제 해결법

- 모든 영역
- 문제 인식
- 아이디어 탐색 ⇒ 브레인스토밍
- 아이디어 정교화 ⇒ 아이디어 분석·정교화, 시각화(스케치), 선택
- 아이디어 적용 ⇒ 표현 활동
- 종합·재검토

#### 귀납적 사고법

- 규칙성 추론
- 문제 인식 → 관계 탐색 → 개념 발견(→ 규칙성, 용어) → 개념 적용 → 정리·발전

#### 기타

- 프로젝트 학습, 토의·토론 학습, 협동 학습 방법
