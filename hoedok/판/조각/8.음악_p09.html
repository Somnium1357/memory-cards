박자와 리듬

박자 젓기

2/4 : 강-약
3/4 : 강 약 약
4/4 : 강 약 중강 약
6/8 : 강 약약 중강 약약

6/8박자

박자에 따른 서양 악곡의 계통
3박자 → (3/4박) ; 마디가 반으로 안 나뉨
2박자 → 2/4박, 4/4박, (6/8박) ; 마디가 반으로 쪼개짐
∴3/4박 / 6/8박 구분도 계통 따라
지휘
빠르게 연주 = 한음 길이 ↓ → 2박자처럼 지휘 (1박=♩.) · 강-약
느리게 연주 = 한음 길이 ↑ → 6박자처럼 지휘 (1박=♪) · 강-약-약-중강-약-약

당김음

셈여림 규칙이 깨진다 = 당김음
리듬에 의해 : 센박 길이 < 여린박 길이
붙임줄에 의해 : 여린박 선율 → 앞으로 선율이 당겨짐
악센트에 의해 : 악센트 명시
쉼표에 의해 : 센 박 자리에 쉼표

센내기와 여린내기

센내기 : 첫박이 센 박 (일반적)
여린내기 : 첫박이 여린 박 (못갖춘마디)
맨첫마디 + 마지막마디 = 온전한 한마디
∴지휘시 예비박 (시작 전 박) 고려해서 지휘
센내기 : ④ 예비박, ① 첫박
여린내기 (첫마디 1박) : ③ 예비박, ④ 첫박

셈여림, 빠르기

셈여림 : 피아니시모 → 피아노 → 메조피아노 → 메조포르테 → 포르테 → 포르티시모
빠르기 : 안단테 → 안단티노 → 모데라토 → 알레그레토 → 알레그로
rit. : 리타르단도 = 점점 느리게
