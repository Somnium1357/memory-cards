5~6학년군 스포츠 - 기술형 스포츠 유형별 활동

1. 기술형 스포츠 의미·유형

1)기록형 → 움직임 기록 향상
2)동작형 → 움직임 정확하게 수행
3)투기형 → 상대방과 신체적 기술 겨루기

2. 기록형 (육상)

트랙 : 단거리·이어달리기
도약 : 멀리·높이뛰기
던지기 : 멀리던지기

1) 단거리 달리기

기본 기능
출발
제자리에 : 출발선 뒤에 양손 짚기
차려 : 엉덩이를 머리보다 높게
출발
가속 달리기 : 상체 서서히 ↑
전력 달리기 : 속도 유지, 무릎 ↑, 팔 앞뒤로 크게
도착 : 최고 속도 유지 - 몸통 부위(가슴) 뻗기 통과
러닝 피니시 : 자세 유지
런지 피니시 : 가슴 앞으로
슈러그 피니시 : 어깨 내밀며 통과

2) 이어달리기

기본 기능
배턴 아랫부분 잡기
줄때 신호
받을때 비슷한 속도로 달리기
주는손과 반대손으로 받기
방법
오버핸드 - 위에서 아래
언더핸드 - 아래에서 위
연습
신호 외치며 걸으며 주고받기 - 배턴 정확하게 전달
달려오는 친구가 곧 지나오면 출발 - 받을때 비슷한 속도로 달리기
원을 따라 달리기 - 곡선 주로
