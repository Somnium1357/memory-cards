지속가능한 기술과 융합

1. 친환경 건설 구조물

1) 건설 기술

건설 구조물의 종류
건축 구조물 : 인간이 거주·생활하는 데 필요한 공간 (e.g. 주택, 아파트, 학교, 병원 등)
토목 구조물 : 생활환경 개선을 위해 자연환경 변화 (e.g. 댐, 도로, 터널, 다리 등)
건설 구조물의 특성
장기성 : 오랜 기간
지역성 : 지역적 전통·특징 반영
일회성 : 한번 지으면 변경 어려움
종합성 : 학문과 기술 조화
공공성 : 공공의 이익을 위함
경제성 : 경제적 효율성 고려

2) 친환경 건설 구조물

종류
패시브 하우스 : 에너지 소비 최소
액티브 하우스 : 스스로 에너지 생산

2. 대체 기술

1) 생활 속 대체 기술

가상현실 : 환경을 컴퓨터로 재현
증강현실 : 현실에 가상 이미지 덧씌움
사물 인터넷 : 사물이 인터넷에 연결
빅데이터 : 많은 양 데이터 분석
