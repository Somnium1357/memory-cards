도덕 수업 모형

4. 가치 분석 수업 모형 (지식·이해)

⇒명료화에 대한 보완
개인적 가치, 판단 기준 X↔합리적 가치 판단, 사실적(=경험적) 증거·가치 원리 정당화 → 판단의 합리성에 초점

단계

  1. 문제 사태 제시
  2. 가치 문제 확인·명료화용어·진술 모호성 해결
  3. 입장 설정·사실적 타당성 탐색가치 선택·사실 문제 해결
  4. 잠정적 가치 결정·가치 원리의 검사
    잠정적 가치의 정당화 by 가치 원리의 보편화 가능성 검사
    새 사례 검사 : 다른 사례에 적용
    포섭 검사 : 일반적(상위) 도덕 원리 검토
    역할 교환 검사 : 심각한 영향 받는 사람·집단
    보편적 결과 검사 : 모두가 그렇게 행동한다면?
  5. 입장 수정·의사 결정
  6. 실천 동기 강화·일상 적용

5. 가치 갈등 해결 수업 모형 (지식·이해)

⇒(정당한) 두 가치의 갈등 상황(→ 사실, 정의, 가치 문제에서 비롯됨)의 해소
→재판관과 비슷한 역할, 법리적 모형과 연결

단계

  1. 문제 제시
  2. 규범 확인 및 의미 파악명료화(정의 문제)
  3. 문제 상황 성격 분석사실 문제
  4. 입장 선택·정당화가치 문제
  5. 입장 수정·대안 숙고

6. 합리적 의사 결정 수업 모형 (지식·이해, 과정·기능)

지식·가치 → 능력·품성 함양
규범 타당성 파악 : 연역 / 귀납

단계

  1. 도덕적 문제 사태의 제시와 분석
  2. 관련 규범의 확인 및 그 의미와 타당성 파악
  3. 여러 대안의 설정과 각 대안의 결과 검토
  4. 대안의 선택 및 정당화
  5. 대안 선택의 수정 및 잠정적 의사 결정

7. 집단 탐구 수업 모형 (지식·이해→탐구/가치·태도→정착)

단계

  1. 탐구 문제의 설정
  2. 탐구 계획의 수립
  3. 탐구의 실시
  4. 탐구 결과 발표 및 논의
  5. 종합 정리 및 평가
