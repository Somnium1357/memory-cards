# memory-cards

임용 인출 카드 iPad 표면. `https://somnium1357.github.io/memory-cards/`

- `cards.html` — 앱 본체 (ts-fsrs 5.4.1 인라인, FSRS 스케줄러)
- `cards-data.json` — 카드 전량 (루틴/본생성 세션이 gen_cards 후 커밋)
- `cards-state.json` — FSRS 상태 + 리뷰 로그 (앱이 GitHub API로 배치 커밋)
- `serif-kr.woff2` — C(페이퍼 웜) 테마 명조 헤드 (Noto Serif KR 서브셋, OFL)
