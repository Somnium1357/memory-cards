시제·높임 기능
용언의 활용
1)규칙 활용
기본형 : 어말, 어미 변화 X
'ㄹ' 탈락 : 어간 끝의 'ㄹ'이 'ㄴ'으로 시작하는 어미 앞에서 탈락 (살다 ⊃ 살- + -는 → 사는)
'ㅡ' 탈락 : 'ㅡ'가 '-아'/'-어'로 시작하는 어미 앞에서 탈락 (치르다 → 치르- + 어 → 치러)
2)불규칙 활용
어간만 바뀜
'ㅅ' : '잇-' + '-어' → 이어 ; 어간 끝 'ㅅ'이 모음 어미 앞 탈락
'ㅂ' : '돕-' + '-아' → 도와 ; ㅂ → ㅗ/ㅜ
'ㄷ' : '걷-' + '-어' → 걸어 ; ㄷ → ㄹ
'르' : '흐르-' + '-어' → 흘러 ; 르 → ㄹㄹ
'우' : '푸-' + '-어' → 퍼 ; ㅜ 탈락
어미만 바뀜
'여' : '일하-' + '-어' → 일하여 ; 어 → 여
'러' : '푸르-' + '-어' → 푸르러 ; '어' → '러'
둘다
'ㅎ' : '파랗-' + '-아' → 파래
