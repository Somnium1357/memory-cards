과학의 본성

1. 과학 태도

1)과학에 대한 태도 ⇒ 흥미·선호도 등
2)과학적 태도 ⇒ 과학을 올바르게 수행하는 데 필요
(청킹 : 증만 비신한 흔객이 개만인 합정에서 협동하여 겸손하게 회의)
증거 존중
비판성 : 사설·주장의 옳고 그름을 따짐
실패의 긍정적 수용 : 좌절은 일시적임을 인식
호기심 : 의문을 품고 답하려는 자세
객관성 : 개인적인 감정·판단 X (cf. 주관성)
개방성 : 새로운 증거에 따라 이론 수정
판단 유보 : 증거 부족할 시 판단 X
합리성 : 검증된 사실 중시
정직성 : 자료 왜곡 X
협동성 : 다른 사람들과 협동
겸손과 회의 : 개방 + 비판

2. 과학적 방법

1)귀납법
개념 : 구체 사례 → 일반 원리
한계 : 관찰 자체가 참 아닐 수도 (이론 의존성), 반드시 비약 (모든 사례 관찰 X)
2)연역법
개념 : 일반 전제 → 특수 사례
한계 : 전제가 참임은 귀납으로만 입증
3)가설-연역법
개념 : 관찰한 현상을 일반화해 가설 설정(귀납) → 가설을 전제로 하는 결론 예측 후 검증(연역)
한계 : 후건긍정의 오류
4)귀추법
개념 : 현상 → 인과적 의문 (배경지식 활용) → 잠정적 설명 (가설)

3. 과학 지식

1)사실 ⇒ 이론 의존성 때문에 관찰한 사실도 절대적 X
2)개념 : 같은 속성을 가진 대상의 범주
3)법칙 : 사실·현상 사이 규칙성
4)이론 : 현상의 원인 설명
5)모형
개념 : 직접 관찰·볼 수 없는 대상에 대한 구체적 표상
장점
쉽게 관찰 어려운 현상·대상 설명
과학 지식을 쉽게 이해
유의점 : 모형과 실제 자연 현상 사이 차이가 있음을 지도

4. 과학의 진보

1)귀납주의 (누가) ⇒ 귀납으로 과학 지식 형성
2)반증주의 (진화) ⇒ 포퍼, 반증가능성이 과학의 조건이며, 높을수록 좋은 이론 ; 반증 과정이 과학의 과정
3)연구 프로그램 (진화) ⇒ 라카토스, 핵 + 보호대로 구성, 보호대 수정·보완, 핵 무너지면 퇴행
4)과학혁명 (격변) ⇒ 쿤, 전과학 → 정상과학 → 위기 → 혁명 → 새로운 정상과학 → 위기
