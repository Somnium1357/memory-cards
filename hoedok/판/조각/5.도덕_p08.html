도덕 교육의 이론적 기초

1. 도덕 심리학

1) 프로이트

인간 : 비합리적 충동으로 움직임
도덕 : 사회의 행위 규범
도덕적 인간 : 사회 규범을 내면화·실천
사회 규범을 내면화하는 성향 = 도덕성
이드현실→자아(ego)⇐초자아
양심 : 금지 ← 규범 내면화
자아 이상 : 지향 ← 대상 동일시

2) 행동주의

인간 : 비합리적 힘(외력)에 의해 움직임
도덕 : 행위 규범
도덕적 인간 : 행위 규범 내면화
행동 학습 = S-R-R

2-1. 사회 학습 이론

⇒강화 이론 + 개인
학습 = 관찰
모방 : 행동 답습
동일시 : 내면적 가치 수용
대상 : 모델
강화
직접 : 외부 → 학습자
간접 : 외부 → 모델
사회학습이론
자기 : 내부 → 학습자 → 강화이론

3) 인지 발달론

피아제
타율적 도덕성 (도덕 사실주의 → 도덕 규칙 = 사물, 불변)
자기중심적 도덕 단계 : 도덕 규칙의 실재성
권위주의적 도덕 단계 : 도덕 규칙의 외부성
자율적 도덕성 (도덕 규칙 = 상대적, 가변)
상호성 : 협동과 합의로서의 도덕 규칙 이해(법적·인습적 규칙)
공정 : 연민과 공감에 따른 개인적 도덕 규칙(공감적·특수적 규칙)
