6.과학 - 지구와 우주

지구의 자전과 낮과 밤 모형실험 (2025 B 과학 8번)
모형실험의 두 관점
우주에서 바라보는 관측자 : 지구본을 움직이며 전체 상황을 바라봄
지구 관측자 : 지구에서 낮과 밤의 변화를 관찰 (지구본에 붙인 관측자 인형)
두 입장 동시에 고려 ⇒ 어떤 관점에서 이야기하는지 확인
관측자 모형 쓰는 까닭 : 우주에서 보는 관점과 지구에서 보는 관점 연결
낮과 밤이 생기는 까닭
태양 빛 받는 쪽 : 낮
태양 빛 못 받는 쪽 : 밤
지구가 하루에 한 바퀴 자전 ⇒ 낮과 밤이 하루에 한 번씩 번갈아
오개념 : 「지구는 왼쪽에서 오른쪽으로 자전한다」
왼쪽·오른쪽은 관측자의 위치와 바라보는 방향에 따라 달라짐 ⇒ 부적절
동서남북 방위 사용 ⇒ 지구는 서쪽에서 동쪽으로 자전
탐구 전 방위 설정 : 관측자가 남쪽을 바라볼 때 기준
건습구 습도계 (2018 A 과학 5번)
구성 : 건구 온도계 · 습구 온도계
습구 온도계 액체샘 : 젖은 헝겊으로 감쌈
원리
헝겊의 물 증발
증발할 때 주변 열 흡수 ⇒ 습구 온도↓
습도 낮을수록(건조할수록) 증발 활발 ⇒ 습구 온도 더 많이 낮아짐
건구와 습구의 온도 차 클수록 습도 낮음
온도 차 없음 : 증발 안 일어날 만큼 수증기 많음 ⇒ 상대 습도 100%
습도표 읽기
건구 온도를 세로줄에서 찾기
건구와 습구의 온도 차를 가로줄에서 찾기
두 줄이 만나는 칸 : 현재 습도
