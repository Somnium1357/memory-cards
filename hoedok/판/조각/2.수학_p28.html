2. 곱셈구구와 한 자리 수 곱셈

1) 배경지식

교환법칙 : a×b = b×a
결합법칙 : (a×b)×c = a×(b×c)
분배법칙 : a×(b+c) = a×b + a×c
항등원 : a×e = e×a = a, e=1
0 : 동수누가에 의해 0×a = 0, 교환법칙에 의해 a×0 = 0

3. 곱하는 수가 한 자리 수인 곱셈

⇒곱해지는 수 조작

1) 배경지식

배열 모델을 이용한 곱셈 해결 전략 (ex. 22×3)
동수누가 : 22씩 세 번 더하기
뛰어 세기 : 22, 44, 66으로 뛰어 세기
수분할을 통한 부분곱 : 자릿값에 대한 전개식으로 분해, 분배법칙 적용하여 부분곱
22×3 = (20+2)×3 = (20×3) + (2×3) = 60 + 6 = 66

2) (몇십) × (몇)

계산 원리
⇒곱해지는 수 몇십을 10×(몇)으로 바꾼 후 결합법칙
20×3 = (10×2)×3 = 10×(2×3) = 10×6 = 60
곱해지는 수 10배 → 결과 10배임을 이해
알고리즘 → (몇)×(몇) 뒤에 0 ~ 세로셈 X
