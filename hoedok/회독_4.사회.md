## 사회과 교수·학습 모형

### 개념 학습 모형

- 개념: 사례 → {속성/분류} → 명명. 논리적 이해
- 구조: 위계 {상위/하위/동위}, 속성 {접합/이접/관계}

#### 속성 학습 모형

- 장점 : 논리, 연역적↑
- 단점 : 추상·어려움↓
- "속성" 중심 (2단계)

| 단계       | 결과       |
| -------- | -------- |
| 문제 제기    | (사회 집단)  |
| 속성 제시·정의 | 결+비결     |
| 속성 검토    |          |
| 사례 검토    | 예·비예 검토  |
| 가설 검증    | 사례 보고 판단 |
| 개념 분석    | 유사 개념?   |
| 관련 문제 검토 | 사회문제 적용  |
| 평가       | 평가       |

#### 원형 학습 모형

- 장점 : 개념이 추상·모호 → 구체적 예로 이해↑
- 단점 : 한 개념에 여러 속성 → 추출 불가
- 원형(전형적 사례) 중심
- 문제 제기 → 원형 제시 → 비례 제시 → 속성 검토 → 개념 분석 → 관련 문제 → 평가

#### 상황 모형

- 상황: context - 학생 경험, 거리…
- 삶과 연결 but 추상화는?
- 문 → 상황 제시 → 사례 검토 → 속성 검토 → 개 → 문 → 평
	- (※ 마지막 세 칸은 한 음절 축약. 속성 학습 모형 단계와 대응시키면 개=개념 분석, 문=관련 문제, 평=평가)

### 탐구 학습 모형

- 실제이론을 도출한 과정(=탐구 과정) 재현
	- 이론 = 일반화된 지식
	- 과학적 방법(사회과학 이론이니)
		- 어려우니 교사 주도 가능(비중 문제)
	- 문제 → 가설 → 자료 수집·분석 → 결론·일반화
- 콕스
	- 문제 파악 → 가설(→ 잠정적) 설정 → 탐색(→ 계획수립) → 증거 제시(→ 자료 수집·분석) → 일반화
- 뱅크스
	- 문제 제기 → 가설 설정 → 용어 정의·개념화 → 자료 수집 → 자료 분석 → 가설 검증, 일반화

### 문제 해결 학습 모형

- 일상 문제 = 학생들이 일상생활에서 마주치는 문제
- 일상 문제에 대한 체계적 탐구 → 문제 해결 능력
- 문제 확인 → 원인 파악 → 해결 방안 탐색 → 해결 방안 결정 → 실천

### 의사 결정 학습 모형

- Why? → 사실 문제 + 가치 문제 혼재된 개인적·사회적 문제 해결
- 의사 결정력 함양
- 뱅크스, 합리적 의사 결정 모형
	- 문제 제기 → 사회 탐구(→ 지식 획득) → 가치 탐구(→ 가치 판단(선택)+정당화) → 의사 결정 → 행동
- 의사 결정 매트릭스
	- 문제 정의 → 대안 나열 → 선택 기준 작성(→ 사실·가치 판단 단계) → 대안 평가 → 의사결정
- + pros
	- 행동 실천 있음
	- 의사 결정력 ↑
- − cons
	- 합리적 의사 결정이 옳은가? (내적-절차적 합리성만)
	- 공동체 모두의 이익 아닐수도

### 논쟁 문제 학습 모형

- 의견 대립, 공동체 구성원 다수에게 영향(사회적 문제), 명확한 정답 X
- 의견 대립
	- 용어 정의 문제
	- 사실 문제
	- 가치 문제
- 각 측면에서 입장 선택, 옹호
	- 가치 문제 = 기본 가치, 헌법적 가치, 법률 등 가치 갈등 해결 기준에 입각
- + pros
	- 의사 결정력 함양
- − cons
	- 인지주의적 오류
	- 보수적 규범 주입
	- 공연한 논쟁, 급진적
	- 보편 규칙 찾기 어려움
- 교사의 입장
	- Kelly
		- 배타적 중립형
		- 배타적 편파형
		- 중립적 공정형
		- 신념을 가진 공정형
	- Harwood
		- 옹호 (소개→의견)
		- 관심 (의견→소개)
		- 신념 (의견만)
		- 객관 (의견X, 서술)
		- 공정한 의장 (의견X, 토론)
		- 악마 옹호 (반대의견만)

| 다양\의견 | O          | X          |
| ----- | ---------- | ---------- |
| O · K | 신공         | 중립적 공정     |
| O · H | 옹호, 관심     | 객관, 공정한 의장 |
| X · K | 배타적 편파     | 배타적 중립     |
| X · H | 신념          | —          |

- 문제 제기 → 개념 명료화 → 사실 확인(→ 경험적) → 가치 갈등 해결(대립 가치 분석) → 대안·결론
- 행동 단계 X

### 협동 학습 모형

- 이질적 집단, 긍정적 상호의존, 개별적 책무성 강조
	- (나타나지 않으면 전통적 소집단 학습)
- 수업 모형
	- 장점 추출 → Jigsaw Ⅱ
		- Jigsaw I
		- STAD (집·성·분·오)
	- Jigsaw I
		- 소집단 구성 → 전문가 학습지 배부(→ Jigsaw Ⅱ 차이) → 전문가 모둠 학습 → 원모둠 학습 → 학습지 작성·정답 확인 → 개별 평가·개별 보상(→ Jigsaw Ⅱ 차이)
	- STAD
		- 소집단 구성 → 안내 학습지 배부 → 모둠 학습 → 학습지 작성·정답 확인 → 개별평가·집단보상(향상 점수), (→ Jigsaw Ⅱ)
	- Jigsaw Ⅱ
		- 소집단 구성 → 전체 학습지 배부(→ 하위주제 = 모둠원 수 맞추기) → 전문가 모둠 학습 → 원모둠 학습 → 학습지 작성·정답 → 개별평가, 집단 보상(향상점수)
		- ※ 향상점수? → 학생이 향상된 정도 점수화
	- +α
		- TGT (Teams - Games - Tournament)
		- TAI (Team Assisted Individualization)
		- GI (Group Investigation)

### 가치 학습 모형

- 가치·태도 학습 for 가치 판단·사회 생활 적응
- ※ 가치 학습 계보
	- 주관적
		- 가치 주입 (교화) : 반복, 암기. 인지주의적 오류
		- 가치 명료화 : 개인적 가치 명료화. 상대주의 문제, 가치 판단 X
	- 객관적
		- 가치 분석
		- 가치 탐구
		- 공통점 : 합리적 가치 판단 목적. 가치 결정력 함양. ／ 차이점 : "평가" ⇒ 내재적 합리만?(=사실 확인, 절차 검증) ／ 외재적 합리도?(=평가, 대안 가치 분석, 대안 검토)
- 가치 명료화
	- 가치 선택 → 가치 존중(=소중히) → 행동
- 가치 탐구(분석)
	- 문제 제기 → 가치 문제·갈등 확인 → 대안 검토·예측 → 가치 선택, 행동.(→ 합리적; 정당화 가능해야)

## 사회과 수업 기법

### 현장 학습

- 교과 - 실제 상황 연결 ⇒ 생생한 이해(목적이 문제해결 : 체험 학습)
- 간접 현장 학습 : 교실로 삶의 현장 들여오기 (초빙)
- 직접 〃 : 삶의 현장 방문하기 (방문)
- ∴ 학습 내용-현실 정합성↑, 협동심, 사회 참여 능력↑
- 유의점
	- 사전 답사·조사 필요
	- 면담 준비 (사진, 녹음기)

### 지도 학습 (지리)

- 도해력 함양이 목표
- 도해력 : 공간 정보 (해석)⇄(가공·변환) 시각 정보
- 유형 : 위치 학습, 방향 학습, 투영법 학습, 기호 학습, 거리 학습

### 사료 학습 (역사)

- 역사적 자료(=사료)를 해석, 당대 사회상 재구성 → 역사적 의미 부여
- 1차 사료 : 당대에 작성
- 2차 사료 : 후대에 작성
- 유의점
	- 사료 신뢰성 판단
	- 번역 정확한지
	- 학습자 발달 단계 맞게. (⇒ 사료 재구성)

### 인물 학습 (역사)

- 인물의 행동에 영향 미친 배경 이해. 결과 분석 ⇒ 인물 입장에서 사고하는 능력
- cf) 민중 역할 강조, 지역사회·여성 인물 소개

### 극화 학습

- 사회 현상을 단순화·추상화하여 학습 ⇒ 가상 상황 구성
	- 단순화, 추상화 : 사실성과의 Trade-off 있음
	- 사회 현상 단순화 : 문제 상황 현실감 있게 인식 → 문제 해결력↑
	- 가상 상황 : 감정 이입 능력↑
- 기준: 규칙·체계·승패 유무
	- 역할놀이 학습 : 역할 배정, 목표X, 체계X
	- 모의 학습 (=시뮬레이션) : 목표O, 체계O, 승패 정함

### 그 외 학습 기법

- 프로젝트 학습 : 학생 스스로 주제 탐구 ⇒ 문제해결력
- 시사 학습 : 새롭게 나타난(=시의성 있는) 주제를 다양한 매체에서 정선 → 재구성하여 학습
	- └ 예전 교육과정에는 신문 활용 학습(NIE) ∴ 흥미↑, 현실-교과 괴리감↓

## 사회과 교육과정의 내용 구성 원리

### 환경 확대법의 탄력적 적용

- 학년이 올라감에 따라 환경(공간)의 범위 확대
- 고장 - 지역 - 국가 - 세계
	- 3 - 4 - 5 - 6
- (→ 22개정) 우리가 살아가는 곳 - 우리 지역 - 여러 지역
	- 3학년 : 고장 (i.e. 기초자치단체)
	- 4학년 : 지역 (i.e. 광역자치단체)
- 22개정 이유
	- 세종특자시처럼 고장 = 광역자치단체
	- 행정구역 경계에서 실제 생활영역이 행정구역과 불일치

### 주제 중심의 통합적 구성

- 사회과의 다양한 영역 (지리, 역사, 일사)을 통합적으로 구성

### 교육과정의 지역화

- 학습자가 살고 있는 지역·실제 활용
- 내용의 지역화 (i.e. 목적으로서의 지역화) ; 고장·지역에 대한 이해가 목적 ⇒ 애향심 고취
- 방법의 지역화 (i.e. 수단으로서의 지역화) ; 사회 현상의 일반적인 원리를 쉽게 이해

### 나선형 교육과정의 원리

- 단순 → 복잡, 구체 → 추상으로 배열 ⇒ 계속성(내용 반복), 계열성(내용 깊이)

## 역사, 지리 영역 지도
