1. 체력운동 기본 움직임 기술

1) 운동과 체력

체력
건강 체력
근력 : 근육이 큰 힘을 낼 수 있는 능력
근지구력 : 근육이 오래·지속적으로 힘을 낼 수 있는 능력
심폐 지구력 : 산소를 이용한 운동 지속력
유연성 : 관절 가동 범위
운동 체력
순발력 : 순간적으로 강한 힘
민첩성 : 빠르게, 방향 전환
협응성 : 여러 근육 조화
평형성 : 자세 유지

2) 걷기와 달리기 ⇒ 심폐지구력

→한 발이 항상 땅에 vs 양 발이 공중
팔

달리기 : ㄴ 자, 리듬에 맞춰
상체
걷기 : 곧게 펴기
달리기 : 5~10° 앞으로 기울이기
발 → 뒤꿈치부터 착지

손가락 ⇒ 손가락 전체로 쥐기, 엄지가 검지 밖으로

4) 버티기와 굽히기 ⇒ 근력 / 유연성

2. 체력운동 기능

1) 신체 특성 알아보기

체격 : 몸의 외형
체형 : 신체의 형태
체력 : 운동체력 + 건강체력
지도변화 가능, 개인차 있음

2) 운동의 단계 알아보기

준비 운동(Warm up) ⇒ 체온 상승, 몸을 부드럽게
방법 : 심장에서 먼 부위부터 (맨손 체조·스트레칭 일반 원리), 자주 사용할 근육
종류 : 동적 스트레칭 (계속 움직임) ⇒ 운동 효율 ↑
본 운동 ⇒ 가장 많은 시간
정리 운동(Cool-down) ⇒ 피로 회복 ; 건너뛰지 않도록 주의
방법 : 많이 사용한 근육 위주
종류 : 정적 스트레칭 (자세 유지) ⇒ 주로 사용한 근육 수축·이완으로 인한 비대칭 해소

3) 오래 달리기, 걷기 (심폐지구력)

⇒바른 걷기·달리기 자세 유지

4) 팔굽혀펴기 (근력 + 근지구력)

무릎 대고 팔굽혀펴기 ⇒ 무릎과 팔이 가까워지면 쉬워짐
자세 ⇒ 머리 - 허리 - 다리 일직선, 어깨 - 팔꿈치 일직선
유의점 ⇒ 허리 꺾이면 X (↑ 머리-허리-다리 일직선), 팔꿈치 몸 밖으로 벌리면 X (↑ 어깨-팔꿈치 일직선)

5) 윗몸말아올리기 (배의 근력)

자세
발바닥 전체가 바닥에 닿게
손은 무릎에 끝 → 친구 손 닿을 때까지 올라가기

6) 왕복달리기

심폐지구력 (→ 긴 거리(15m))
민첩성 (→ 짧은 거리(3m) + 순발력)
자세 : 방향 바꿀 때 중심↓, 속도↓

7) PAPS (운동 체력 중심 → 건강 체력 중심)

필수
심폐 지구력 : 오래달리기 (왕복, 걷기), 스텝
유연성 : 앉아 윗몸 앞으로 굽히기, 종합 유연성 (어깨, 몸통, 옆구리, 하체)
근력·근지구력 : 팔굽혀펴기 (남, 여는 무릎), 윗몸말아올리기, 악력
순발력 : 50m 달리기, 멀리뛰기
비만 : BMI (체중(kg) / 키(m)²)

3, 4학년군 운동 - 건강 운동 및 생활 습관

1. 건강 생활 습관

1) 건강한 생활 습관

건강 : 신체, 정신, 사회적 안녕

2) 바른 자세로 생활하기

디지털 기기 : 화면과 적당한 거리, 고개 숙이기 X (거북목)
서기와 걷기 : 양발에 같은 힘, 가방 양어깨 수평
물건 들기 : 허리 펴고 무릎 굽히기

3) 자세가 몸에 미치는 영향

몸의 변화 : 척추 측만증, 거북 목 (귓구멍이 어깨 앞으로), 골반 변형

4) 체중과 체형 관리하기

비만 : 체지방률 기준

2. 운동 생활 습관

원리

1. 건강체력

1) 의미와 요소

2) 근력·근지구력

측정

분류

측정 : 왕복 오래달리기 (PAPS)
운동 : 줄넘기 – 초보자는 가슴, 숙련자 배꼽

방법 : 난이도↑, 시간↑, 고강도 훈련 추가 (인터벌 트레이닝), 진전 상황 모니터링

4) 유연성

유의점 : 반동X, 천천히 자연스럽게 호흡
운동 : 스트레칭 (정적 / 동적)
