3~4학년군 스포츠 - 스포츠 유형별 움직임 기술

1. 기술형 스포츠 유형별 움직임

⇒동작형, 투기형, 기록형

1) 구르기

원리
몸을 둥글게 해 회전력 ↑
무게 중심은 이동 방향으로
앞구르기
동작
머리의 뒷부분이 매트에 닿게
무릎을 가슴쪽으로, 턱 당기기 ⇒ 몸을 둥글게
매트에 닿는 순서 : 발 → 양손 → 뒷머리 → 등 → 허리 → 엉덩이 → 발
연습
오뚝이 : 속도 ↑
턱에 끼기 : 턱 당기기 (둥글게)
경사면 : 구르는 힘 ↑ ⇒ 무게 중심 넘기는 감각 익히기
뒤구르기
동작
엉덩이를 발뒤꿈치에서 멀리 (속도↑)
무릎·턱 당기기
순서 : 머리 → 등 → 어깨 → (양손 → 뒷머리) → 발
연습 : 회전 속도 ↑ 계열 / 둥글게 계열
피드백 : 손으로 매트 밀어내기 (시작, 목 회전, 일어나기 공통)

2) 옆돌기

동작
시선 : 정면 → 손끝
매트에 닿는 순서 : 왼발 → 왼손 → 오른손 → 오른발 → 왼발
연습 : 양팔로 버티며 다리 들기 ⇒ 팔 힘 ↑
보조 : 학생 뒤에서, 허리 잡기

3) 전력 달리기

동작
윗몸 점차 세우기
팔꿈치 L자, 앞뒤로 힘차게 흔들기
무릎 높게 들어 보폭 ↑
결승선에서 속도 줄이지 X, 가슴 내밀며 통과 (= 런지 피니시)
연습
보폭↑ : 훌라후프, 무릎↑
속도 줄이지 X : 스카프
