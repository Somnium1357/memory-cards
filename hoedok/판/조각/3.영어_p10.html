기능별 언어지도 - 이해

Ⅰ. 듣기 - 읽기 공통 내용

1. 이해 처리 과정

Bottom-Up : 상향식 이해 처리. 언어 기반 decoding 중심. form 위주. schema 사용 X
Top-down : 하향식 이해 처리. 전체적 이해 중심. meaning 위주. schema 사용
Interactive : 상·하향 모두 사용

2. 과정 중심 지도

전 (Pre)
어휘 지도 (상향식)
배경지식 활성화 (하향식)
동기 부여, 목적 안내
중 (While)
이해에 도움을 주는 활동 (과다한 듣·읽기 X) ⇒ 읽기 shared reading
후 (Post)
이해 확인
상향식 언어 지도
기능 통합

Ⅲ. 읽기 지도의 특성

1. 읽기 단계

Literal comprehension(문자 그대로 내용 파악)
→
Interpretive(추론·행간의 의미)
→
Critical(비판적)
→
Creative(감상·감정)

2. 읽기 유형

Intensive : 한 부분에 집중적 → 문법·구문구조 분석 등 (⊂ 수능 영어)
Extensive : 전체적인 이해 → 주로 흥미로 (⊂ 다독가)
Reading aloud : 실제성↓ (실제로 소리내지 못함), 학생들 주의가 발음으로 감
Silent reading : 어려움. 실제적
