3. 지시·접속 표현

1) 지시 표현 (가리키는 말)

기능 : 응집성 ↑
사용 방식 : 화자, 청자, 대상의 거리에 따라 표현 결정

2) 접속 표현 (이어주는 말)

기능 : 응집성 ↑
사용 방식 : 문장 사이의 의미 관계에 따라 결정

4. 시간 표현

1) 과거 시제 (사건시 → 발화시)

선어말 어미 '-었', '-았'
시간을 나타내는 부사어

2) 현재 시제 (사건시 = 발화시)

선어말 어미 '-는, -ㄴ', 관형사형 어미 '-는'
시간을 나타내는 부사어

3) 미래 시제 (발화시 → 사건시)

선어말 어미 '-겠', 관형사형 어미 '-(으)ㄹ', 의존 명사 결합 '-(으)ㄹ 것'

5. 관용 표현

⇒둘 이상의 단어가 합쳐져 새로운 의미를 가지는 것
관용어 : 비유, 교훈, 풍자성 ↓
속담 : 비유, 교훈, 풍자성 ↑

6. 지식 탐구 학습 모형

⇒구체적인 사례 → 개념·규칙 발견, 학습자 중심

단계

문제 확인 → 자료 탐색 → 지식 발견 → 지식 적용
