읽기 - 평가

1) 선다형 평가(객관식)

⇒4~5개 답지로 반응 제한 ; 읽기 과정보다 결과 평가

2) 빈칸 메우기법(빈칸에 들어갈 내용)

⇒문맥 + 사전지식 이용 → 사실적 이해, 추론적 이해 평가
정확단어(토씨) / 허용단어 채점
장 : 과정평가, 타당, 신뢰도 ↑
단 : 허용단어 채점시 객관성 문제

3) 자유 회상 검사(기억나는 내용 모두 쓰기)

⇒단서(제목·주요 단어) 없이 기억한 정보 회상 ; 읽기 결과 총체적 평가

4) 중요도 평정(중요X … 매우 중요)

⇒글을 의미 단위(보통 문장)로 쪼개고 중요도 판단

5) 오독 분석법(소리내어 읽고~)

⇒음성적으로 잘못 읽는 부분 분석 ; 읽기 과정에 대한 구체적 정보

6) 자율적 수정(아, 이게 아니라~)

⇒학생이 스스로 고쳐 읽는 행위 분석 ; 상위인지적 독해 능력 평가

7) 프로토콜 분석

학생의 사고 구술을 녹화·녹음한 자료 ; 초인지 직접 확인

8) 관찰법

⇒체크리스트/일화 기록

9) 포트폴리오법

⇒수행·성취 자료 기록 파일로 평가 ; 읽기 발달 지속 평가

10) 요약하기(전략&평가)
