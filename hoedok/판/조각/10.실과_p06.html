5. 우리나라 밥상차림

1) 밥상 차림

형식
주식 : 밥
부식 : 국 + 반찬
→첩 : 반찬 접시 수 (밥, 국, 김치, 장, 찌개 X)
차리기 : 왼쪽부터 밥 → 국그릇 → 수저

2) 썰기와 교차오염

썰기
통째썰기 : 통으로
팔모썰기 : 정육면체 (깍두기)
채썰기 : 2mm정도 너비로 길게
다지기 : 2mm 정도로 잘게
어슷썰기 : 비스듬
길게 썰기 : 나무젓가락 정도 (김밥)
반달 썰기 : 반원
은행잎 썰기 : 사분원
나박 썰기 : 높이 낮은 직육면체 (나박김치)
교차오염 : 도마 분리, 손씻기

2) 제작 과정

구상 → 치수 → 본뜨기 → 마름질 → 바느질 → 완성
본뜨기 : 종이에 치수 기준으로 본뜨고 자르기
마름질 : 옷감에 본 대고 바느질선 그리고 → 여유(시접) 줘서 자르는선 그리고 자르기
