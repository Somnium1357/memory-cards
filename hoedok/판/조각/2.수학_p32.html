수와 연산 - 분수의 덧셈·뺄셈

1. 분모가 같은 진분수의 덧셈·뺄셈

1) (진분수) + (진분수)

계산 원리 : 단위분수 변환 → 분배법칙의 역 (∵ 분모가 같은 분수 덧셈 = 단위분수 개수의 합)
e.g. 2/6 + 3/6 = 1/6 × 2 + 1/6 × 3 = 1/6 × (2+3) = (2+3)/6 (→ 계산 알고리즘) = 5/6

2) 받아올림 있는 (대분수) + (대분수)

자연수 부분 / 진분수 부분으로 나누어 계산
⇒모델 : '1'이 되는 모델 등분할 X
가분수로 바꾸어 계산
⇒모델 : 모든 영역을 분모로 등분할
대분수는 항상 이 두 가지로 나뉨

3) 유의점

약분은 5~6학년군 내용이나 결과 기약분수 표현 강제 X

4) 오류

분모끼리, 분자끼리 더하는 오류
원인 : 분모·분자 의미 이해 X, 영역 모델 1개 크기 = 1 이해 X
인지적 갈등 : 어림 활용
지도 : 알고리즘, 구체물 조작
1을 분수로 잘못 바꾸는 오류
원인 : 자연수 받아내림
지도 : 1을 크기가 같은 분수 여럿으로

2. 분모가 다른 진분수의 덧셈·뺄셈

1) (진분수) + (진분수)

조작 활동 → 재귀적 분할
통분 ⇒ 분수의 단위는 분모가 결정하므로 단위 통일
공통분모 → LCM, 분모의 곱 등 방법 가능

2) 유의점

결과 약분 가능

3) 오류

분모끼리, 분자끼리 더하는 오류
원인 : 분모·분자 의미 이해 X, 분모가 같은 분수의 덧셈 계산 방법 이해 X (cf. 동분모 오류 원인)
이하는 동분모와 같음
