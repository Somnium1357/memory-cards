쓰기 - 쓰기 이론

1. 형식주의 작문 이론

1) 개념

쓰기 : 쓰기와 관련된 지식을 글로 실현하는 과정
장르 규범적 지식, 문법 지식
⇒쓰기는 선조적 (일방 선형적) 과정, 결과물을 중시

2) 지도 방법 ⇒ 결과 중심 쓰기 지도

지도 내용 : 장르 규범적 지식, 문법 지식
교사 : 모범적인 텍스트를 분석해 쓰기 지식 전달, 결과물 점검・평가
쓰기와 관련된 지식이 잘 반영된 텍스트
학생 : 수동적으로 모범적인 텍스트 모방, 반복적인 연습

2. 인지 구성주의 작문 이론

1) 개념

쓰기 : 개인이 쓰기 문제 해결 과정을 통해 글을 완성해 가는 과정
⇒쓰기는 회귀적 과정. 쓰기 전략과 그 선택을 위한 초인지 강조
상위 인지를 통한 조정하기에서 필요 단계로 회귀

2) 지도 방법 ⇒ 과정 중심 쓰기 지도

지도 내용 : 쓰기 전략, 상위인지
능숙한 필자 : 수사적 맥락 고려한 독자 중심 글쓰기
미숙한 필자 : 수사적 맥락 고려한 독자 중심 글쓰기 X 자기 중심적 글쓰기
교사 : 사고 구술법 같은 방법으로 조력, 안내
학생 : 능동적으로 의미 구성

3. 사회 구성주의 작문 이론

1) 개념

쓰기 : 담화 공동체에서의 상호작용을 통한 의미 구성
담화 규범 : 담화 공동체의 규범 ⇒ 이를 수용하는게 합의 (사회·문화적 맥락에 포함)

2) 지도 방법 ⇒ 맥락 중심 쓰기 지도

⇒맥락과 담화 관습을 고려한 실제적 쓰기 결과물 (cf. 형식주의)
교수 방법 ⇒ 쓰기 워크숍 ; 과정-결과 균형, 맥락 안에서 쓰기
교사 : 촉진자, 안내자
학생 : 상호작용을 통해 능동적 의미 구성
