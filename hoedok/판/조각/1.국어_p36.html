말·듣 - 대화

1. 배경지식

1)자아 개념 : 다른 사람들이 자기를 어떻게 생각하는지에 대한 스스로의 생각
부정적 → 긍정적 by 칭찬, 긍정적 피드백
2)자아 노출 : 타인에게 자신의 정보 알리는 것 ⇒ 친밀감 형성에 중요
⇒속도·정도 조정 필요
순서 : 사회적 차원 → 개인적 차원
3)나 전달법 : 나를 주어로 생각·감정 전달
4)공감적 듣기
의미·효과 : 분석·비판 X, 상대방 관점에서 이해 ⇒ 대인관계 긍정적 영향
cf. 비판적 듣기 - 대인관계 악영향
전략
소극적 듣기 : 집중하기 (집중 확인), 격려하기 (이야기 이어나가도록)
적극적 듣기 : 요약하기 (그대로 요약), 반영하기 (피드백)
5)순서 교대의 원리 : 말차례 지켜 가며 대화 ⇒ 말차례 교환 신호 따라서

2. 각론

1)칭찬의 방법
언어적 강화 : 특성·결과 칭찬
격려 : 과정 칭찬
사회적 인정 : 사회적 영향 칭찬 (~덕분에)

3. 대화의 원리

1)협력의 원리
양의 격률 : 필요한 만큼만
질의 격률 : 진실만
관련성의 격률 : 목적·주제와 유관한 것만
태도의 격률 : 간결·조리 있게
→ 고의로 위반하여 대화 함축
2)공손성의 원리
관용 : 화자 혜택 ↓, 부담 ↑
요령 : 청자 부담 ↓, 이익 ↑
찬동 : 청자 비방 ↓, 칭찬 ↑
겸양 : 화자 칭찬 ↓, 비방 ↑
동의 : 이견 ↓, 일치 ↑

4. 기타 각론

1)준·비언어적 표현 사용 ⇒ 뜻을 효과적으로 전달
2)인과 ⇒ 원인 - 결과 일대일 아님을 지도
