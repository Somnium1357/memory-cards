원기둥, 원뿔, 구

배경지식

곡면체

회전체

정의 : 평면도형을 같은 도형 위 직선을 축으로 잡고 회전. (학교 지도 X)
구성요소 : 원기둥, 원뿔, 구 ⇒ 발생적으로 정의 (학교에서는 경험만)
성질 : 다양한 원뿔곡선 생각

원기둥

정의 : 평행·합동의 두 원 대응점 연결
구성요소 : 모선, 밑면, 옆면
종류
직원기둥 : 모선 ⊥ 밑면
빗원기둥 : 모선 not ⊥ 밑면

원뿔

정의 : 원과 그 평면 밖의 정점을 이은 선분으로 만들어짐
구성요소 : 밑면, 꼭짓점, 옆면, 모선
종류
직원뿔 : 정점과 밑면의 중심을 이은 선분 ⊥ 밑면
빗원뿔 : 정점과 밑면의 중심을 이은 선분 not ⊥ 밑면

구

정의 : 한 점에서 같은 거리
구성요소 : 중심, 지름, 반지름
성질 : 평면으로 자르면 원 (⇒ 현의 수직이등분성을 회전시킴)

핵심 각론

원기둥

정의 : 예시적 or 밑면만 명명
구성요소 : 밑면, 옆면, 높이 ⇒ 모선 X
원기둥 만들기 : 회전체 명시 X, 모선이 그리는 면이 옆면임을 암묵적으로 보임
전개도
의미 : 모서리가 없이 밑면의 둘레와 옆면을 따라 자름
⇒점선은 "모서리를 따라 접는 선"이므로 점선 없음
전개도 조건 : 원의 둘레의 길이와 가로가 같은 직사각형, 마주 보는 합동인 원

원뿔

정의 : 예시 or 밑면만 명명
구성요소 : 밑면, 모선, 높이
원뿔 만들기 : 직각삼각형 회전

구

정의
예시적 : 일반적
발생적 : 반원의 회전체
구성요소와 성질
예시 : 중심-가장 깊은 점 / 반지름 / 지름
발생 : 중심 : 반원의 중심 / 반지름 : 반원의 반지름 / 지름
구 만들기 : 반원 회전
