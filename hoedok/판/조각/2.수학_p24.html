약수와 배수

의미 : 약수 : 나누어 떨어짐 / 배수 : 정수배
성질 : 약수 개수 홀수면 제곱수, 크기랑 약수 개수 무관

완전수, 부족수, 과잉수, 친화수

Nm 의 약수 d1…dn 에 대해 Σ(k=1→n) dk = Dm 라하면
N > D : 부족
N = D : 완전
N < D : 과잉
N1=D2, N2=D1 → N1,N2가 친화수

배수 판정법

7의 배수 판정
N=10a+b, M=a-2b → N=10M+21b
N이 7의 배수 ⇔ M이 7의 배수
(⇒) 10M+21b → 7배수
7,10 서로소 → M 7배수
(⇐) N=7배수+7배수 → N→7배수
