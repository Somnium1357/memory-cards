## 기초 문식성

### 낱자와 음소

#### 국어의 계열

- 의사소통
	- 음성 언어 - 음소(→ 뜻을 구별) - 음절(→ 소리를 구별) - 단어 - 문장 - 문단 - 글
		- 음소
			- 자음
			- 모음
		- 음절
			- C+V
			- C+V+C
	- 문자 언어 - 낱자 - 글자 - 단어 - 문장 - 문단 - 글
		- 낱자
			- 자음자
			- 모음자
- "기본자" / "~음" / "~음자" ⇒ 구별해서 기억
- 기본자 (제자 원리상 기본) → 자·모음자 만들어짐 (문자언어)
- 자·모음 → 음성언어 계열

#### 모음과 모음자

- 모음자
	- 제자 원리
		- 기본자 "·, ㅡ, ㅣ" (≒ 천, 지, 인) ⇒ 상형의 원리
		- → 기본자끼리 한번 합성하여 초출자 "ㅗ,ㅏ,ㅜ,ㅓ" ⇒ 합성의 원리
		- → 초출자에 '·' 한번씩 합성하여 "ㅛ,ㅑ,ㅠ,ㅕ"
		- ※ 빠진 모음들은 "합용", 이중모음 표기 (≒ 병서)
- 모음
	- 단모음과 이중모음
		- 단모음: 발음시 조음 기관이 움직이지 않음
		- 이중모음: 발음시 조음 기관이 움직임
	- 단모음의 체계 (⇒ 키위제외해, 금붕어조아)
		- 기준: 혀의 전후 위치, 혀의 높낮이, 입술의 모양

#### 자음과 자음자

- 자음자
	- 제자 원리
		- 기본자 "ㄱ,ㄴ,ㅁ,ㅅ,ㅇ" (≒ 조음 기관 모양) ⇒ 상형의 원리
		- → 기본자에 획을 더하여 가획자
			- ㄱ→ㅋ
			- ㄴ→ㄷ→ㅌ
			- ㅁ→ㅂ→ㅍ
			- ㅅ→ㅈ→ㅊ
			- ㅇ→ㆆ→ㅎ
			- 가획했는데 소리가 세지지 않는 이체자
				- ㆁ
				- ㄹ
				- ㅿ
		- 가획의 원리
	- 병서: 자음 나란히 쓰기
		- 쌍자음 (각자 병서, 같은 거)
		- 겹자음 (합용 병서, 다른 거)
- 자음
	- 자음의 분류 (바다사자가/ㅁㄴㅇ/ㄹ/ㅎ)
	- 분류 기준: 조음 방법, 조음 위치, 세기

- 음소가 세기에 따라 분류, 한국어 음운체계 특징
- 뜻, 어감 구별

#### 한글의 특성

- 문자적 : 표음 문자, 음소 문자 (소리-문자 대응 일대일), 모아쓰기
- 음운 체계적 : 모음 조화, 소리의 길이로 의미 구별, 삼지적 상관속
- ※ 지도 시 유의사항

### 글자와 음절

#### 글자

- 받침이 없는 글자
	- 짜임: 좌우, 상하, 상하우
	- 자형
		- 세로획이 있음 : 기울인 세모형
		- 세로획이 없음 : 바른 세모형
	- ㅜ, ㅠ ⇒ 마름모형
- 받침이 있는 글자
	- 짜임: 좌우 받침, 상하 받침, 상하우 받침
	- 자형
		- 세로획 ㅇ : 네모형
		- 세로획 X : 마름모형

### 단어

#### 음운 현상

- 대치 (음운의 수 그대로)
	- 음절의 끝소리 규칙 (평파열음화)
		- 음절의 끝소리가 평음화·파열음화 (평음화: 된·거센 → 예사, 파열음화: ㅅ,ㅈ→ㄷ)되어 "ㄱ,ㄴ,ㄷ,ㄹ,ㅁ,ㅂ,ㅇ"로 발음
	- 자음 동화
		- 비음화
			- "ㄱ,ㄷ,ㅂ"이 "ㄴ,ㅁ" 앞에서 비음 "ㅇ,ㄴ,ㅁ"으로 바뀌는 현상
		- 유음화
			- "ㄴ"이 유음 "ㄹ"로 바뀌는 현상
	- 된소리되기 (경음화)
		- 받침 뒤의 "ㄱ,ㄷ,ㅂ,ㅅ,ㅈ"가 된소리로 발음됨
	- 구개음화
		- 받침의 "ㄷ,ㅌ"이 "ㅣ"로 시작하는 형식 형태소(→ 조사, 어미, 접사)를 만나 구개음 "ㅈ,ㅊ"으로 발음
- 축약 (음운의 수 줄어듦)
	- 거센소리되기
		- "ㄱ,ㄷ,ㅂ,ㅈ"이 "ㅎ"과 만날 때 거센소리로 발음됨 ("ㅅ" 제외 → 조음방법이 같음)
- 탈락 (음운의 수 줄어듬)
	- 자음군 단순화
		- 음절의 끝소리에 오는 겹받침 중 하나가 탈락
			- 첫째 자음 : 일반적. [넓], [밟] 포함
				- 다만 '밟-'은 자음 앞에서 [밥] : 밟다[밥ː따], 밟는[밤ː는] ⟨교재 자료_기초문식성 26쪽 · 표준발음법 10항 다만⟩
				- 다만 '넓-'은 '넓죽하다[넙쭈카다]', '넓둥글다[넙뚱글다]'에서 [넙] ⟨교재 자료_기초문식성 26쪽 · 표준발음법 10항 다만⟩
			- 둘째 자음 : ㄺ,ㄻ,ㄿ, 단, 'ㄺ'+'ㄱ' → 'ㄺ'는 'ㄹ'로 발음
				- 이 예외는 **용언 어간**의 'ㄺ'에만 적용 (cf. 흙길[흑낄]) ⟨교재 자료_기초문식성 26쪽 「용언 어간의 겹받침 'ㄺ'은 'ㄱ' 앞에서 [ㄹ]로 발음한다」⟩
			- ※ 흙이 [흘기] 같은 연음 현상과 구분 (음운 수)
	- 'ㅎ' 탈락 (후음 탈락)
		- 'ㅎ' + 모음 어미·접미 에서 'ㅎ' 탈락
			- 받침의 'ㅎ' 음가 유지 X ⇒ 특히 받침의 'ㄶ' 구분
				- 않는[안는] : 자음군 단순화
				- 않은[아는] : 'ㅎ' 탈락, 연음
	- 표기반영
		- 'ㄹ' 탈락 : 솔+나무
		- 'ㅡ' 탈락 : 잠그+아
		- 동일 모음 탈락 : 가+아서
- 첨가
	- 'ㄴ' 첨가
		- 앞말이 자음으로 끝나고 뒷말이 'ㅣ,ㅑ,ㅕ,ㅛ,ㅠ'
		- 물약[물략]: ㄴ첨가, 유음화 (2음절 첫 ‘ㅇ’ = 음가 X → 유음화 대상 X) ※구멍 09-20
	- 사잇소리
		- 합성어에서 'ㅅ' 첨가, 된소리/'ㄴ'/'ㄴㄴ'으로 발음

#### 오류 유형

- 음운 단위
	- 평음의 유기음화(거센소리화) : 갈치 → 칼치(X), 갈치(O)
	- 이중 모음의 단모음화 : 뭐더라 → 머더라(X), 뭐더라(O)
	- 중모음의 고모음화 : 그리고 → 그리구(X), 그리고(O)
- 단어 단위
	- 연음 오류 : 빛에 → 비세(X), 비체(O)
	- 동화 오류 : 강릉 → 강릉(X), 강능(O)
	- 된소리되기 오류 : 거꾸로 → 꺼꾸로(X), 거꾸로(O)
	- 첨가 오류 : 금요일 → 금뇨일(X), 그묘일(O)

### 문장

#### 문장의 종류와 문장 부호

- 종류
	- 평서, 의문, 감탄, 청유, 명령
- 문장부호
	- 마침표, 느낌표, 물음표, 쉼표
	- 큰따옴표(→ 직접인용, 말), 작은따옴표(→ 마음속 말, 생각)

#### 문장 성분

- 문장 : 문장 성분 + 종결 어미 + 문장 부호
	- 단어, 어절(→ 띄어쓰기), 구(→ 주술 관계 X), 절(→ 주술 관계 O)
- 주성분
	- 주어 : 누가/무엇이 → 서술어의 주체
	- 서술어 : 어떠하다(→ 형용사) / 어찌하다(→ 동사) / 무엇이다(→ 체언+서술격조사'-이다') → 주어의 상태·동작·성질 풀이
	- 보어 : '되다/아니다' 앞에서 보격 조사 '이/가'와 결합 → 서술어 보충
	- 목적어 : 무엇을 → 서술어의 대상
- 부속 성분
	- 관형어 : 체언을 수식 ⇒ 의존 명사 앞에 오는 경우 필수적
	- 부사어 : 주로 서술어를 수식 ⇒ 서술어의 자릿수에 따라 필수적 (두 자릿수 中 일부, 세 자릿수)
		- 한 자릿수 : 주+술
		- 두 자릿수 : 주+(목/부/보)+술
		- 세 자릿수 : 주+목+부+술
- 독립 성분
	- 독립어 ⇒ 감탄사, 호격 조사

#### 문장의 짜임

- 홑문장
	- 주-술 관계 하나
	- 홑문장의 분류
		- 한자리
			- 주어+서술어 ⇒ 무엇이+어찌하다/어떠하다 : 주어+용언
			- 주어+서술어 ⇒ 무엇이+무엇이다 : 주어+(체언+서술격조사'-이다')
		- 두자리
			- 주어+목적어+서술어 ⇒ 무엇이+무엇을+어찌하다
			- 주어+부사어+서술어 ⇒ 무엇이+무엇에+어떠하다/어찌하다
			- 주어+보어+서술어 ⇒ 무엇이+무엇이(가)+되다/아니다
		- 세자리
			- 주어+부사어+목적어+서술어 ⇒ 무엇이+무엇에게+무엇을+어찌하다
		- '어떠하다'(≒형용사) 서술어는 한자리, 두자리 中 부사어에만
- 겹문장
	- 주술 관계 둘 이상
	- 이어진문장
	- 안은문장

#### 각론

- 띄어 읽기
	- 주어부/서술어부 ⇒ 문장 시작에서 주어까지/주어 뒤부터 문장 끝까지
	- 의미 단위에 따라 어절/어구 단위로
	- 문장 부호에 따라 ⇒ 마침표,느낌표,물음표(⩔), 쉼표(∨), 글 끝에서는 띄어 읽기 X
- 흉내 내는 말(의성어,의태어) ⇒ 부사/부사어
- 꾸며 주는 말(관형어,부사어) ⇒ 관형어-체언, 부사어-용언

### 문단

#### 문단의 구조

- 여러 문장이 모여 하나의 중심 생각을 나타내는 글의 단위
	- 잘 드러난 문장 : 중심 문장
		- 중심 문장 지원 : 뒷받침 문장
- 여러 구조의 문단을 제시해 중심 문장이 반드시 문단 맨 앞이 아님을 지도
	- 두괄식, 미괄식, 양괄식, 무괄식 ; 무괄식은 간추리기 활동

#### 문단의 요건

- 통일성 : 의미적 연결 ; 하나의 중심 내용으로 통일
- 응집성 : 형식적 연결 ; 지시·접속 표현과 같은 담화 표지로 향상

#### 각론

- 지도 내용
	- 문단의 개념
	- 문단의 기능·역할
	- 중심·뒷받침 문장 관계
	- 문단의 형식

### 글

- 유창하게 읽기(읽기 유창성)
	- 자동성, 정확성
	- 표현성 ⇒ 어조, 강세, 속도, 억양 등의 표현 요소 활용 → 분위기 효과적으로 표현하기

## 문법

### 단어

#### 품사

- 2체계, 5기능, 9의미로 단어 분류
- 불변어
	- 체언(주·목·보)
		- 명사 : 의존 명사 → 관형어 필수, 띄어쓰기
		- 대명사 : 지시, 인칭
		- 수사
	- 수식언
		- 부사 : 용언, 문장 전체 수식
		- 관형사 : 체언 수식, 조사 X
	- 독립언 - 감탄사
	- 관계언 - 조사 : 체언 뒤, 서술격 조사(-이다) 가변어
- 가변어
	- 용언
		- 동사
		- 형용사
	- 서술격 조사
- 용언
	- 어간 + 어미(선어말, 어말), 어간 + 다 = 기본형
		- 시제·높임 기능
	- 용언의 활용. (⇒ 사례 보고 이름 매칭)
		- 규칙 활용
			- 기본형 : 어말, 어미 변화 X
			- 'ㄹ' 탈락 : 어간 끝의 'ㄹ'이 'ㄴ'으로 시작하는 어미 앞에서 탈락 (살다 ⊃ 살- + -는 → 사는)
			- 'ㅡ' 탈락 : 'ㅡ'가 '-아'/'-어'로 시작하는 어미 앞에서 탈락 (치르다 → 치르- + 어 → 치러)
		- 불규칙 활용
			- 어간만 바뀜
				- 'ㅅ' : '잇-' + '-어' → 이어 ; 어간 끝 'ㅅ'이 모음 어미 앞 탈락
				- 'ㅂ' : '돕-' + '-아' → 도와 ; ㅂ → ㅗ/ㅜ
				- 'ㄷ' : '걷-' + '-어' → 걸어 ; ㄷ → ㄹ
				- '르' : '흐르-' + '-어' → 흘러 ; 르 → ㄹㄹ
				- '우' : '푸-' + '-어' → 퍼 ; ㅜ 탈락
			- 어미만 바뀜
				- '여' : '일하-' + '-어' → 일하여 ; 어 → 여
				- '러' : '푸르-' + '-어' → 푸르러 ; '어' → '러'
			- 둘다 - 'ㅎ' : '파랗-' + '-아' → 파래

#### 국어사전에서 단어 찾기

- 활용
	- 가변어는 기본형을 찾는다 / 나머지는 기본형이 X (형태가 변하지 않으므로)
- 차례
	- 첫 자음 : (기본→쌍자음), ㄱ~ㅎ (ㄱ,ㄲ,ㄴ,ㄷ,ㄸ~)
	- 모음 : (기본→병서 ; 합자도 다시 순서 맞춰서), (ㅏ,ㅐ,ㅑ,…,ㅜ,ㅝ,ㅞ,ㅟ,…)
	- 받침 : (홑→쌍→겹), (ㄱ,ㄲ,ㄳ,ㄴ,…)

#### 동형이의어와 다의어

- 동형이의어 : 의미 간 유사성 X, 국어사전 뜻풀이 각각 (차다¹, 차다² …)
- 다의어 : 의미 간 유사성 O, 국어사전 중심 의미 → 주변 의미 (눈¹-「1」,「2」,「3」…)

#### 의미 관계

- 유의 관계
	- 항상 대체할 수 있지는 X ; 교체 검증을 통해 지도
- 반의 관계
	- 의미 자질 중 하나만 다름
	- 등급 : 중간 속성 O, 정도 부사 가능
	- 상보 : 중간 속성 X, 정도 부사 불가

	- 포함될 때 의미 관계 ; 상대적

#### 어휘 지도 (명칭, 장점)

- 도구적 관점
	- 국어사전 찾기 : 의미를 정확하게 이해
	- 맥락 활용 지도 : 낱말이 사용되는 상황 파악
- 인지적 관점
	- 어휘 자체가 인지적 능력 ; 어휘 사이 관련성, 배경 지식 형성한다
	- 의미 자질 분석 : 의미 관계, 개념 차이 파악
	- 의미 구조도 그리기 : 공통점·차이점 도식화 ; 차이점·유사점 인식
	- 의미 지도 그리기 : 하나의 주제 중심, 관련된 어휘 연결 ; 배경지식, 계층 위계 구조 이해
- 기타
	- 말놀이
	- 어휘망 그리기 : 의미 관계 그리기
	- 형태 분석하기 : 접두·접미, 어근 분석
	- 단어 연상하기 : 사진·그림으로 기억
		- 단일 단어
		- 여러 단어
	- 시각적 변별 : 비슷한 단어를 시각으로 구별

## 읽기

### 읽기 과정 모형

#### 상향식 과정 모형 (= 글 중심 모형)

- 의미 구성 = 각 언어 단위의 정확한 해독
- ∴ 읽기 지도 = 해독 지도(→ 의미를 정확히 이해하도록 하는 활동)
- 배경지식, 맥락 영향 설명 불가능 (무의미 단어 문제, 동형이의어 문제)

#### 하향식 과정 모형 (= 독자 중심 모형)

- 의미 구성 = 스키마를 바탕으로 한 독자의 예상·추론, 텍스트는 이를 확인하는 용도
- ∴ 읽기 지도 = 배경지식 활성화, 예측·추론과 같은 읽기 전략 지도
- 미숙한 독자, 배경지식에서 먼 글(=어려운 글), 무작위 단어 나열 문제
- 스키마(≒배경지식)
	- 구조화된 지식
	- 내용 스키마 : 내용 지식
	- 구조 스키마 : 구조·형식에 대한 지식
	- 언어 스키마 : 의미 단위 간의 관계

#### 상호작용 과정 모형

- 의미 구성 = 독해의 과정에서 상향식·하향식 언어 처리가 병렬적으로 작동
- ∴ 읽기 지도 = 상향·하향 절충
- 사전적 설명력을 가진 모형이 아니라 사후적 설명 도구가 될 위험성 (⇒ 오류 진단이 안 됨)

#### 교섭 과정 모형 (= 사회·문화 모형)

- 의미 = 독자나 텍스트 내부가 아니라 읽기 사건에서 의미가 생성(→ 상황 맥락(독자의 자세), 사회문화적 맥락(해석 관습) 영향받음)
- ∴ 읽기 지도 = 대화를 통해 새로운 의미 구성, 비판적·창의적 읽기

### 과정 중심 읽기 지도

- 읽기의 과정을 강조, 각 과정에서 필요한 기능·전략 지도
- cf) 결과 중심 읽기 지도 ⇒ 결과 강조
- 기능 : 무의식적 작용, 사실·추론·감상·창의·비판적 읽기
- 전략 : 의식적 작용, 전략 학습을 통해 기능으로 전이.(= 읽기 활동, 전·중·후로 나뉨)

#### 읽기 전 활동 전략.

- 읽는 목적 설정하기
	- 목적에 따라 글의 종류, 읽는 방법 달라짐
- 미리 보기
	- 제목·목차·머리말 등 미리 보고 배경지식 활성화
- 연상하기
	- 글 안 읽고 내용 떠올리기, 배경지식 활성화
- 예측하기 (cf. 추론하기)
	- 책에서 읽게 될 내용(책에 써있는) 추측하기 ↔ 책에 없는 내용 추론하기
- 배경지식, 내용정리
	- KWL (Know, Want, Learned)
		- 읽기 전체 과정에서 활용, H(How)를 읽기 후 활동에 더하기도
	- SQ3R (Survey, Question, Read, Recite, Review)
		- 훑어보고 → 질문 → 읽기 → 암송 → 다시 읽기
- 설문 조사
	- 배경지식 활성화

#### 읽는 중 활동 전략

- 구조 파악하기
	- 글의 구조 파악, 도해 조직자 사용
- 질문하기
	- 교사 질문 / 학생 질문 생성 전략
	- 사고 수준에 따른 질문 유형
		- 사실적 질문 : 글에 답이 O
		- 추론적 질문 : 글에 드러나지 X
		- 비판적 질문 : 판단·평가
		- 감상적 질문 : 정의적
	- 사고 유형에 따른 질문 유형
		- 폐쇄적 질문
			- 인지·기억적 질문 : 단순 재생
			- 수렴적 사고 질문 : 분석
		- 개방적 질문
			- 확산적 사고 질문 : 다양한 생각 자유롭게
			- 평가적 사고 질문 : 비판·판단
- 추론하기 (cf. 추론적 읽기 기능, 예측하기)
	- 글에 드러나지 않은 내용 추측하기 (cf. 예측하기)
	- 스키마 + 맥락의 실마리 활용
- 중심 내용 파악하기
	- 문단 중심 문장 → 글 중심 내용
- 협의하기
	- 교사-학생 간 / 학생 상호 / 자기 협의(능숙한 독자)
- 메모하기
	- 중요 부분 밑줄·괄호, 떠오른 생각 여백에 ⟨교재 수학,국어 기본이론서 p162⟩
- 점검하기
	- 초인지(상위인지)에서 나옴, 읽기 과정 통제·조절
		- └ 교사 : 읽기 과정 점검 질문 촉진

#### 읽은 후 활동 전략

- 요약하기
	- 규칙
		- 삭제 : 예시·세부정보 삭제
		- 선택 : 중요내용 선택
		- 대체 : 하위어 나열 → 상위어 대체
		- 구성 : 중심문장 없으면 구성
	- 조건
		- 글쓴이 생각·의도 왜곡 X
		- 자기 언어로 재구성
	- 요약문 요건 : 중심 생각과 근거 제시 · 문장 연결 자연스러움 · 글쓴이 생각·의도 왜곡 금지 · 자기 언어로 재구성 ※구멍 09-27
- 의미 지도 그리기 (cf, 도해 조직자)
	- 내용을 자유롭게 그림으로 표현, 반드시 글의 구조 반영할 필요 X (↔ 도해 조직자)
- 장르 바꾸기
	- 다른 장르로 (이야기 → 극, 일기 → 편지) ⟨교재 수학,국어 기본이론서 p164⟩
- 비판적 읽기 (기능 & 전략)
	- 준거 : 내용의 타당성(오류X, 일관성), 내용의 공정성(편향X), 자료의 신뢰성
- 창의적 읽기
	- 글쓴이 생각 + 배경지식 → 새로운 내용 구성
	- (ex. 해결책 찾기)

### 평가

- 선다형 평가 (객관식)
	- 4~5개 답지로 반응 제한 ; 읽기 과정보다 결과 평가 ⟨교재 수학,국어 기본이론서 p167⟩
- 빈칸 메우기법 (빈칸에 들어갈 내용)
	- 문맥 + 사전지식 이용 → 사실적 이해, 추론적 이해 평가
	- 정확단어(토씨) / 허용단어 채점
	- 장 : 과정평가, 타당, 신뢰도 ↑
	- 단 : 허용단어 채점시 객관성 문제
- 자유 회상 검사 (기억나는 내용 모두 쓰기)
	- 단서 없이 기억한 정보 회상 ; 결과 총체적 평가 ⟨교재 수학,국어 기본이론서 p168⟩
- 중요도 평정 (중요X … 매우 중요)
	- 글을 의미 단위(보통 문장)로 쪼개고 중요도 판단
- 오독 분석법 (소리내어 읽고~)
	- 음성적으로 잘못 읽는 부분 분석 ; 읽기 과정에 대한 구체적 정보
- 자율적 수정 (아, 이게 아니라~)
	- 학생이 스스로 고쳐 읽는 행위 분석 ; 상위인지적 독해 능력 평가
- 프로토콜 분석
	- 학생의 사고 구술을 녹화·녹음한 자료 ; 초인지 직접 확인

#### 내체표

- 지식·이해
	- 맥락, 갈래
- 과정·기능
	> ※정정 2026-09-21 — 앱 피드백 c1df5f38 「작품 읽기와 이해 / 해석과 감상 / 비평 / 창작 네 개」 · ⟨교육과정 별책5 p17 문학 내용 체계표⟩ 확인. 노트의 넷(해석·감상·비평·창작)은 아래 그대로 둔다
	- 해석 : 의미 추론
	- 감상 : 아름다움·감상
	- 비평 : 주관적 평가
	- 창작 : 문학 텍스트 생산 (⇒ 1~2학년군은 그림)

#### 작품의 맥락

- 작가 맥락 : 작가 배경, 창작 의도 등
- 독자 맥락 : 독자의 사전 지식, 발달 정도 등 ⇒ 수용 이론(독자에 따라 다양한 작품 해석) → 반응 중심 학습 모형
- 사회·문화적 맥락 : 역사적 사건, 문화적 배경 등
- 문학사적 맥락 : 문예 사조
- 상호 텍스트적 맥락 : 하나의 대상에 대한 서로 다른 두 글이 가지는 관련성

#### 문학 읽기 관점

- 내재적 : 작품 자체에 집중
- 외재적
	- 표현론적 : 작가에 집중
	- 수용론적 : 독자에 집중
	- 반영론적 : 사회·문화에 집중

### 서정문학

#### 시

##### 개괄

- 개념 : 함축적·운율성 언어
- 구성
	- 형식적 요소 : 행(줄), 연(의미 단위 ; 시적 대상과 화자의 태도·정서 변화에 따라 바뀜), 시어(시에 사용된 단어)(→ 운율, 함축, 회화성)
	- 내용적 요소 : 소재(작품의 내용적 재료), 제재(중심 소재), 주제(중심 생각)
	- 표현적 요소

##### 시의 내용

- 시적 화자 : 말하는 주체 (허구적 대리인, 시인 X)
	- 반드시 일치 X ※노트에서 「정서」·「태도」 두 줄만 중괄호로 묶어 걸린 주석이다(어조는 묶음 밖)
		- 정서 : 감정·생각
		- 태도 : 마음가짐·대응
	- 어조 : 말투 (by 종결어미)
- 시적 대상 : 화자가 주목하는 대상
- 시적 상황 : 화자의 상황
- 심상
	- 시어의 이미지
	- 단일 감각적 심상
		- 시각 : 색채·모양·동작·상태 (색모동상)
		- 후각, 청각, 촉각, 미각
	- 공감각적 심상 ⇒ 한 감각이 다른 감각으로 옮겨 감 ; 순서 판단 시 반드시 평서문화
		- (ex. 푸른 종소리 → 종소리가 푸르다 → 청각에서 시각)

##### 시의 형식

- 운율
	- 개념 : 운 + 율격 ; 말의 리듬
	- 형성
		- 운(같은 위치의 소리 반복) - 음위율
			- 두운(행 시작)
			- 각운(행 끝)
		- 율격(음성적 요소 반복)
			- 음수율 : 글자 수(= 음절 수) 반복
			- 음보율 : 음보(= 끊어 읽는 단위) 반복
		- 시어의 반복
		- 문장 구조의 반복
		- 음성 상징어 : 의성어 + 의태어
- 시상 전개
	- 시간적
		- 순행적
		- 역순행적
	- 수미상관 : 첫·마지막 부분 유사 ⇒ 운율, 형태적 안정감(균제미). 강조

##### 시의 표현

- 비유 : 어떤 대상(원관념)을 다른 대상(보조 관념)에 빗대어 표현 ⇒ 둘 사이 유사성 필수
	- 직유 : 직접 드러내어 표현, 연결어 O
	- 은유 : 같은 것처럼 표현, 연결어 X
	- 의인 : 사람이 아닌 것에 인격 부여
	- 활유 : 무생물에 생명 부여
- 상징 : 원관념 X, 보조 관념만 ⇒ 추상적 관념을 사물로 구체화 (유사성 X)
	- 개인적 : 시인 개인의 상징 (e.g. 산울림 - 고독)
	- 관습적 : 사회·문화적 상징 (e.g. 까치 - 손님)
	- 원형적 : 인류 보편적 상징 (e.g. 햇살 - 희망)
- 기타
	- 반어 : 화자 정서·태도와 표현이 반대 → 표현 자체는 말이 됨
	- 역설 : 말하고자 하는 것을 모순적으로 표현 → 표현 자체가 말이 안 됨
	- 대조 : 반대 속성의 대상 나란히
	- 대구 : 비슷한 문장 구조 연속
	- 객관적 상관물 : 정서·생각을 다른 대상을 끌어와 객관적으로 표현 ; 일치/불일치로 나뉨
	- 감정이입 : 객관적 상관물 중 일치

#### 소설

	- 회상
	- 제목

##### 구성 요소

- 인물
	- 유형
		- 역할
			- 주동 인물 — 주인공
			- 반동 인물 — 주인공과 대립
		- 전형성
			- 전형적 인물 — O
			- 개성적 인물 — X
		- 성격 변화
			- 평면적 인물 — X
			- 입체적 인물 — O
	- 제시 방법
		- 직접 제시 — 서술 or 등장인물이 성격 설명 (→ 오해X, 전개속도↑)
		- 간접 제시 — 설명X, 말·행동 (→ 생생, 독자가 판단)
- 사건
	- 핵심 사건
	- 주변 사건 — 생략 가능
- 갈등
	- 내적 갈등
	- 외적 갈등 — 인물, 사회, 자연, 운명 vs. 인물
- 배경 (분위기, 개연성, 주제 형상화, 암시)
	- 자연적 배경
		- 시간적 배경 — 시간 표지어 O
		- 공간적 배경
	- 사회적 배경

##### 구성(플롯) (⇒ 인과순으로 사건 배열 (cf. 스토리 - 시간순))

- 구성 단계
	- 발단 — 사건(갈등)의 실마리
	- 전개 — 사건의 본격적 진행, 갈등 발생
	- 위기 — 갈등 고조
	- 절정 — 갈등 최고조, 사건(갈등) '해결'의 실마리
	- 결말 — 사건(갈등) 해결과 마무리
- 구성 유형
	- 평면적 구성 — 시간순
	- 입체적 구성 — 시간순X
	- 액자식 구성 — 내부 + 외부이야기
- 복선 : 소설이나 희곡에서 앞으로 일어날 사건을 미리 넌지시 암시하는 장치 ※구멍 09-30
	- 예 : 「로미오와 줄리엣」 — 로미오가 「무덤 속 시체처럼」 보인다는 줄리엣의 말 ※구멍 09-30

#### 옛이야기 (= 전승문학)

- 분류
	- 신화 : 신 영웅
	- 전설 : 증거물에 엮여 실제같은
	- 민담 : 흥미 위주, 상상
- 옛이야기 vs. 동화
	- 인물 : 전형·평면 vs. 입체·개성
	- 배경 : 추상 vs. 구체
- 내용적 특징
	- 슬기·재치
	- 풍자·해학
	- 권선징악
	- 비판적
- 형식 특징 ⇒ 서술자적 논평 O
	- 관용적 표현
	- 대립과 반복
	- 진행 형식 (= 동화)
	- 형식 특징 모두 : 서술자적 논평 / 관용적 표현 / 대립과 반복 ※구멍 09-29(진행 형식은 동하 10-01 뺌)

	- 내용 요소 : 제목, 소개, 줄거리, 인상 깊은 부분, 평가

## 매체

### 교육과정

#### 내체표

- 과정·기능
	- 접근과 선택 : (5~6) 정보 검색하기
	- 해석과 평가 : (5~6) 매체 자료의 신뢰성 평가하기
	- 제작과 공유 : (5~6) 복합양식 매체 자료 제작·공유하기
	- 점검과 조정 : (3~4) 매체 소통 윤리

### 배경지식

- 매체와 매체 자료의 개념
	- 매체 : 소통의 매개물 (media)
	- 매체 자료 : 매체로 전달되는 내용 (contents)
- 매체의 유형과 특성
	- 음성·문자 언어 : 면대면 소통
	- 인쇄 매체 : 간접 소통
	- 대중 매체 : 대량 전달 방식의 소통 (매스컴)
	- 뉴미디어 : 쌍방향 소통
- 복합 양식성 : 하나의 매체에 여러 양식 복합적으로 결합 ⇒ 이해·활용 능력 : 복합양식 문식성(→ 디지털·미디어 활용 역량)

### 각론

- 검색하기 : 핵심어로 검색어 만드는 방법 지도
	- 인터넷 텍스트 특징 : 하이퍼텍스트 (비선형적)
	- 신뢰성 판단 : 출처 확인, 교차 검증
	- 필요한 정보 선택하는 기준 : 적합성, 최신성(→ 목적에 따라 우선순위 유동적), 신뢰성
- 신뢰성 평가하기
	- 기준
		- 제작자의 전문성·권위
		- 실제 근거 자료 기반인지
		- 근거 자료의 최신성, 정확성, 증빙 가능성
- 매체 소통 윤리 ⇒ 저작권 존중

### 성취기준

#### 1~2학년

##### 듣기·말하기 영역

[2국01-03] ‘상대의 말을 집중하여 듣고 **말차례**를 지키며 대화한다.’ — 이 성취기준은 구어 의사소통의 **상호 교섭성**을 인식하는 출발점으로, 대화 상황에서 상대의 말에 집중하여 그 내용을 이해하고 **순서를 교대**하며 구어 의사소통에 참여하는 기본 능력을 기르기 위해 설정하였다. 다음 말할 사람을 선택하여 부르거나, 고갯짓, 시선, 억양 등의 **말차례 교환 신호**를 활용하여 다음 사람이 알아차릴 수 있도록 하기를 학습한다.

올바른 구어 의사소통 습관을 형성할 수 있도록 **학습자의 삶과 연계하여** 지도한다. … 수업 시간뿐만 아니라 평소 학교생활이나 가정생활에서도 **말차례 지키기**와 바르고 고운 말 사용하기를 실천하도록 한다.

발표하기를 지도할 때는 학습자가 공적 발표 상황에 대해 부담감이나 불안감을 느낄 수 있으며 발표 수행 결과에 따라 **부정적인 자아 개념**을 형성할 수도 있다는 점에 유의하여, 동료 학습자의 발표에 대해 긍정적으로 반응하고 상호 격려하는 교실 문화를 조성하도록 한다.

##### 읽기 영역

[2국02-02] ‘의미가 잘 드러나도록 문장과 짧은 글을 **알맞게 띄어 읽는다**.’ — 글을 읽으면서 의미 단위를 인식하고 이에 맞게 띄어 읽는 것은 글의 의미를 정확하게 파악하고 **읽기 유창성**을 높이는 데 중요한 요소이다. 이 성취기준은 글을 **의미 단위에 알맞게 띄어 읽으며** 글의 의미를 파악하는 능력을 기르기 위해 설정하였다.

###### 띄어 읽기 넷 ([2국02-02] 해설)

- 글의 의미를 이해하기 위해 학습하는 띄어 읽기 — 각각 「… 띄어 읽기」

띄어 읽기 — **의미 단위에 따른 어구나 어절 단위 등으로** · **주어부와 서술어부 등을 단위로 하여** · **문장 부호에 따라 문장 단위를 인식하면서** · **쉬는 지점, 쉼의 길이에 유의하며**

1~2학년 읽기 — 알맞게 띄어 읽기는 함께 읽기와 혼자 읽은 후 짝과 함께 상호 점검하며 읽기 등의 방법을 활용한다. 이때 의미에 따라 여러 단위에서 띄어 읽기가 가능하므로 **기계적으로 띄어 읽기를 하지 않도록 유의한다**.

1~2학년 읽기 — 학습자가 한글 학습에 흥미를 느끼고 지속적으로 참여할 수 있도록 몸으로 문자를 표현하는 등의 **신체 놀이**, 첫음절이 같은 단어를 다양하게 떠올려 보는 **연상 놀이** 등을 활동 중심 수업과 연계하여 지도할 수 있다.

##### 쓰기 영역

1~2학년 쓰기 — 쓰기의 기초에 해당하는 내용은 읽기 영역의 ‘**읽기의 기초**’와 문법 영역의 ‘**한글의 기초와 국어 규범**’과 연계하여 지도할 수 있다.

1~2학년 쓰기 — 기초 한글 학습이 부족한 학습자를 위해서 문자 학습에 흥미를 느낄 수 있도록 신체 놀이, 연상 놀이, 질문 놀이 등 **놀이 중심**으로 교수·학습을 진행한다.

##### 문법 영역

1~2학년 문법 — 읽기 영역의 ‘읽기의 기초’, 쓰기 영역의 ‘쓰기의 기초’ 성취기준과 연계하여 ‘낱자, 글자, 단어, 문장’에 대한 순차적이고 체계적인 학습을 제공함으로써 입학 초기 **기초 문식성**을 지원하도록 한다.

1~2학년 문법 — 특히 단어를 다룰 때는 **소리와 표기가 일치하는 단어부터 소리와 표기가 일치하지 않는 단어로 학습 범위를 점차 확장하여**, 소리와 표기가 일치하지 않지만 자주 쓰이는 단어를 어법에 맞게 적고 바르게 읽을 수 있도록 지도한다.

1~2학년 문법 — 기초적인 한글 학습을 위해 문법을 지도할 때는 … 다양한 국어 자료를 바탕으로 **말놀이**나 신체 놀이, 수수께끼 등 흥미로운 활동을 계획하여, 학습자들의 수준이 다르더라도 소외되는 학습자 없이 문법 활동에 모두 적극적으로 참여할 수 있도록 지도한다.

##### 문학 영역

1~2학년 문학 — 낭송이나 낭독을 지도할 때는 **작품의 분위기나 느낌을 살려서 표현하는** 데에 중점을 두되, 같은 작품이라도 낭송하는 사람에 따라 개성 있는 느낌을 만들어 낼 수 있으므로 융통성을 가지고 **허용적인 분위기** 속에서 다양한 활동이 이루어지게 한다.

##### 매체 영역

[2국06-02] ‘일상의 경험과 생각을 글과 그림으로 표현한다.’ — 글, 그림(또는 사진, 이모티콘 등)을 활용하여 자신, 친구, 가족, 학교, 교실 등 친숙한 주제에 대해 표현하거나 **그림일기**를 작성해 보는 활동을 통해 자신의 경험과 생각을 다양한 방식으로 표현해 보는 데 중점을 둔다.

#### 3~4학년

##### 듣기·말하기 영역

[4국01-03] ‘상황에 적절한 **준언어·비언어적 표현**을 활용하여 듣고 말한다.’ — 이 성취기준은 구어 의사소통 상황에서 억양, 어조, 속도 등의 **준언어적 표현**과 표정, 시선, 몸동작, 자세 등의 **비언어적 표현**을 활용하여 의미를 효과적으로 전달하고 이해할 수 있는 능력을 기르기 위해 설정하였다.

###### 점검·조정 기능 (3~4학년 듣기·말하기 고려 사항)

- 듣기·말하기 과정과 전략에 대해 점검하고 조정하기 기능은 담화마다 무엇을 점검하는지로 지도한다(준언어·비언어적 표현이 효과적인지 등)
- 대화 : 예의에 어긋남이 없는지
- 발표 : 내용이 목적과 주제에 알맞은지
- 토의 : 제시한 의견이 주제에 적절하고 이유가 의견을 뒷받침하고 있는지

화자와 청자로서의 **효능감**을 가질 수 있도록 발표를 비롯한 다양한 담화 상황에 자신감 있게 참여하고 상대방과 긍정적으로 상호 작용할 수 있는 기회를 제공한다.

토의하기를 지도할 때는 토의 담화에 입문하는 단계임을 고려하여 토의 집단을 짝, 소집단, 대집단으로 서서히 확대하고 … **토의의 절차나 형식을 지나치게 강조하지 않으며, 학급 회의나 원탁회의 등을 활용하여** 학습자들이 자신의 생각을 자유롭게 나눌 수 있도록 한다.

##### 읽기 영역

[4국02-03] ‘질문을 활용하여 글을 예측하며 읽고 자신의 읽기 과정을 점검한다.’ — 이 성취기준은 글을 읽으며 글에 대한 질문을 만들고 이에 대한 답을 예측하면서 글을 읽는 **추론적 읽기** 능력을 기르기 위해 설정하였다.

[4국02-04] ‘글에 나타난 사실과 의견을 구분하고 필자와 자신의 의견을 비교한다.’ — 이 성취기준은 글에 나타난 사실과 의견을 구별하고 필자와 자신의 의견을 비교하면서 **필자의 의견을 일방적으로 수용하지 않고 글을 비판적으로 읽는 능력**을 기르기 위해 설정하였다.

[4국02-05] ‘글이나 자료의 출처가 믿을 만한지 판단한다.’ — 이 성취기준은 도서관이나 인터넷 등을 통해 글이나 자료를 찾아 읽을 때 출처의 **신뢰성**을 평가하며 읽고 믿을 만한 글이나 자료를 선별하는 능력을 기르기 위해 설정하였다.

##### 쓰기 영역

3~4학년 문법 — 언어가 의사소통 및 관계 형성의 수단임을 지도할 때에는, 언어의 다양한 기능 중 **지시적·정보적·친교적** 기능에 중점을 두어 일상생활에서 수집한 다양한 언어 사례를 분석해 봄으로써 …

### 교수·학습 및 평가

#### 교수·학습 방법

##### 듣기·말하기 영역

###### 실제적 수행법

- 실제나 그와 유사한 교실 환경에서 / 수용 가능한 화제에 대하여 / 담화 종류·역할·목적에 맞게 / 실제로 의사소통

##### 읽기 영역

‘읽기’ 영역 — 학습자의 수준, 관심, 흥미, 적성, 진로 등을 고려한 **자기 선택적 읽기** 활동을 안내하고 특히, 읽기 상황과 학습자의 읽기 수준을 고려하여 읽을거리의 난도나 분량 등을 결정하되, 짧고 쉬운 글이나 자료에서 **한 권 이상의 책 읽기**로 심화할 수 있도록 지도한다.

‘읽기’ 영역 — 읽기 과정에서 학습자가 스스로 질문을 생성하고 학습자 간의 발표, 대화, 토론 등의 과정을 통해 다른 독자들의 다양한 반응을 공유함으로써 학습자가 **개인적 읽기에 머무르지 않고 사회적 읽기에 참여하는 독자로 성장할** 수 있도록 지도한다.

##### 쓰기 영역

‘쓰기’ 영역 — 학습자가 생산한 글을 가능한 방법을 활용하여 발표하거나 출판하여 다양한 독자의 반응을 경험할 수 있도록 지원함으로써 학습자가 실제 삶의 맥락 속에서 **적극적인 필자**로 성장할 수 있도록 조력한다.

##### 문법 영역

‘문법’ 영역 — 문법 교육 내용이 **위계적**으로 반복·심화될 수 있도록 지도하되, 학습한 내용을 국어생활의 개선에 능동적으로 활용할 수 있도록 안내한다.

##### 문학 영역

‘문학’ 영역 — 제한된 분량의 교재, 한정된 시수 등으로 인해 수업 시간에는 작품을 일부만 발췌하여 읽는다 하더라도, **책 한 권 읽기나 작품 전체 읽기 활동 등을 통해 불완전한 문학 수업의 한계를 최소화할** 수 있게 한다.

#### 평가 방법

##### 듣기·말하기 영역

‘듣기·말하기’ 영역에서는 듣기와 말하기를 유기적으로 통합하여 **구어 의사소통에 적극적이고 협력적으로 참여하는 데 필요한 능력**과 **상대를 배려하고 공감하는 소통 태도**를 중점적으로 평가한다.

구어 의사소통 활동을 수행하는 과정을 평가하는 것이 중요하므로, **구체적이고 실제적인 담화 맥락**을 조성하여 **평가의 실제성**을 확보하고, **직접 평가**를 실시하도록 한다.

듣기·말하기 태도를 평가할 때는 … 자기 점검표나 성찰 일지를 활용하여 태도 변화를 지속적으로 점검하고 그 결과를 **누적하여 평가한다**.

##### 읽기 영역

‘읽기’ 영역에서는 교과서의 제재뿐 아니라 교과서 밖의 적절한 제재도 활용하여 **실제적인 읽기 능력과 읽기 태도**, **다양한 독서 경험** 등을 종합적으로 평가하는 데 중점을 둔다.

‘읽기’ 영역 — 읽기 태도나 습관 등을 평가할 때는 **일회적 평가**보다 **누적적 평가**를 실시하여 지속적으로 점검하고 학습자의 향상을 지원할 수 있도록 한다.

##### 쓰기 영역

‘쓰기’ 영역에서는 **상황 맥락과 사회·문화적 맥락을 고려하여 글을 쓰는 능력**과 **긍정적이고 적극적인 쓰기 태도**에 중점을 두어 평가한다.

‘쓰기’ 영역 — 태도와 같은 정의적 측면을 평가할 때는 **일회적 평가**보다 **누적적으로 평가하고** 지속적으로 피드백을 제공하여 쓰기 태도를 함양할 수 있도록 평가 도구를 구성한다.

‘쓰기’ 영역 — 학습자의 쓰기 과정과 결과물을 평가할 때는 **교사 평가 이외에 자기 평가, 동료 평가를 적극적으로 활용하여**, 학습자가 평가가 자신의 글쓰기 과정과 그 결과를 점검하고 보완할 수 있는 정보를 제공해 주는 학습 과정의 일부임을 이해하도록 유도한다.

##### 문법 영역

‘문법’ 영역에서는 문법 지식을 단순 암기하는 데 그치지 않고 국어의 구조와 문법의 작동 원리를 파악하고 이를 생활 속에 적용, 실천할 수 있도록 **문법 지식의 이해와 탐구 및 적용 능력**에 중점을 두어 평가한다.

‘문법’ 영역 — 태도와 같은 정의적 측면을 평가할 때는 자기 점검표나 성찰 보고서 등의 도구를 제공하여 지속적으로 **누적 평가**가 가능하도록 지원한다. **평가의 실제성**을 확보할 수 있도록 다양한 국어 자료를 활용해 과제를 설계한다.

##### 문학 영역

‘문학’ 영역의 평가는 **문학 영역의 지식을 이해하고 문학 작품을 해석, 감상, 비평하며 문학 작품을 창작할 수 있는 능력**에 중점을 두어 평가한다.

‘문학’ 영역 — 교과서에 일부만 수록된 작품에 한정하지 않고 **책 한 권 읽기나 작품 전체 읽기**에 바탕을 둔 평가 활동을 통해 긴 호흡으로 작품을 즐겨 읽는 태도를 형성하는 데 도움이 되는 평가를 기획한다.

##### 매체 영역

‘매체’ 영역에서는 상황 맥락과 사회·문화적 맥락을 고려하여 **매체를 수용하고 생산하는 능력**과 **능동적인 태도**에 중점을 두어 평가한다.
