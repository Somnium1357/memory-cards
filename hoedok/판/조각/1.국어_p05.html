3) 탈락 (음운의 수 줄어듬)

자음군 단순화
⇒음절의 끝소리에 오는 겹받침 중 하나가 탈락
첫째 자음 : 일반적. [넓], [밟] 포함
둘째 자음 : ㄺ,ㄻ,ㄿ, 단, 'ㄺ'+'ㄱ' → 'ㄺ'는 'ㄹ'로 발음
흙이 [흘기] 같은 연음 현상과 구분 (음운 수)
'ㅎ' 탈락 (후음 탈락)
⇒'ㅎ' + 모음 어미·접미 에서 'ㅎ' 탈락
받침의 'ㅎ' 음가 유지 X ⇒ 특히 받침의 'ㄶ' 구분
않는[안는] : 자음군 단순화
않은[아는] : 'ㅎ' 탈락, 연음
표기반영
'ㄹ' 탈락 : 솔+나무
'ㅡ' 탈락 : 잠그+아
동일 모음 탈락 : 가+아서

4) 첨가

'ㄴ' 첨가
⇒앞말이 자음으로 끝나고 뒷말이 'ㅣ,ㅑ,ㅕ,ㅛ,ㅠ'
물약[물략] : ㄴ첨가, 유음화. 두 번째 음절의 첫 ‘ㅇ’은 음가가 없으므로 유음화의 대상이 될 수 없다. (구멍 09-20)
사잇소리
⇒합성어에서 'ㅅ' 첨가, 된소리/'ㄴ'/'ㄴㄴ'으로 발음

2. 오류 유형

1) 음운 단위

평음의 유기음화 (거센소리화) : 갈치 → 칼치(X), 갈치(O)
이중 모음의 단모음화 : 뭐더라 → 머더라(X), 뭐더라(O)
중모음의 고모음화 : 그리고 → 그리구(X), 그리고(O)

2) 단어 단위

연음 오류 : 빛에 → 비세(X), 비체(O)
동화 오류 : 강릉 → 강릉(X), 강능(O)
된소리되기 오류 : 거꾸로 → 꺼꾸로(X), 거꾸로(O)
첨가 오류 : 금요일 → 금뇨일(X), 그묘일(O)

적용 시 고려 사항

1~2학년 문법 — 특히 단어를 다룰 때는 소리와 표기가 일치하는 단어부터 소리와 표기가 일치하지 않는 단어로 학습 범위를 점차 확장하여, 소리와 표기가 일치하지 않지만 자주 쓰이는 단어를 어법에 맞게 적고 바르게 읽을 수 있도록 지도한다.
