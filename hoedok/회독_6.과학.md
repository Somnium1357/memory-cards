### 순환 학습 모형 (5E, POE 모형)

- : 학생들이 발견·탐구하기 너무 어려운 개념 대상 ⇒ 교사·교과서에서 개념 제시
- 과학자의 장기적 탐구 과정 모델링 (탐구학습 ≒ 단기 → 다양 개념)
- 탐색 → 개념 도입 → 개념 적용 → 탐색·순환 (개념 적용X 사례)
	- 기본적 순환 학습 모형 단계
- +α : 순환 학습 모형 분류 : 서술적(그냥 기술) / 경험-귀추적(가설 선정만) / 가설-연역적(가설 검증까지)
	- (서술적 → 초등)
- 5E 모형 (Eng, Explo, Expla, Elab, Eval)
	- Engagement → Explore → Explanation → Elaborate → Evaluate
	- Engagement
		- 동기 유발 (⇒ 인지적 갈등 유발)
	- Explore
		- 교사 주도 X
		- 결과 예상
			- → 실험 검증
	- Explanation
		- 문제에 대한 답
			- 교사 설명, 개념 제시
	- Elaborate
		- 개념 정교화
			- 예시 찾기 등
			- 적용
	- Evaluate
		- 학생 평가
	- (→ 탐색 : Engagement~Explore / 개념 도입 : Explanation / 개념 적용 : Elaborate~Evaluate)
- POE 모형 (Pred, Obsrv, Expla) ≒ PEOE (E-Exp.)
	- Prediction → Observation → Explanation
	- Prediction
		- 학생들이 예상
			- + 정당한 까닭
		- 글로 쓰기 → 정교화
	- Observation
		- 관찰 결과 기록
	- Explanation
		- 예상과 관찰 사이 모순 해결
		- 근거 바탕 + 까닭
			- 추리 가능
