1. 배경지식

1) 소수의 개념

십진 분수 : 분모가 10ⁿ인 분수의 표현

2) 소수의 유형

순소수 : 정수부 = 0
대소수 : 정수부 ≠ 0
유한소수 : 0이 아닌 숫자가 유한 번 반복
무한소수 : 0이 아닌 숫자가 무한 번 반복
