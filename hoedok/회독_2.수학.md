## 수학의 가치와 특성

### 수학의 가치 (= 필요성)

- 실용, 도야, 심미, 문화

### 수학적 사고

- 귀납적 사고 (구체 → 일반)
	- 잠정적(≒ 개연적), 반드시 참은 아님
- 연역적 사고 (일반 → 구체)
	- 귀납으로 형성, 연역으로 구체. 반드시 참
- 유추적 사고 (구체 → 구체, by 유사성)
	- 잠정적
- 직관적/논리적 사고
	- 단계에 따라 논리적 or not
- 가역적 사고 (역방향 변화)
	- 거꾸로 풀기

### 수학적 지식의 형태와 특성

- 형태
	- 개념 : 결정적 속성의 명명
	- 원리 : 일반적인 성질
	- 법칙 : 보편적 규칙
- 특성
	- 추상화
	- 형식화
	- 이상화
	- 일반·특수화
	- 계통성
	- 논리·직관성
	- 실용성
	- 역동성

### 평면도형

#### 삼각형

- 배경지식
	- 삼각형의 종류
		- 각의 크기
			- 직각삼각형 - a²+b²=c² - 한각 직각
			- 예각삼각형 - a²+b²>c² - 세각 예각 → 한 각도 둔각 X
			- 둔각삼각형 - a²+b²<c² - 한각 둔각
		- 변의 길이
			- 부등변
			- 이등변
			- 정삼각형
	- 다각형 분류
		- 분할적 : A∩B=∅
		- 계층적 : A∩B≠∅
	- 필요·충분조건
		- 필요 : A는 B의 필요 → B이려면 A가 필요. → A⊃B
		- 충분 : A는 B의 충분 → A이면 B에게 충분. → A⊂B
		- 필충 : A=B. (= A⊂B, A⊃B)
- 각론
	- 변의 길이
		- 이등변 - 정의 : 두 변의 길이가 같은 삼각형(학교수학은 계층적 정의)

#### 사각형

- 배경지식
	- 여러 가지 사각형의 정의와 성질
		- 정의
			- 사다리꼴 : 적어도 한 쌍의 변이 평행
			- 평행사변형 : 마주보는 두 쌍의 변이 평행
			- 마름모 : 네 변의 길이가 같은
			- 직사각형 : 네 각이 모두 직각
			- 정사각형 : 네 각이 모두 직각, 네 변의 길이가 같은
		- 성질
			- 대각선
				- 이등분 → 평행사변형 (포함 사각형)
				- 수직이등분 → 마름모 (포함 사각형)
			- 이외 성질 : 자명하나, 변,각의 크기는 "마주보는"
				- (cf. 마름모가 아닌 연꼴 → 평행사변형 아님)
	- 여러 가지 사각형의 관계
		- 자명하게 기억.

- 핵심 각론
	- 직사각형과 정사각형
		- 정의 : 학문적 정의 그대로
		- 오개념 : 반례 지도
	- 여러 가지 사각형과 그 성질
		- 사다리꼴
			- 정의
		- 평행사변형

		- 마름모

		- 직사각형과 정사각형
			- 성질 + 지도 방법
		- (cf) "대각선" 용어는 지도 X, "마주 보는 꼭짓점끼리 이은 선"

#### 다각형

- 배경지식
	- 다각형과 정다각형의 정의
		- 다각형 : 선분으로만 둘러쌓인 도형
		- 정다각형 : 모든 변의 길이,각의 크기 같음
	- 볼록다각형과 오목다각형
		- 정의 → 도형 내부의 임의의 두 점 이은 선분 중 도형 밖을 지나는 선분이 있는가?
		- 특징 → 오목다각형 : 우각, 도형 밖의 대각선
	- 대각선
		- 정의 인접하지 않는 두 꼭짓점을 이은 선분
		- 다각형의 대각선 수 n(n-3)/2
		- 사각형의 종류에 따른 대각선의 특징 사각형 파트에서
		- 오각형 내각의 합 구하기
			- 연역적인 방법
				- 한 점에서 그을 수 있는 대각선 수
				- +1 하면 다각형을 나누는 삼각형의 수
				- ×180 = 내각의 합
				- ∴ n각형의 내각의 합 = {(n-3)+1}×180 = (n-2)×180°
- 핵심 각론
	- 다각형과 정다각형의 정의
		- "선분으로만 구성", "닫혀 있음"
		- (cf) 각(반직선,열려있음), 원(선분 X)
	- 대각선
		- 정의
		- 다각형의 대각선 수
		- 사각형의 종류에 따른 대각선의 특징
		- 대각선을 이용하여 팔각형의 모든 각의 합 구하기
	- 모양 만들기와 채우기
		- 같은 정다각형 ⇒ 한 각의 크기가 360°의 약수
			- 한 각의 크기 : (n-2)/n × 180

#### 원

	- 원의 성질
	- 원의 성질을 이용한 원의 중심 찾기
		- 서로 다른 두 현의 수직이등분선의 교점
		- 원에 내접하는 서로 다른 두 직각삼각형의 빗변의 교점
- 핵심 각론
	- 여러 가지 방법으로 원 만들기
		- 누름못, 자
	- 원의 구성요소 알아보기
		- 원의 지름, 원의 반지름, 원의 중심
		- 지도 방법
			- 누름못 이용 ⇒ "중심" 기반 정의
			- 종이접기 이용 ⇒ "지름" 기반 정의
	- 원의 성질
		- 성질 + 지도 방법

#### 변환

- 배경지식
	- 합동변환
		- 평행이동(밀기)
			- 학문 : 절대적 위치(좌표)
			- 학교 : 상대적 위치만 - 얼마나 이동했는지 알 수 없음
		- 대칭이동(뒤집기)
		- 회전이동(돌리기)
			- 학문수학 VS 학교수학
			- 학교수학 ⇒ 축·중심 지도하지 X
				- ∴ 위치에 대해 다루지 X
	- 닮음변환 → 비와 비율
	- 공간 감각
		- 의미 초등학교 도형 지도의 목적
		- 하위요인
			- 공간에서의 위치 지각 능력
				- 위치 변화에 대한 이해
			- 공간 관계에 대한 지각 능력
				- 돌리거나 뒤집어도 합동임의 이해
			- 시각적 기억 능력
				- 도형의 원래 모양
				- 가역적 사고 → 거꾸로 풀기
- 핵심 각론
	- 이동
		- 평면 도형의 이동
			- 생활 용어, 정의 X
				- 밀기
				- 뒤집기
				- 돌리기
		- 점의 이동 격자 사용, 위치와 방향
	- 합동
		- 도형의 합동의 의미 포개었을 때 완전히 겹쳐짐
		- 합동인 도형의 성질 대응변, 각 같음
			- 지도 : 포개보기, 자(변), 각도기(각)
	- 대칭
		- 선대칭 도형
			- 의미 한 직선을 중심으로 접으면 포개어짐
			- 성질 대응점을 이은 선분이 대칭축에 수직이등분됨
		- 점대칭 도형
			- 의미 한 점을 중심으로 180° 돌리면 포개어짐
			- 성질 대응점을 이은 선분이 대칭의 중심을 지나고, 그에 의해 이등분됨
		- (→ 대응각·변 당연히 같음.)

### 입체도형

#### 직육면체와 정육면체

- 배경지식
	- 입체도형
		- 다면체 모든 면이 평면으로 둘러싸인 입체도형
			- 성질 오일러 공식 (V-e+f=2)
			- 학교수학에서는 무정의로 사용
	- 직육면체와 정육면체의 정의
		- 육면체 : 6개의 다각형으로 둘러싸임
		- 직육면체
			- 모든 면이 수직 (학문)
			- 직사각형 6개 (학교)
		- 정육면체 - 정사각형 6개
- 핵심 각론
	- 직육면체와 정육면체
		- 정의 직육면체, 정육면체 포함 관계 명시적 지도 X
		- 구성요소 꼭짓점, 면, 모서리
		- 성질 밑면 : 임의로 한 쌍(마주보는) ⇒ 나머지 두 쌍은 옆면
		- 겨냥도와 전개도
			- 의미
				- 겨냥 : 보이지 않는 부분을 보이게 그린 것
				- 전개 : 입체도형을 모서리를 따라 잘라 펼쳐놓은 것(cf. 원기둥)
			- 그리는 방법
				- 겨냥
					- 평행, 길이성질 유지
					- 수직은 유지 X
				- 전개
					- 겹치는 면 X
					- 접었을 때 만나는 길이 같게
					- 같은 사각형은 같게

#### 각론

- 10이 되는 더하기와 빼기
	- 10의 보수 관계 이해, 받아올림·내림의 기초
	- ⊕ 덧셈 ⇒ 교환법칙 이해
- 더해서 10이 되는 두 수를 이용한 세 수의 덧셈
	- 순서대로 더한 값((a+b)+c)(→ (a+b)가 10이 아니도록 설정) 과 10이 되는 두 수를 먼저 더해 10을 만들고 나머지 한 수는 더한 값(a+(b+c))(→ (b+c)가 10이 되도록 설정) 이 같음
- (몇)+(몇) = (십몇), (십몇)-(몇) = (몇)
	- 덧셈 ⇒ 가산수, 피가산수를 분해, 더해서 10이 되는 수를 만듦(→ 결합법칙에 의해 결과 같음)
	- 뺄셈
		- 피감수를 분해 : 10에서 먼저 빼고, 나머지 더함 ⇒ 감가법
		- 감수를 분해 : 빼서 10을 만들고, 10에서 추가로 뺌 ⇒ 감감법

#### 받아올림·내림

- 계산 원리
	- 덧셈 : 자릿값에 의한 전개식으로 분해, 교환·결합법칙
	- 뺄셈 : 자릿값에 의한 전개식으로 분해, 교환·결합법칙 + 덧셈에 대한 곱셈의 분배법칙
- 조작 활동
	- 자릿값에 맞는 수 모형으로 나타내기 (덧-각각, 뺄-피감수), 같은 모형끼리 더하기/빼는 수만큼 덜어내기
	- 받아올림(더해서 10개 이상, 10개→1개), 받아내림(뺄 수 X, 1개→10개)의 의미가 드러나는 조작 활동
- 세로셈 표준 알고리즘
	- 세로셈으로 나타내고, 자리에 맞게 수 쓰고, 일의 자리부터, 각 자리끼리 더하기/빼기
	- 합≥10 이면 받아올림, 뺄 수 없으면 받아내림
- 오류 유형
	- 덧셈 : 받아올림 X/아래에 쓰는 오류 ⇒ 받아올림 이해 X ; 구체물 조작 활동
	- 뺄셈 : 받아내림 대신 큰 수 - 작은 수 ⇒ 자릿값, 받아내림 이해 X, 한 자리수 뺄셈 관성 ; 구체물 조작 활동

#### 곱셈구구와 한 자리 수 곱셈

- 배경지식
	- 교환법칙 : a×b = b×a
	- 결합법칙 : (a×b)×c = a×(b×c)
	- 분배법칙 : a×(b+c) = a×b + a×c
	- 항등원 : a×e = e×a = a, e=1
	- 0 : 동수누가에 의해 0×a = 0, 교환법칙에 의해 a×0 = 0
- 각론
	- 곱셈구구의 원리
		- 동수누가 : n씩 더하기
		- 규칙성 : 곱하는 수 1 늘어날 때마다 n 늘어남
	- 1단 곱셈구구
		- 항등원 이해
	- 0의 곱 (0×a = a×0 = 0)
	- 곱셈표
		- 곱셈의 교환법칙 이해

#### 곱하는 수가 한 자리 수인 곱셈 ⇒ 곱해지는 수 조작

- 배경지식
	- 배열 모델을 이용한 곱셈 해결 전략 (ex. 22×3)
		- 동수누가 : 22씩 세 번 더하기
		- 뛰어 세기 : 22, 44, 66으로 뛰어 세기
		- 수분할을 통한 부분곱 : 자릿값에 대한 전개식으로 분해, 분배법칙 적용하여 부분곱
			- 22×3 = (20+2)×3 = (20×3) + (2×3) = 60 + 6 = 66
- (몇십) × (몇)
	- 계산 원리
		- 곱해지는 수 몇십을 10×(몇)으로 바꾼 후 결합법칙
		- 20×3 = (10×2)×3 = 10×(2×3) = 10×6 = 60
		- 곱해지는 수 10배 → 결과 10배임을 이해
	- 알고리즘 → (몇)×(몇) 뒤에 0 ~ 세로셈 X
- (몇십몇) × (몇), (세 자리 수) × (한 자리 수)
	- 계산 원리
		- 곱해지는 수를 자릿값에 대한 전개식으로 분해한 뒤 분배법칙 적용
		- 33 × 2 = (30+3)×2 = (30×2) + (3×2) = 60 + 6 = 66
	- 알고리즘
		- 세로셈 부분곱 알고리즘 : 세로셈으로 나타내고 각 자리에 맞춰 수를 쓴(이하 세로셈 표현) 뒤 곱해지는 수 분해, 부분곱의 합
		- 세로셈 표준 알고리즘 : 세로셈 표현 뒤 곱해지는 수를 일의 자리부터 곱하고 결과 ≥ 10이면 바로 윗자리로 올림

#### 곱하는 수가 두 자리 수인 곱셈 ⇒ 곱하는 수 조작

- 곱하는 수가 (몇십)
	- 계산 원리
		- 곱하는 수 몇십을 10×(몇)으로 바꾼 후 교환법칙·결합법칙
		- 47 × 20 = 47 × (10 × 2) = 47 × (2 × 10) = (47 × 2) × 10 = 94 × 10 = 940
		- 곱하는 수 10배 → 결과 10배임을 이해
	- 알고리즘 → (곱해지는 수)×(몇) 뒤에 0 ~ 세로셈 X
- 곱하는 수가 (몇십몇)
	- 계산 원리
		- 곱하는 수를 자릿값에 대한 전개식으로 분해한 뒤 분배법칙 적용
		- 17 × 35 = 17 × (30+5) = (17 × 30) + (17 × 5) = 510 + 85 = 595
	- 알고리즘
		- 세로셈 부분곱 알고리즘 : 세로셈 표현 뒤 곱하는 수 분해, 부분곱의 합
		- 세로셈 표준 알고리즘 : 세로셈 표현 뒤 곱하는 수를 일의 자리부터 곱하고 결과 ≥ 10이면 바로 윗자리로 올림

#### 곱셈 오류 지도

- 자릿값 무시
	- 원인 : 자릿값 개념 형성 X
	- 지도 : 자릿값 의미 지도
- 자릿값 위치가 정확하지 않음
	- 지도 : 보조선 사용
- 올림 계산 X
	- 원인 : 자릿값 이해 X, 올림 처리 오개념
	- 지도 : 곱한 결과가 10 이상이면 바로 윗자리로 올리도록 지도

#### 나눗셈의 의미와 실생활 상황, 곱셈과 나눗셈의 관계

- 실생활 상황

#### 나누는 수가 한 자리인 나눗셈

- 배경 지식
	- 분배법칙 → 피제수 분해만 가능
	- 세로셈 알고리즘

		- 어림을 통한 잠정 몫 사용
- 피제수 (몇십)
	- 계산 원리

	- 알고리즘
		- (몇)÷(몇)에 0 붙임, 세로셈 X
- 피제수 (몇십몇)
	- 계산 원리
		- 피제수 분할 후 분배법칙
	- 알고리즘 : 세로셈 표준
	- 나머지 : 분수·소수 범위에서는 나머지 X, 몫 변화
- 이하 동일 내용 반복으로 생략
- 혼합 계산 → 5~6학년군, 계산 순서 지도

#### 배경지식

- 분수의 의미

	- 측정 : 전체 단위 등분해 보조 단위, 측정값 ; 연속 상황, 가분수 지도  * 분수 맥락에서 등분할 = 크기 뿐 아니라 모양도 같게 분할

	- 비율
	- 연산자
- 분수 지도 모델

### 분수의 덧셈·뺄셈

#### 분모가 같은 진분수의 덧셈·뺄셈

- (진분수) + (진분수)
	- 계산 원리 : 단위분수 변환 → 분배법칙의 역 (∵ 분모가 같은 분수 덧셈 = 단위분수 개수의 합)
		- e.g. 2/6 + 3/6 = 1/6 × 2 + 1/6 × 3 = 1/6 × (2+3) = (2+3)/6(→ 계산 알고리즘) = 5/6
- 받아올림 있는 (대분수) + (대분수)
	- 대분수는 항상 이 두 가지로 나뉨
		- 자연수 부분 / 진분수 부분으로 나누어 계산
			- 모델 : `1`이 되는 모델 등분할 X
		- 가분수로 바꾸어 계산
			- 모델 : 모든 영역을 분모로 등분할
- 유의점
	- 약분은 5~6학년군 내용이나 결과 기약분수 표현 강제 X
- 오류
	- 분모끼리, 분자끼리 더하는 오류
		- 원인 : 분모·분자 의미 이해 X, 영역 모델 1개 크기 = 1 이해 X
		- 인지적 갈등 : 어림 활용
		- 지도 : 알고리즘, 구체물 조작
	- 1을 분수로 잘못 바꾸는 오류
		- 원인 : 자연수 받아내림
		- 지도 : 1을 크기가 같은 분수 여럿으로

#### 분모가 다른 진분수의 덧셈·뺄셈

- (진분수) + (진분수)
	- 조작 활동 → 재귀적 분할
	- 통분 ⇒ 분수의 단위는 분모가 결정하므로 단위 통일
	- 공통분모 → LCM, 분모의 곱 등 방법 가능
- 유의점
	- 결과 약분 가능
- 오류
	- 분모끼리, 분자끼리 더하는 오류
		- 원인 : 분모·분자 의미 이해 X, 분모가 같은 분수의 덧셈 계산 방법 이해 X (cf. 동분모 오류 원인)
		- 이하는 동분모와 같음

### 분수의 곱셈

#### 곱셈 상황과 단위

- 분수의 곱셈 상황

#### (분수) × (자연수) ⇒ 동수누가

- 대분수 × 자연수

#### (자연수) × (분수)

- 비교
	- 자연수가 분모의 배수
		- 조작 : 자연수를 분모로 등분할 → 분자만큼
	- 자연수가 분모의 배수 X
		- 조작 : 자연수를 1로 분할 - 분모로 등분할

#### (분수) × (분수)

- (진분수) × (진분수) - 비율 상황 (4/5 × 2/3)
	- 조작 : 주차장 전체 넓이를 5로 나눈 것 중 4개 → 색칠한 부분을 3으로 나눈 것 중 2개 → 표시한 부분은 전체 5×3칸 중 4×2칸 → 4×2/5×3 = 8/15
		- [도식] 조작 세 단계 아래에 기준량이 각각 적혀 있다 — 「5로 나눈 것 중 4개」 아래 (기준 : 1), 「3으로 나눈 것 중 2개」 아래 (기준 : 4/5), 「5×3칸 중 4×2칸」 아래 (기준 : 1). 앞의 두 기준을 잇는 긴 선 위에 「단위의 재개념화」가 적혀 있다
- (진분수) × (진분수) - 넓이 상황 (4/5 × 2/3)
	- 조작 : 1칸의 넓이 = 1/5 × 1/3 = 1/15, 가로 4/5, 세로 2/3인 직사각형은 단위 넓이 가로 4칸, 세로 2칸 ; 4×2 = 8칸 → 1/15 × 8 = 8/15
	- (선수학습 : 단위분수의 곱셈)

#### (자연수) ÷ (자연수)

- 몫 < 1 : 등분제 상황으로 지도
- 몫 > 1
	- 등분제
		- 4÷3 = 3과 3/3 ÷ 3

#### (분수) ÷ (자연수)

- 분자가 제수의 배수 ⇒ 등분할하여 단위분수 → 갯수 나누기
- 분자가 제수의 배수 X ⇒ 분자가 제수의 배수가 되도록 분할 (재귀적 분할)
- 분수의 곱셈으로 나타내기
	- 이유 : m으로 나눈 것 중 하나 = m 등분한 것 중 1 = 1/m 이므로 b/a ÷ m은 b/a의 1/m배, 따라서 b/a ÷ m = b/a × 1/m
