## 생활환경과 지속 가능한 선택

### 생활자원

- 생활하는데 필요한 자원
	- 유형(= 물적) - 돈 등
	- 무형(= 인적) - 시간 등

#### 생활시간

- 종류
	- 생리적 (= 필수)
	- 노동 (= 의무) - 학교, 직업, 가사
	- 여가 (= 사회·문화)
- 관리
	- 목표 → 계획(→ 중요도, 긴급도 고려) → 실천 → 평가

#### 용돈

- 관리
	- 계획(용돈 예산서) → 실천(용돈 기입장) → 평가(용돈 결산서)

### 생활자원 관리, 재활용·재사용

- 성적고 ⇒ 생태감수성, 생태전환교육

#### 옷 관리

- 실천
	- 패스트 패션 : 순환속도 ↑
	- 슬로 패션 : 순환속도 ↓
- 정리 : 니트류는 개어서 보관, 방습(여름), 방충(겨울)

#### 식품 관리

- 보관
	- 상온 : 곡류·콩류, 열대과일, 감자·양파·고구마·마늘
	- 냉장고 : 상온 외. 달걀 뾰족한 부분 밑으로
- 기한
	- 유통기한 : 판매 가능 기한
	- 소비기한 : (적절한 보관 하) 섭취 가능 기한

#### 재사용·재활용

- 재사용 : 가공 X
- 재활용 : 가공 O
- 5R : Recycle, Reuse, Refuse, Reduce, Rot

### 식재료

- 성적고 : 오감 교육

#### 식품 표시

- 영양 성분 표시
	- 총 내용량당 열량
	- 총 내용량당 영양소 함량
	- 1일 영양 성분 기준치에 대한 비율
- 품질 인증 마크
	- 유기농 : 비료, 농약 X
	- 무농약 : 화학 비료 < 권장 시비량 1/3, 농약 X
	- 무항생제 : 항생제 X
	- 지리적 표시제 : 특정 지역
	- 우수 농산물 : 유해·위해 요소 X
	- 전통 식품 : 우수한 전통 식품
	- HACCP : 유통 전 과정 관리 → 안전성

#### 오감 교육

- 맛 - 단맛, 신맛, 짠맛, 쓴맛, 감칠맛 ⇒ 매운맛, 떫은맛은 맛 X (보조맛)

#### 친환경 식생활

	- 단위 유의 (t × km)

### 간단한 옷의 수선

#### 기초 바느질

- 시침질
	- 천 고정 목적 → 바느질선 살짝 밖에서, 본바느질 후 제거
	- 바늘땀 2~4cm, 간격 0.2~0.4cm
	- 핀 사용 가능
- 홈질
	- 바늘땀·간격 0.2~0.4cm
- 박음질
	- 튼튼, 모양 반듯
	- 앞면 간격 X, 뒷면 겹쳐짐
	- 한땀 뒤에서 꽂아 한땀 앞으로 뺀다
- 감침질
	- 실이 대각으로
	- 앞면은 거의 안보이게, 뒷면은 대각

#### 옷의 수선

- 단추 달기 ⇒ 옷과 단추 사이에 옷감 두께만큼 틈 필요 → 실기둥 만들기

### 간단한 생활용품 만들기

#### 바느질 도구

- 대바늘뜨기 : 대바늘 2개 (or 줄바늘) + 털실로 고리 모양 만들어 가며 떠 나감 (편물)
- 코바늘뜨기 : 코바늘 (끝 뾰족이 갈고리) + 털실로 고리 모양 만들어 가며 떠 나감 (편물)

#### 주머니 만들기

- 순서 : 준비 → 계획 → 제작 (본뜨기, 마름질, 바느질(→ 윗단 두번 접어내리기)) → 마무리

#### 대바늘뜨기

- 용어
	- 코 : 바늘로 만든 낱개의 고리
	- 단 : 고리들의 집합 (가로줄)
- 코 만들기 : 대바늘뜨기 시작
- 겉뜨기 (기호: |) : 실은 대바늘 뒤에, 오른쪽 대바늘을 왼쪽 대바늘 코 앞에서 뒤로, 오른쪽 대바늘에 시계 반대 방향으로 실 걸기
- 안뜨기 (기호: -) : 실은 대바늘 앞에, 오른쪽 대바늘을 왼쪽 대바늘 코 뒤에서 앞으로, 오른쪽 대바늘에 시계 반대 방향으로 실 걸기
- 코 마무리하기 : 마감
- 대바늘뜨기의 기본 조직
	- 원리
		- 앞면이 겉뜨기면 뒷면은 안뜨기, vice versa
		- 단이 끝날때마다 앞·뒷면을 뒤집어가며 뜨개질함
		- 조직도는 앞면 모양
	- 종류
		- 평편 뜨기 : 겉뜨기·안뜨기 한 단씩 교대 → 표면·이면 다름, 끝 말리는 컬업 현상 ⇒ 목도리 X
		- 고무편 뜨기 : 겉뜨기·안뜨기 코 단위 교대 ⇒ 세로 줄무늬, 가로 신축성
		- 펄편 뜨기 : 모든 단 겉or안뜨기 ⇒ 표면 = 이면, 세로 신축성

#### 코바늘뜨기

- 사슬뜨기 : 시작
- 짧은뜨기 : 기둥코 1 → 코 2개 → 2개 코 사이로 (1-2-2)
- 긴뜨기 : 기둥코 2 → 코 3개 → 3개 코 사이로 (2-3-3)
- 빼뜨기 : 마감
- 한길긴뜨기 : 기둥코 3 → 2개씩 2번 빼냄 (3-2-2)
