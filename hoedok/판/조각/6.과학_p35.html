과학 학습 이론

1. 구성주의

개념 : 지식은 학습자 내부에서 주체적으로 구성 (cf. 객관주의)
객관주의 vs. 구성주의
구성주의객관주의
학습자능동적 창조수동적 수용
교사안내·조력전달·지휘
방법협동·문제해결학습강의·암기
평가질적 : 교육 방법 평가양적 : 학습자 서열

2. 행동주의

개념 : 학습 = S-R-R 통한 행동 변화

3. 인지 발달 이론 (피아제)

개념 : 학습 = 인지 구조(도식)의 변화
과정

조절 : 도식 변화 O, 도식을 자극에 맞춤
평형 상태

불평형 상태= 인지적 갈등

4. 유의미 수용 학습 이론 (오슈벨)

개념
원리
점진적 분화 : 일반 → 특수 (하위적)
통합적 조정 : 새로운 개념이 이미 학습된 내용과 통합 (상위적, 병위적)
선행 조직자 ⇒ 학습 시작 전에 인지 구조 미리 설정
설명 조직자 : 관련 개념 X, 더 일반적 개념 제시
비교 조직자 : 관련 개념 O, 유사성·차이점 제시해 연결·분별

5. 지식의 구조 (브루너)

표현 양식
⇒학습 여부를 결정하는 요인(내용 무관) → 나선형 교육과정(같은 구조를 다른 양식으로)
활동 (E, Enactive)
영상 (I, Image)
상징 (S, Symbolic)
지식의 구조화 ⇒ 기본 개념들 상호 연관시키는 것 (e.g. 밀도 = 질량/부피) → 적절한 양식으로 제시
