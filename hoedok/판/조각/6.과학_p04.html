6) 개념 변화 학습 모형

⇒"오개념 변화"

조건

1)불만족 (dissatisfaction)
2)이해 가능한 개념 (intelligible)
3)타당함 (plausible)
4)활용 가능 (fruitful)

단계

개념 표현 :
사전 개념 조사 (=오개념)
↓
개념 재구성
명료화 : 오개념 명료화
인지적 갈등 유발 : 불만족 유발
개념 구성 : 이해 가능한 개념 구성
개념 평가 : 개념의 타당성 평가 (학생 성취 X)
↓
개념 응용 :
개념 활용 가능성
↓
개념 변화 검토 :
사전 개념 ↔ 새로운 개념 비교

오개념의 특징

현상 중심 사고 : 눈에 보이는 현상 (수증기 응결 → 사라짐)
상황 의존 : 다른 상황 → 다른 결과 (물 끓임 → 열/증발 → 수증기)
미분화 : 여러 개념 분화 X (무게·질량·밀도…)
제한 : 두드러지는 현상만 (솜 상자 vs 쇠 상자 ~ 열전도X, 느낌)
변화 중심 : 변화하는 것 중심 (등속 운동하는 물체엔 힘 O)
단순 인과 : 복잡한 인과를 단순화하기 (비눗방울 터지는 이유 → 단순 시간)
