5~6학년군 운동

1. 건강체력

1) 의미와 요소

요소 : 근력, 근지구력, 심폐지구력, 유연성 +α 신체 조성 (PAPS 비만)

2) 근력·근지구력

측정
윗몸 말아 올리기 (PAPS) : 반동 이용 X
악력 검사 (PAPS)
운동 : 스쾃, 런지, 플랭크
유의점 : 정확한 동작
유형
맨몸 : 난이도 ∝ 동작의 난이도, 반복 횟수, 지속 시간
중량 : 점진적 과부하
저항 밴드 : 신축성 밴드 이용
분류
등장성 수축 운동 : 근육 길이 변화 O
등척성 수축 운동 : 근육 길이 변화 X
호흡 : 힘 줄 때 날숨

3) 심폐지구력

측정 : 왕복 오래달리기 (PAPS)
운동 : 줄넘기 – 초보자는 가슴, 숙련자 배꼽
유의점 : 착지 시 무릎 구부리기
방법 : 난이도↑, 시간↑, 고강도 훈련 추가 (인터벌 트레이닝), 진전 상황 모니터링

4) 유연성

측정 : 앉아 윗몸 앞으로 굽히기 (PAPS)
유의점 : 반동X, 천천히 자연스럽게 호흡
운동 : 스트레칭 (정적 / 동적)
