문법 - 글과 담화

1. 의사소통과 관계 형성으로서의 언어

1) 언어의 본질

⇒의사소통, 관계 형성의 수단
특성
기호성 : 일정한 의미를 기호로 표현
자의성 : 의미와 기호 결합의 우연성
사회성
역사성
창조성
기능
지시적 기능
정보적 기능
친교적 기능
정서적 기능
명령적 기능
→ 맥락에 따라 기능이 바뀜
온라인 대화 : 문자 언어, 시·공간 무관, 준·비언어 표현 간접
면대면 대화 : 음성 언어, 동일 시·공간, 준·비언어 표현 직접

2) 언어의 맥락

의사소통의 배경·환경
상황 맥락 : 담화에 직접적인 영향
사회·문화적 맥락 : 담화에 간접적인 영향

2. 높임 표현

1. 종류

1)주체 높임
⇒주어를 높임 (-께서, -시, 어휘)
2)객체 높임
⇒목적어, 부사어 높임 (-께, 어휘)
3)상대 높임
격식
하십시오 ⇒ 윗사람
하오 ⇒ 비슷
하게 ⇒ 비슷, 아랫사람 존중
해라 ⇒ 아랫사람 하대
비격식
해요 ⇒ 높이는 상황
해 ⇒ 높이기 X

2. 사용 방식

관계 : 나이, 지위, 친소
장면 : 공식 / 비공식
