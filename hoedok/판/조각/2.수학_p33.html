4. (분수) × (분수)

1) (진분수) × (진분수) - 비율 상황 (4/5 × 2/3)

조작 : 주차장 전체 넓이를 5로 나눈 것 중 4개 → 색칠한 부분을 3으로 나눈 것 중 2개 → 표시한 부분은 전체 5×3칸 중 4×2칸 → 4×2/5×3 = 8/15
조작 세 단계 아래에 기준량이 각각 적혀 있다 — 「5로 나눈 것 중 4개」 아래 (기준 : 1), 「3으로 나눈 것 중 2개」 아래 (기준 : 4/5), 「5×3칸 중 4×2칸」 아래 (기준 : 1). 앞의 두 기준을 잇는 긴 선 위에 「단위의 재개념화」가 적혀 있다

2) (진분수) × (진분수) - 넓이 상황 (4/5 × 2/3)

조작 : 1칸의 넓이 = 1/5 × 1/3 = 1/15, 가로 4/5, 세로 2/3인 직사각형은 단위 넓이 가로 4칸, 세로 2칸 ; 4×2 = 8칸 → 1/15 × 8 = 8/15
(선수학습 : 단위분수의 곱셈)
