1.국어

문학

옛이야기의 내용 특징 · 전승 특성 (2015 A 국어 3번)
옛이야기 : 입에서 입으로 전해지는 이야기 ; 입말로 구비전승 ⇒ 전승문학
민중들의 꿈과 소망, 한(恨)을 이야기함
만든 사람 : 땀 흘려 일하는 백성 (돈·권력·힘 없는 약자)
민중의 욕망을 충족하는 방향으로 이야기가 만들어짐
가진 자보다 못 가진 자가 더 꾀바르게 그려짐 ⇒ 한풀이 역할
다른 내용 특징 : 슬기와 재치, 풍자와 해학, 운명에 대한 믿음, 권선징악, 비현실적인 내용
전승 과정의 구술성
글이 아닌 입말로 전해짐
이야기 내용이 누락되거나 추가되는 경우 있음
시어의 음악성 (2023 A 국어 3번)
시어 : 일상 언어와 구별 ; 사실 전달보다 정서 표현 기능
시어의 특성
음악성 : 시어를 통해 운율을 나타내는 특성
음절 수 반복
시어 반복
문장 구조 반복
(e.g. 권태응 「감자꽃」 「자주 꽃 핀 건 자주 감자 / 파 보나 마나 자주 감자」)
회화성 : 시어를 통해 이미지(= 심상)를 형성하는 특성 (e.g. 「으르렁 드르렁」 아버지 코 고는 소리)
함축성 : 함축적 의미를 가지는 특성 ; 다의적·암시적·상징적
일상 언어 : 지시적 기능 ⇒ 정확성 추구
기출 장면 : 「귀뚤귀뚤」, 「우리 우리」 반복 ⇒ 음악성

문법

한글 맞춤법 총칙 : 「소리대로 적되 어법에 맞도록 함을 원칙으로 한다」 (2016 A 국어 3번)
교육과정 : [9국04-06](중학교) 성취기준 해설에 실린 문장
1~2학년 지도 순서
소리와 표기가 일치하는 단어
소리와 표기가 일치하지 않지만 자주 쓰이는 단어를 어법에 맞게 적기
기출 장면 : 독서 감상문의 「뵈요」 ; 총칙은 배경, 정답은 준말 조항
표기 원리 : 「ㅚ」로 끝난 어간 + 「-어」가 「ㅙ」로 줄면 준 대로 적음 (한글 맞춤법 제35항 붙임 2)
「뵈-」 뒤에 「요」 바로 못 붙음 ⇒ 「-어」 넣어 「뵈어요」, 줄이면 「봬요」
채점 키워드 : 「줄여 쓴다(줄어든다)」
복합어 : 단일어가 아닌 단어 (2017 A 국어 2번)
단일어 : 하나의 어근으로만 이루어진 단어
어근 + 어근 = 합성어 (e.g. 밤낮, 새해, 배부르다, 힘쓰다)
어근 + 접사 = 파생어 (e.g. 덧신, 맨손, 먹이, 믿음, 삶, 샛노랗다, 공부하다)
어근 : 낱말의 실질적인 의미를 나타내는 부분
접사 : 어근에 붙어 뜻을 더하거나 품사를 바꾸는 부분
기출 장면 : 「삶」, 「믿음」, 「먹이」, 「덧신」, 「맨손」 : 파생어
대비 : 「밤낮」, 「새해」 : 합성어
단어의 짜임 : 2015 개정은 초등 성취기준 ; 2022 개정은 중학교 [9국04-02]로 이동

기초 문식성

음절의 끝소리 규칙(평파열음화) : 음절의 끝소리가 대표음 ㄱ, ㄴ, ㄷ, ㄹ, ㅁ, ㅂ, ㅇ으로만 발음 (2025 A 국어 1번)
(e.g. 밖[박], 부엌[부억], 빗[빋], 낮[낟], 꽃[꼳], 밭[받], 잎[입])
기출 장면 : 대표음별 단어 묶음
[ㄱ] : 부엌[부억], 꺾다[꺽따]
[ㄷ] : 빗[빋], 낫[낟], 쫓다[쫃따], 붙다[붇따], 있다[읻따]
[ㅂ] : 무릎[무릅], 덮다[덥따]
구분 : 자음군 단순화 : 겹받침 중 하나 탈락
(e.g. 읽다[익따], 밟다[밥따], 없다[업따])

쓰기

쓰기 과제의 실제성 (2025 A 국어 3번)
실제성 : 작문 학습 활동이 교실 밖 학습자들의 실제 작문 활동을 반영하는가의 문제
작문의 주제, 목적, 예상 독자를 학습 활동에 구체적으로 구현해야 함
교육과정 쓰기 교수·학습 방법 : 실제로 글을 쓰는 활동 강조
발표·출판 ⇒ 다양한 독자의 반응 경험
실제 삶의 맥락 속 적극적인 필자로 성장
실제성 높이기 : 상황 맥락 구체화
상황 맥락 : 목적, 주제, 독자, 글쓴이의 입장, 매체 등 글 쓰는 상황에 직접 관여하는 맥락
기출 장면 : 「우리 문화재를 보호하자는 주제로 제안하는 글 쓰기」를 「교장 선생님께 제안하는 편지 써서 전달하기」로 수정
실제 독자 : 교장 선생님 (수정 전엔 독자 없음)
매체 : 편지 (수정 전엔 매체 없음)
삶의 문제인 주제 : 우리 학교의 개선해야 할 점 (수정 전 문화재 보호 = 학생 삶과 거리)
채점 키워드 : 독자, 주제, 매체 중 2
쓰기 불안(writing apprehension) : 쓰기 상황을 두려워하고 피하려는 정의적 경향 (2025 A 국어 3번)
기출 장면 : 관찰 기록 「쓰기에 관심이 없는 것인지, 쓰기 불안이 높은 것인지 불분명」
쓰기 흥미 : 쓰기에 대해 가지는 관심과 선호도 (관심 없음 쪽)
정의적 측면 평가 : 일회적 평가보다 누적적으로 평가 (같은 물음의 정답)
같은 문항의 다른 정의적 요인 : 쓰기 효능감 : 쓰기를 성공적으로 수행할 수 있다는 기대와 믿음
설명하는 글 : 정보성 높게 요구되는 장르 (2026 A 국어 2번)
자기 표현적 글(경험한 일, 편지)과 차이
기출 장면 : 「선생님, 쓸 말이 없어요」
원인 : 내용 지식(화제 지식) 부족
「어떻게」가 아닌 「무엇을」 쓸 것인가의 어려움 ⇒ 브레인스토밍만으론 내용 생성 어려움
쓰기 지식의 종류
내용 지식(화제 지식) : 필자가 화제와 관련하여 알고 있는 지식
담화 지식 : 언어 체계 및 언어 표현 맥락에 대한 지식 (맞춤법, 독자, 장르 지식 포함)

읽기

바렛(Barrett)의 읽기 기능 수준 (2026 A 국어 1번)
축어적 재인 및 회상 : 세부 내용 재인 및 회상, 줄거리 재인 및 회상

3.영어

기능별 언어 지도

읽기 단계 — 텍스트를 읽는 단계(읽기 중) (2015 B 영어 11번 · 2025 A 영어 5번)
교사의 시범 읽기(teacher read-aloud) : 교사가 텍스트를 소리 내어 천천히 읽어 줌
함께 읽기(shared reading) : 빅북(big book)이나 화면 · 교사가 포인터로 낱말 하나씩 가리키며 소리 내어 읽으면 학생도 함께 읽기
소리 내어 읽기 : 짝 또는 전체로 읽기 연습
paired reading : 짝 읽기 · 두 명이 짝 이루어 함께 읽기
choral reading : 합창 읽기 · 전체 학생이 운율에 맞추어 함께 읽기
guided reading : 유도 읽기 · 학생 스스로 텍스트 읽기 · 교사는 관찰하며 도움
independent reading (SSR) : 독립 읽기 · 마지막 단계
교사 도움 없이 책이나 글을 자발적으로 읽기
소리 내지 않고 읽는 단계 ⇒ 묵독(sustained silent reading, SSR)이라고도
story map (2020 A 영어 10번)
이야기의 구조와 흐름을 시각화한 그래픽 조직자
주요 사건 구조화 · 줄거리 요약 돕는 스캐폴딩 역할
기출 장면 : 읽기 중 단계 · 「The Giving Tree」 한 번 더 읽으며 활동지 빈칸에 알맞은 문장 채우기 ("Let's make a story map.")
같은 결의 읽기 중 활동
의미망(semantic map) 채우며 읽기
글의 구조를 도식화한 트리(tree) 완성하기
낱말 분류하기 → 새 낱말 읽기 (2023 A 영어 5번)
기출 장면 : 강 교사
낱말 카드를 철자 보고 두 묶음으로 나누기
-at 묶음 : bat · cat · hat · mat ⇒ [-æt]
-ate 묶음 : gate · late · mate · skate ⇒ [-eɪt]
"It starts like 'up'" ⇒ 새 낱말 update 읽게 함
활동 까닭 : 철자 패턴에 따른 소리 규칙 발견 → 새 낱말 읽기에 적용
음절 구성 : onset(어두자음군) + rime(각운)
강 교사 : rime이 같은 낱말 선정 (e.g. bat · cat)
안 교사 : onset이 같은 낱말 선정 (e.g. big · bear · ball)
word family : 같은 rime 공유해 한 묶음으로 가르치는 낱말 무리 (e.g. -at의 bat · cat · hat · mat)
analogy(유추에 의한 읽기) : 이미 아는 낱말의 철자 덩어리 빌려 처음 보는 낱말 읽기 (e.g. up + gate ⇒ update)
익힌 철자–소리 대응 규칙 활용 ⇒ 파닉스 지식으로 해독
language frames (2022 A 영어 5번)
뒤에 할 의사소통 과업에 필요한 표현과 기대 결과를 미리 보여 주는 언어 틀
제시 기법 : modeling(모델링) — 수행할 과제·사용할 언어 형태의 전형적 예를 분명히 보여 주기
기출 장면 : 교사가 손 인형 Froggie와 대화 ("What do you want to be?" · "I want to be a singer.")
학생 : 과업에 필요한 표현 + 활동의 예상 결과 알게 됨

요소별 언어 지도

형태 초점의 시점 — Form-Focused Instruction (2024 A 영어 5번)
Focus on Form(Long) : 수업 초점은 의미·의사소통 · 부수적으로 언어 형태를 맥락 속에서 의식시킴
preemptive : 오류 나기 전 가르칠 형태에 미리 주의 돌리기
PPP식 : 가르칠 언어 형태를 미리 선정
기출 장면 : 과업 시작 때 "By the way, don't forget to use 'ate', 'bought', and 'saw' when you describe your pictures." ⇒ 불규칙 과거형 오류 예방
reactive : 의사소통 우선 · 필요할 때만(e.g. 오류 났을 때) 잠깐 형태로 주의 · Long이 제안
기출 장면 : 목표 형태(불규칙 과거형) 오류 see는 고쳐 줌 · 무관한 관사 오류(He played a piano.)는 안 고침
원문 : "Instead of teaching a long list of grammatical constructions in a preemptive PPP way, Long (2007) proposed an essentially reactive approach, whereby learners are primarily engaged in communication with only a brief digression to grammar when necessary (e.g., when learners commit errors)."

언어 습득 이론

private speech — Vygotsky (2024 A 영어 5번)
혼잣말 · 개인적 대화
단순한 자기중심적 대화(egocentric speech) X
목표 달성 전략에 따라 자기 행동을 결정하는 데 도움
계획 세우고 문제 풀기 위한 지적 적응 수단
어려운 과제 만나면 증가
나이 들며 내적 언어(inner speech)와 사회적 언어(social speech)로 나뉨
기출 장면 : S6가 교사–S5 대화 듣다 "음…, buy의 과거가 buyed가 아니고 bought이구나"
혼잣말로 오류 스스로 수정 ⇒ 과잉 일반화된 문법 지식 재구조화(restructuring)

교수법

content-based instruction(CBI) (2024 A 영어 4번)
교과 내용 학습 + 언어 학습 통합
기출 장면 : 과학 시간에 배운 동물을 영어 활동 소재로 ⇒ 타 교과 학습 내용을 영어 학습에 통합
