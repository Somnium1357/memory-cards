2. 국어사전에서 단어 찾기

1) 활용

⇒가변어는 기본형을 찾는다 / 나머지는 기본형이 X (형태가 변하지 않으므로)

2) 차례

첫 자음 : (기본→쌍자음), ㄱ~ㅎ (ㄱ,ㄲ,ㄴ,ㄷ,ㄸ~)
모음 : (기본→병서 ; 합자도 다시 순서 맞춰서), (ㅏ,ㅐ,ㅑ,…,ㅜ,ㅝ,ㅞ,ㅟ,…)
받침 : (홑→쌍→겹), (ㄱ,ㄲ,ㄳ,ㄴ,…)

3. 동형이의어와 다의어

동형이의어 : 의미 간 유사성 X, 국어사전 뜻풀이 각각 (차다¹, 차다² …)
다의어 : 의미 간 유사성 O, 국어사전 중심 의미 → 주변 의미 (눈¹-「1」,「2」,「3」…)

4. 의미 관계

1) 유의 관계

⇒항상 대체할 수 있지는 X ; 교체 검증을 통해 지도

2) 반의 관계

⇒의미 자질 중 하나만 다름
등급 : 중간 속성 O, 정도 부사 가능
상보 : 중간 속성 X, 정도 부사 불가
관계 : (대체로) 정도 부사 불가. 'X가 A이면 Y가 B이다' 성립

3) 상하 관계

⇒포함될 때 의미 관계 ; 상대적

5. 어휘 지도 (명칭, 장점)

1) 도구적 관점

국어사전 찾기 : 의미를 정확하게 이해
맥락 활용 지도 : 낱말이 사용되는 상황 파악

2) 인지적 관점

⇒어휘 자체가 인지적 능력 ; 어휘 사이 관련성, 배경 지식 형성한다
의미 자질 분석 : 의미 관계, 개념 차이 파악
의미 구조도 그리기 : 공통점·차이점 도식화 ; 차이점·유사점 인식
의미 지도 그리기 : 하나의 주제 중심, 관련된 어휘 연결 ; 배경지식, 계층 위계 구조 이해

단어 연상하기 : 사진·그림으로 기억
