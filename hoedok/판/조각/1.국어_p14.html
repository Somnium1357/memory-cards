읽기 - 읽기 과정 모형

1. 상향식 과정 모형 (= 글 중심 모형)

⇒의미 구성= 각 언어 단위의 정확한 해독
∴읽기 지도= 해독 지도
의미를 정확히 이해하도록 하는 활동
⇒배경지식, 맥락 영향 설명 불가능 (무의미 단어 문제, 동형이의어 문제)

2. 하향식 과정 모형 (= 독자 중심 모형)

⇒의미 구성= 스키마를 바탕으로 한 독자의 예상·추론, 텍스트는 이를 확인하는 용도
∴읽기 지도= 배경지식 활성화, 예측·추론과 같은 읽기 전략 지도
⇒미숙한 독자, 배경지식에서 먼 글 (=어려운 글), 무작위 단어 나열 문제
스키마 (≒배경지식)
⇒구조화된 지식
내용 스키마 : 내용 지식
구조 스키마 : 구조·형식에 대한 지식
언어 스키마 : 의미 단위 간의 관계

3. 상호작용 과정 모형

⇒의미 구성= 독해의 과정에서 상향식·하향식 언어 처리가 병렬적으로 작동
∴읽기 지도= 상향·하향 절충
⇒사전적 설명력을 가진 모형이 아니라 사후적 설명 도구가 될 위험성 (⇒ 오류 진단이 안 됨)

4. 교섭 과정 모형 (= 사회·문화 모형)

⇒의미= 독자나 텍스트 내부가 아니라 읽기 사건에서 의미가 생성
상황 맥락 (독자의 자세), 사회문화적 맥락 (해석 관습) 영향받음
∴읽기 지도= 대화를 통해 새로운 의미 구성, 비판적·창의적 읽기
