5~6학년군 스포츠 - 기술형 스포츠 유형별 활동

9. 투기형 (태권도)

1) 기본 기술

지르기
얼굴 지르기 : 얼굴 향해
몸통 지르기 : 명치 향해
아래 지르기 : 단전 향해
차기
앞차기 : 앞축으로
옆차기 : 발날로
돌려 차기 : 발등으로
막기
얼굴 막기 : 손목 이마 앞
몸통 막기 : 팔 밖 → 안, 어깨높이
아래 막기 : 팔 위 → 아래, 아랫배 밑

2) 품새

⇒혼자, 품새 선 따라 연습

3) 약속 겨루기

사전에 약속된 공격·방어 동작 연습하는 겨루기
유의점 : 정해진 동작 외 위험한 동작 X

4) 태권도 겨루기

단계 : 차려 → 경례 → 겨루기 준비 → 시작 → 경기 후 인사

10. 투기형 (씨름)

1) 기본 기술

손기술
앞무릎 치기 : 오른손 → 오른 무릎, 오른다리·무게중심 앞
뒷무릎 치기 : 오른손 → 왼무릎, 왼다리 앞/무게중심 뒤
다리 기술
안다리 걸기 : 오른다리 → 왼다리 (안쪽), 왼다리 가까울때
밭다리 걸기 : 오른다리 → 오른다리 (바깥쪽), 오른다리 가까울때
허리 기술
엉덩배지기 : 엉덩이 왼쪽을 상대 다리 사이로
들배지기 : 샅바 잡고 들고 몸 시계방향

2) 경기 순서

경례 → 선수 앉아 → 샅바 잡아 → 일어서서 준비 → 경기 시작 → 경기 후 인사
＊제한시간 내 승부 X → 가벼운 사람 승

3) 연습 활동

⇒악력, 하체 힘 기르기
