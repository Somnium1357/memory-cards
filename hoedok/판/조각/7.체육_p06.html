8. 이해 중심 게임 모형 (⟺ 기능 중심 게임 모형)

⇒전술 > 기술, 왜 > 어떻게
게임 먼저 → 전술·기능 필요성 이해 ; 비슷한 게임 = 비슷한 전술이므로 유사한 전략 사용

단계

게임 소개소개
→
게임 이해규칙
→
전술 이해간단한 게임
→
의사 결정
→
기술 연습기능
→
실제 게임 수행실제 게임
∴흐름을 축약하면 게임(변형) → 기능 → 게임(실제)
시간 배분을 게임 중심으로
