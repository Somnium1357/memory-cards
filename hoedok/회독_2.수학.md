## 수학의 가치와 특성

### 수학의 가치 (= 필요성)

- 실용, 도야, 심미, 문화

### 수학적 사고

- 귀납적 사고 (구체 → 일반)
	- 잠정적(≒ 개연적), 반드시 참은 아님
- 연역적 사고 (일반 → 구체)
	- 귀납으로 형성, 연역으로 구체. 반드시 참
- 유추적 사고 (구체 → 구체, by 유사성)
	- 잠정적
- 직관적/논리적 사고
	- 단계에 따라 논리적 or not
- 가역적 사고 (역방향 변화)
	- 거꾸로 풀기

### 수학적 지식의 형태와 특성

- 형태
	- 개념 : 결정적 속성의 명명
	- 원리 : 일반적인 성질
	- 법칙 : 보편적 규칙
- 특성
	- 추상화
	- 형식화
	- 이상화
	- 일반·특수화
	- 계통성
	- 논리·직관성
	- 실용성
	- 역동성

## 수학 학습 이론

### 스켐프

#### 도구적 이해

- 규칙이나 공식의 적용 방법은 알지만 이유·원리를 모름

#### 관계적 이해

- 규칙이나 공식의 적용 방법과 이유·원리를 알고 있음
- '이유·원리'뿐 아니라 방법도 알아야 함

### 브루너

#### EIS 이론

- 행동적 표상(E) : 조작 활동·행동으로 표현
- 영상적 표상(I) : 그림·도식으로 표현
- 기호적 표상(S) : 문자·기호로 표현

### 피아제

#### 인지 발달 이론

- 개념 : 학습 = 인지 구조(도식)의 변화
- 과정
	- 동화 : 도식 변화 X, 자극을 도식에 맞춤
	- 조절 : 도식 변화 O, 도식을 자극에 맞춤

![[도식_2.수학_평형화.svg]]

#### 인지 발달 단계

- 감각운동기 (0~2세)
- 전조작기 (2~7세)
- 구체적 조작기 (7~12세) ⇒ 논리적 사고에 있어 구체물의 물리적 조작 필요
	- 논리-수학적 사고
	- 가역성의 원리 → 보존 개념 획득 ; 수, 양(특히 넓이 등적변형)의 보존
- 형식적 조작기 (12세~)

#### 추상화의 유형

- 경험적 추상화 : 물리적 속성에 대한 스키마
- 반영적 추상화 : 사람의 행동을 추상화 (논리-수학적 추상화)
- 의사-경험적 추상화 : 반영적 추상화와 같은 스키마 형성하되, 확인을 위해 구체물이 반드시 필요

### 프로이덴탈

#### 현실적 수학 교육, 수학화

- 맥락적이고 학습자 내부에서 구성
- 수학화 : 현상을 본질(수학적 수단)에 의해 조직
	- 수평적 수학화 : 현실 상황을 수학적으로 표현 (현실 → 수학)
	- 수직적 수학화 : 수학적 표현을 형식화·추상화 (수학 → 수학)
	- 응용적 수학화 : 수학적으로 도출한 내용을 현실에 적용 (수학 → 현실)

#### 수학화 교수·학습의 원리

- 안내된 재발명 : 교사의 안내에 따라 수학적 내용 재발명
- 반성적 사고 : 수준 상승의 원동력
- 현실과 결부된 수학 : 세 수학화의 순환으로 수학-현실 연결

#### 국소적 조직화

- 성질 나열 후 정의 → 나머지 성질 증명 (≒ 반 힐레, 관계적 수준) ※정정 2026-09-12(원표기 「디에네스」 · 동하 확정 M4 「반힐레임」 · 되돌리지 말 것)

#### 유의미 수용 학습 이론 지도 원리

- 통합적 조정 : 기존 내용과 학습 내용의 통합 (병위·상위적)

	- 설명 조직자 : 상위 개념 제시 ; 점진적 분화 (하위적)
	- 비교 조직자 : 동위 개념 제시 ; 통합적 조정 (병위적)

### 교수학적 변환론

#### 교수학적 변환

- 학문 수학 → 학교 수학 변환

#### 극단적 교수학적 현상

- 개인화/배경화
	- 강조 : 메타-인지 이동 : 교수학적 보조 수단(e.g. 교구)에 학생의 사고 집중
	- 간과 : 형식적 고착 : 수학 지식의 형식만 연습
- 탈개인화/탈배경화
	- 강조 : 토파즈식 외면치레 : 학생의 학습 환경 X (e.g. 과도한 힌트 제공)
	- 간과 : 조르단식 외면치레 : 학생의 사소한 행동을 보고 학생 과대평가

### 평면도형

#### 삼각형

- 배경지식
	- 삼각형의 종류
		- 각의 크기
			- 직각삼각형 - a²+b²=c² - 한각 직각
			- 예각삼각형 - a²+b²>c² - 세각 예각 → 한 각도 둔각 X
			- 둔각삼각형 - a²+b²<c² - 한각 둔각
		- 변의 길이
			- 부등변
			- 이등변
			- 정삼각형
	- 다각형 분류
		- 분할적 : A∩B=∅
		- 계층적 : A∩B≠∅
	- 필요·충분조건
		- 필요 : A는 B의 필요 → B이려면 A가 필요. → A⊃B
		- 충분 : A는 B의 충분 → A이면 B이기에 충분. → A⊂B
		- 필충 : A=B. (= A⊂B, A⊃B)
- 각론
	- 변의 길이
		- 이등변 - 정의 : 두 변의 길이가 같은 삼각형(학교수학은 계층적 정의)

#### 사각형

- 배경지식
	- 여러 가지 사각형의 정의와 성질
		- 정의
			- 사다리꼴 : 적어도 한 쌍의 변이 평행
			- 평행사변형 : 마주보는 두 쌍의 변이 평행
			- 마름모 : 네 변의 길이가 같은
			- 직사각형 : 네 각이 모두 직각
			- 정사각형 : 네 각이 모두 직각, 네 변의 길이가 같은
		- 성질
			- 대각선
				- 이등분 → 평행사변형 (포함 사각형)

#### 다각형

- 배경지식
	- 다각형과 정다각형의 정의
		- 다각형 : 선분으로만 둘러쌓인 도형
		- 정다각형 : 모든 변의 길이,각의 크기 같음
	- 볼록다각형과 오목다각형
		- 정의 → 도형 내부의 임의의 두 점 이은 선분 중 도형 밖을 지나는 선분이 있는가?
		- 특징 → 오목다각형 : 우각, 도형 밖의 대각선
	- 대각선
		- 정의 인접하지 않는 두 꼭짓점을 이은 선분
		- 다각형의 대각선 수 n(n-3)/2
		- 사각형의 종류에 따른 대각선의 특징 사각형 파트에서
		- 오각형 내각의 합 구하기
			- 연역적인 방법
				- 한 점에서 그을 수 있는 대각선 수
				- +1 하면 다각형을 나누는 삼각형의 수
				- ×180 = 내각의 합
				- ∴ n각형의 내각의 합 = {(n-3)+1}×180 = (n-2)×180°
- 핵심 각론

### 반 힐레, 기하 사고 수준 이론

#### 기하 사고 수준

- 시각적 인식 수준 → 직관적 사고. (1~2학년군)
	- 구체물(사고 대상)의 모양(사고 수단)을 직관적으로 인식하는 단계
- 분석적 수준. → 귀납적 사고 (3~4학년군)
	- 도형(사고 대상)들을 분석하여 구성 요소 및 성질(사고 수단)을 파악하는 단계
	- 특징
		- 관찰·실험과 같은 구체적 조작 활동을 통해 귀납적으로 도형의 구성 요소·성질 파악
		- 구체물의 대소 관계 파악
		- 도형을 성질이나 구성 요소에 따라 분류
- 비형식적 연역(=관계적) 수준 → 연역적 사고 (5~6학년군)
	- 도형·도형의 성질(사고 대상)이 논리적으로 정렬(명제(사고 수단))
	- 특징
		- 도형 사이의 포함관계를 이해
		- 이미 알고 있는 도형의 성질로부터 다른 도형의 성질을 비형식적으로 연역
		- 여러 성질을 열거하고, 필요충분한 성질을 선택하여 도형을 정의
- 형식적 수준 (중·고)
	- 형식적 연역 (명제 → 논리)
- 엄밀한 수준
	- 다양한 공리체계 이해 (논리 → 추상화)

	- 원리 이해 → 구체적인 조작 활동
	- 기능 숙달 → 세로셈 표준 알고리즘 지도. (행동주의)
	- 감각 형성 → 다양한 계산 방법 구성 (어림셈과 함께 구성주의)
		- 보수 관계 이해
			- 가르기 (분해) → 거꾸로 세기
			- 모으기 (합성) → 이어 세기
- 덧셈과 뺄셈 상황
	- 덧셈
		- 이미 있는 것/새로 더해지는 것 구분 유무
			- 합병
			- 첨가
	- 뺄셈
		- 제거 : 나머지
		- 비교 : 두 양의 차 ⇒ 그림으로 표현시 반드시 일대일 대응 관계
- 문장제 유형
	- a(→ 초기값) + b(→ 변화값) = c(→ 결과)
		- 등호 : 연산 표시 X, 좌변과 우변이 같다는 관계 표시
			- └→ ∴ 읽을 때 '~와 같습니다' 로 ('는' X)
- 연산 법칙
	- 뺄셈에서는 성립하지 X (연산 결과 바뀌는 예 제시하여 지도)
		- 덧셈의 교환법칙 ⇒ a+b = b+a
		- 덧셈의 결합법칙 ⇒ (a+b)+c = a+(b+c)
		- 뺄셈은 -1을 곱한 것으로 생각하여 곱셈의 분배법칙 이용, 덧셈으로 전환
	- 항등원 ⇒ a+e = e+a = a, e=0 ⇒ 뺄셈에서는 a-0=a, a-a=0 상황 지도
- 계산 전략
	- 구체물 활용
		- 수 세기 : 수 세기 전략 (모두, 이어, 거꾸로...)
		- 수 지식 : 수 관계 지식(규칙성), 연산법칙 (결합, 교환...)

#### 각론

- 10이 되는 더하기와 빼기
	- 10의 보수 관계 이해, 받아올림·내림의 기초
	- ⊕ 덧셈 ⇒ 교환법칙 이해
- 더해서 10이 되는 두 수를 이용한 세 수의 덧셈
	- 순서대로 더한 값((a+b)+c)(→ (a+b)가 10이 아니도록 설정) 과 10이 되는 두 수를 먼저 더해 10을 만들고 나머지 한 수는 더한 값(a+(b+c))(→ (b+c)가 10이 되도록 설정) 이 같음
- (몇)+(몇) = (십몇), (십몇)-(몇) = (몇)
	- 덧셈 ⇒ 가산수, 피가산수를 분해, 더해서 10이 되는 수를 만듦(→ 결합법칙에 의해 결과 같음)
	- 뺄셈
		- 피감수를 분해 : 10에서 먼저 빼고, 나머지 더함 ⇒ 감가법
		- 감수를 분해 : 빼서 10을 만들고, 10에서 추가로 뺌 ⇒ 감감법

#### 받아올림·내림

- 계산 원리
	- 덧셈 : 자릿값에 의한 전개식으로 분해, 교환·결합법칙
	- 뺄셈 : 자릿값에 의한 전개식으로 분해, 교환·결합법칙 + 덧셈에 대한 곱셈의 분배법칙
- 조작 활동
	- 자릿값에 맞는 수 모형으로 나타내기 (덧-각각, 뺄-피감수), 같은 모형끼리 더하기/빼는 수만큼 덜어내기
	- 받아올림(더해서 10개 이상, 10개→1개), 받아내림(뺄 수 X, 1개→10개)의 의미가 드러나는 조작 활동
- 세로셈 표준 알고리즘
	- 세로셈으로 나타내고, 자리에 맞게 수 쓰고, 일의 자리부터, 각 자리끼리 더하기/빼기
	- 합≥10 이면 받아올림, 뺄 수 없으면 받아내림
- 오류 유형
	- 덧셈 : 받아올림 X/아래에 쓰는 오류 ⇒ 받아올림 이해 X ; 구체물 조작 활동
	- 뺄셈 : 받아내림 대신 큰 수 - 작은 수 ⇒ 자릿값, 받아내림 이해 X, 한 자리수 뺄셈 관성 ; 구체물 조작 활동

#### 덧셈과 뺄셈의 관계와 어림

- 관계
	- 역관계, 가역적 사고.
		- 덧 → 뺄 : a+b=c
			- a=c-b
			- b=c-a
		- 뺄 → 덧 : a-b=c
			- a=b+c
			- a=c+b
- 미지수 포함 덧·뺄셈식 → 그림 보고 식 세우기
- 어림 (구성주의)
	- 결과 어림, 타당한지 확인 → 주로 조화수(계산 쉬운 수) 사용. + 앞자리, 조정
	- 대안 알고리즘
		- 부분합
		- 부분차

### 자연수의 곱셈

#### 곱셈의 의미와 실생활 상황

- 배경 지식
	- 곱셈의 의미 (→ 곱하는 수 자연수 X면 불가능)
		- 동수누가 : 같은 수 반복해서 더하기 — 도입
		- 배 : 한 양을 확대·축소하는 연산 — 본질
	- 곱셈 상황
		- 묶음 : 같은 개수씩 묶은 집합의 크기
		- 배열 : 직사각형으로 묶음이 배열
		- 비교 : 집합의 크기 비교, A가 B의 n배
		- 비율 : 비율과 항목의 수가 정해졌을때 전체
		- 넓이 : 직사각형의 넓이 (5-1)
		- 조합 : 경우의 수 (중등)
	- 곱셈 지도 모델
		- 묶음
		- 배열
		- 직선
		- 조합

#### 곱셈구구와 한 자리 수 곱셈

- 배경지식
	- 교환법칙 : a×b = b×a
	- 결합법칙 : (a×b)×c = a×(b×c)
	- 분배법칙 : a×(b+c) = a×b + a×c
	- 항등원 : a×e = e×a = a, e=1
	- 0 : 동수누가에 의해 0×a = 0, 교환법칙에 의해 a×0 = 0
- 각론
	- 곱셈구구의 원리
		- 동수누가 : n씩 더하기
		- 규칙성 : 곱하는 수 1 늘어날 때마다 n 늘어남
	- 1단 곱셈구구
		- 항등원 이해
	- 0의 곱 (0×a = a×0 = 0)
	- 곱셈표
		- 곱셈의 교환법칙 이해

#### 곱하는 수가 한 자리 수인 곱셈 ⇒ 곱해지는 수 조작

- 배경지식
	- 배열 모델을 이용한 곱셈 해결 전략 (ex. 22×3)
		- 동수누가 : 22씩 세 번 더하기
		- 뛰어 세기 : 22, 44, 66으로 뛰어 세기
		- 수분할을 통한 부분곱 : 자릿값에 대한 전개식으로 분해, 분배법칙 적용하여 부분곱
			- 22×3 = (20+2)×3 = (20×3) + (2×3) = 60 + 6 = 66
- (몇십) × (몇)
	- 계산 원리
		- 곱해지는 수 몇십을 10×(몇)으로 바꾼 후 결합법칙
		- 20×3 = (10×2)×3 = 10×(2×3) = 10×6 = 60
		- 곱해지는 수 10배 → 결과 10배임을 이해
	- 알고리즘 → (몇)×(몇) 뒤에 0 ~ 세로셈 X
- (몇십몇) × (몇), (세 자리 수) × (한 자리 수)
	- 계산 원리
		- 곱해지는 수를 자릿값에 대한 전개식으로 분해한 뒤 분배법칙 적용
		- 33 × 2 = (30+3)×2 = (30×2) + (3×2) = 60 + 6 = 66
	- 알고리즘
		- 세로셈 부분곱 알고리즘 : 세로셈으로 나타내고 각 자리에 맞춰 수를 쓴(이하 세로셈 표현) 뒤 곱해지는 수 분해, 부분곱의 합
		- 세로셈 표준 알고리즘 : 세로셈 표현 뒤 곱해지는 수를 일의 자리부터 곱하고 결과 ≥ 10이면 바로 윗자리로 올림

#### 곱하는 수가 두 자리 수인 곱셈 ⇒ 곱하는 수 조작

- 곱하는 수가 (몇십)
	- 계산 원리
		- 곱하는 수 몇십을 10×(몇)으로 바꾼 후 교환법칙·결합법칙
		- 47 × 20 = 47 × (10 × 2) = 47 × (2 × 10) = (47 × 2) × 10 = 94 × 10 = 940
		- 곱하는 수 10배 → 결과 10배임을 이해
	- 알고리즘 → (곱해지는 수)×(몇) 뒤에 0 ~ 세로셈 X
- 곱하는 수가 (몇십몇)
	- 계산 원리
		- 곱하는 수를 자릿값에 대한 전개식으로 분해한 뒤 분배법칙 적용
		- 17 × 35 = 17 × (30+5) = (17 × 30) + (17 × 5) = 510 + 85 = 595
	- 알고리즘
		- 세로셈 부분곱 알고리즘 : 세로셈 표현 뒤 곱하는 수 분해, 부분곱의 합
		- 세로셈 표준 알고리즘 : 세로셈 표현 뒤 곱하는 수를 일의 자리부터 곱하고 결과 ≥ 10이면 바로 윗자리로 올림

#### 곱셈 오류 지도

- 자릿값 무시
	- 원인 : 자릿값 개념 형성 X
	- 지도 : 자릿값 의미 지도
- 자릿값 위치가 정확하지 않음
	- 지도 : 보조선 사용
- 올림 계산 X
	- 원인 : 자릿값 이해 X, 올림 처리 오개념
	- 지도 : 곱한 결과가 10 이상이면 바로 윗자리로 올리도록 지도

### 자연수의 나눗셈

#### 나눗셈의 의미와 실생활 상황, 곱셈과 나눗셈의 관계

- 실생활 상황
	- 등분제 : 묶음의 크기 상황
	- 포함제 : 묶음의 수 상황
- 곱셈과 나눗셈의 관계 - 역연산 (가역)
	- 곱셈식 하나를 포함제·등분제 두 상황으로 표현
	- ∴ 한 상황을 곱셈·나눗셈으로 표현하여 지도

#### 나누는 수가 한 자리인 나눗셈

- 배경 지식
	- 분배법칙 → 피제수 분해만 가능
	- 세로셈 알고리즘
		- 자릿값에 따라 전개 X, 적절한 몫이 나오도록 분할 ; 84÷6 = (60÷6)+(24÷6)
		- 왼쪽(높은 자리)부터
		- 어림을 통한 잠정 몫 사용
- 피제수 (몇십)
	- 계산 원리
		- (몇십) → 10×(몇), 결합법칙 (제수는 분수 곱셈으로)
	- 알고리즘
		- (몇)÷(몇)에 0 붙임, 세로셈 X
- 피제수 (몇십몇)
	- 계산 원리
		- 피제수 분할 후 분배법칙
	- 알고리즘 : 세로셈 표준
	- 나머지 : 분수·소수 범위에서는 나머지 X, 몫 변화
- 이하 동일 내용 반복으로 생략
- 혼합 계산 → 5~6학년군, 계산 순서 지도

### 분수

#### 배경지식

- 분수의 의미
	- 전체-부분 : 전체 m부분중 n부분의 크기 ; 이산·연속 상황 가능, 주로 진분수 지도
	- 측정 : 전체 단위 등분해 보조 단위, 측정값 ; 연속 상황, 가분수 지도  * 분수 맥락에서 등분할 = 크기 뿐 아니라 모양도 같게 분할
	- 몫 : 나눗셈의 몫
	- 비율
	- 연산자
- 분수 지도 모델
	- 영역 모델 : 영역(전체), 합동인 도형(부분)으로 ⇒ 기준에 따라 각 도형이 나타내는 분수 바뀜
	- 넓이 모델 : 모양 무관, 같은 넓이로 분할
	- 길이 모델 : 기준에 따라 각 길이가 나타내는 분수 바뀜
	- 집합 모델 : 이산량

#### 양의 등분할

- 전체에 대한 부분 → 분수
	- 분모 : 묶음·분할 수 / 분자 : 색칠·선택
- 전체에 대한 분수 → 부분
	- 전체 : 분모로 등분 / 부분 : 분자만큼 묶음

#### 분수의 분류

- 단위분수 = 분자가 1
- 진분수 / 가분수 / 대분수 ⇒ 분모 > 분자?
	- Y : 진
	- N : 자연수 분리?
		- Y : 대
		- N : 가

#### 분모가 같은 분수의 비교

- 단위분수, 진분수, 가분수, 대분수
	- 분수 크기 비교에 전체 다르면 오개념 생길 수 있으니 유의

#### 크기가 같은 분수 만들기, 약분·통분

- 배경지식
	- 크기가 같은 분수 (= 동치 분수)
		- 의미 : 전체 고정 - 같은 양
		- 전체 변화 - 같은 비율
		- 방법 : 분모가 크게 - 재귀적 분할
		- 분모가 작게 - 칸끼리 묶음
- 각론
	- 약분 : 분모와 분자를 1이 아닌 공약수로 나눔 (기약분수 = 더 이상 약분 x)
	- 통분 : 분모가 같게 (= 공통분모) 분모끼리 곱하거나 최소공배수로

#### 분모가 다른 분수의 크기 비교

- 각론
	- 통분의 필요성
		- 분수의 단위는 분모가 결정하므로 단위를 같게 하기 위해

### 분수의 덧셈·뺄셈

#### 분모가 같은 진분수의 덧셈·뺄셈

- (진분수) + (진분수)
	- 계산 원리 : 단위분수 변환 → 분배법칙의 역 (∵ 분모가 같은 분수 덧셈 = 단위분수 개수의 합)
		- e.g. 2/6 + 3/6 = 1/6 × 2 + 1/6 × 3 = 1/6 × (2+3) = (2+3)/6(→ 계산 알고리즘) = 5/6
- 받아올림 있는 (대분수) + (대분수)
	- 대분수는 항상 이 두 가지로 나뉨
		- 자연수 부분 / 진분수 부분으로 나누어 계산
			- 모델 : `1`이 되는 모델 등분할 X
		- 가분수로 바꾸어 계산
			- 모델 : 모든 영역을 분모로 등분할
- 유의점
	- 약분은 5~6학년군 내용이나 결과 기약분수 표현 강제 X
- 오류
	- 분모끼리, 분자끼리 더하는 오류
		- 원인 : 분모·분자 의미 이해 X, 영역 모델 1개 크기 = 1 이해 X
		- 인지적 갈등 : 어림 활용
		- 지도 : 알고리즘, 구체물 조작
	- 1을 분수로 잘못 바꾸는 오류
		- 원인 : 자연수 받아내림
		- 지도 : 1을 크기가 같은 분수 여럿으로

#### 분모가 다른 진분수의 덧셈·뺄셈

- (진분수) + (진분수)
	- 조작 활동 → 재귀적 분할
	- 통분 ⇒ 분수의 단위는 분모가 결정하므로 단위 통일
	- 공통분모 → LCM, 분모의 곱 등 방법 가능
- 유의점
	- 결과 약분 가능
- 오류
	- 분모끼리, 분자끼리 더하는 오류
		- 원인 : 분모·분자 의미 이해 X, 분모가 같은 분수의 덧셈 계산 방법 이해 X (cf. 동분모 오류 원인)
		- 이하는 동분모와 같음

### 분수의 곱셈

### 소수의 사칙연산

#### 소수의 덧셈과 뺄셈

- 계산 원리
	- 단위소수의 개수로 바꾼 뒤 분배법칙의 역
- 알고리즘
	- 세로셈
		- 소수점끼리 맞추어 세로로 → 같은 자리끼리 더하기·빼기 → 결과에 소수점 그대로 내려 찍기
- 보충 지도
	- 받아내림 이해 X ⇒ 수직선으로 지도 (≒ 자연수)
- 오류
	- 덧셈 : 오른쪽 끝을 맞추어 계산 ⇒ 오른쪽 끝자리에 0 붙이고 자릿수 맞추어 계산
	- 뺄셈 : 빼야 할 수를 그대로 내려 씀 ⇒ 오른쪽 끝자리에 0 붙이고 자릿수 맞추어 계산

#### 소수의 곱셈

- 계산 원리
	- 분모가 10의 거듭제곱인 분수의 곱셈으로 표현하여 지도
	- e.g. 0.7(→ 7×1/10) × 0.5(→ 5×1/10) = 7/10 × 5/10 = (7×5)/(10×10) = 35/100 = 0.35
		- 이 사실 이해하도록 지도 ※노트에서 「①」·「②」 두 줄을 중괄호로 묶어 걸린 주석이다
			- ① 7×5의 1/100배가 됨
			- ② 피승수·승수가 각각 1/10배 ⇒ 결과가 1/100
- 알고리즘
	- 소수점 무시하고 자연수 곱셈 계산 → 승수·피승수 소수점 아래 자리의 수의 합만큼 곱한 결과의 소수점 왼쪽으로 옮겨 찍기

#### 제수가 자연수인 소수의 나눗셈

- 계산 원리
	- 분모가 10의 거듭제곱인 분수의 나눗셈으로 표현하여 지도 ; 분자가 나누어떨어지지 않을 때도 분모가 10ⁿ인 동치분수로 바꾸어야 다시 소수 변환이 편리
	- e.g. 4.2(→ 42×1/10) ÷ 6 = 42/10 ÷ 6 = (42÷6)/10 = 7/10 = 0.7
		- ① 피제수가 1/10배 ⇒ 몫도 1/10배
- 알고리즘
	- 자연수 나눗셈처럼 소수로 계산
		- 나누어떨어지지 X - 피제수에 0 붙여 계산
		- 몫의 소수점 - 피제수의 자연수부 바로 뒤에서 옮겨 적음
		- 몫의 자연수부가 비어 있음 - 일의 자리에 0 쓰기
- (자연수) ÷ (자연수) - 수 모형
	- e.g. 3 ÷ 4 = (2.8 + 0.2) ÷ 4 = 0.7 + 0.05 = 0.75
	- 지도 : 3 = 백 모형 3개 → 4로 나눌 수 X, 십 모형 30개(→ 백 모형이 모두 분해 ⇒ 일의 자리가 0) → 4로 나누면 7 … 2 → 낱개 모형 20개 → 4로 나누면 5개

#### 제수가 소수인 소수의 나눗셈

- 계산 원리
	- 분수의 나눗셈으로 지도
	- e.g. 8.24 ÷ 4.12 = 824/100 ÷ 412/100 = 824(→ 8.24×100) ÷ 412(→ 4.12×100) = 2
		- 제수와 피제수를 똑같이 100배 하면 몫도 같음 (cf. 제수 자연수에서 알 수 있는 사실)
- 알고리즘
	- 제수·피제수 소수점을 같은 자리만큼 옮김 → 몫의 소수점은 옮긴 소수점 위치에 맞춤

#### 1~2학년군

[2수03-01 · 입체도형의 모양] 교실 및 생활 주변에서 여러 가지 물건을 관찰하여 **직육면체, 원기둥, 구의 모양**을 찾고, 이를 이용하여 여러 가지 모양을 만들 수 있다.

[2수03-02 · 입체도형의 모양] 쌓기나무를 이용하여 여러 가지 입체도형의 모양을 만들고, 그 모양에 대해 **위치**나 **방향**을 이용하여 말할 수 있다.

[2수03-03 · 평면도형과 그 구성 요소] 교실 및 생활 주변에서 여러 가지 물건을 관찰하여 **삼각형, 사각형, 원의 모양**을 찾고, 이를 이용하여 여러 가지 모양을 만들 수 있다.

[2수03-04 · 평면도형과 그 구성 요소] **삼각형, 사각형, 원**을 **직관적**으로 **이해**하고, 그 모양을 그릴 수 있다.

[2수03-05 · 평면도형과 그 구성 요소] **삼각형, 사각형**에서 각각의 **공통점**을 찾아 말할 수 있다.

(적용 시 고려 사항 · [2수03-01] · 입체도형의 모양) 입체도형과 평면도형의 모양을 다룰 때 모양의 특징을 **직관적**으로 파악하여 모양을 분류하고, 분류한 모양을 지칭하기 위해 일상용어를 사용하게 할 수 있다.

(적용 시 고려 사항 · [2수03-02] · 입체도형의 모양) 쌓기나무, 칠교판 등의 구체물을 이용한 모양 만들기를 통하여 도형에 대한 **공간 감각**을 기르게 한다.

[2수03-06 · 양의 **비교**] 구체물의 **길이, 들이, 무게, 넓이**를 **비교**하여 각각 ‘길다, 짧다’, ‘많다, 적다’, ‘무겁다, 가볍다’, ‘넓다, 좁다’ 등을 구별하여 말할 수 있다.

[2수03-07 · **시각**과 시간] 시계를 보고 **시각**을 ‘**몇 시 몇 분**’까지 읽을 수 있다.

[2수03-08 · 시각과 시간] **1시간과 1분의 관계를 이해하고**, 시간을 ‘시간’, ‘분’으로 표현할 수 있다.

[2수03-09 · 시각과 시간] **실생활 문제 상황과 연결하여** 1분, 1시간, 1일, 1주일, 1개월, 1년 사이의 관계를 이해한다.

[2수03-10 · 도형과 측정 1~2학년군] 길이 단위 **1cm와 1m**를 알고, 이를 이용하여 주변 사물의 길이를 측정할 수 있다.

∙[2수03-10 · 도형과 측정 1~2학년군] 길이의 표준 단위를 도입하기 전에 구체물을 **직접 비교**해 보거나 여러 가지 **임의 단위**를 사용하여 **구체물의 길이를 재어보는 활동**을 통해 **표준 단위의 필요성**을 알게 한다.

[2수03-11 · 도형과 측정 1~2학년군] **1m와 1cm의 관계를 이해하고**, 길이를 ‘**몇 m 몇 cm’와 ‘몇 cm’로** 표현할 수 있다.

[2수03-12 · 도형과 측정 1~2학년군] 여러 가지 물건의 길이를 **어림**하고, 길이에 대한 **양감**을 기른다.

[2수03-13 · 도형과 측정 1~2학년군] **실생활 문제 상황과 연결**하여 길이의 덧셈과 뺄셈을 할 수 있다.

(적용 시 고려 사항 · [2수03-06] · 양의 비교) 양의 비교는 학생들에게 친근한 실생활 상황을 이용하고, **직관적인 비교, 직접 비교, 간접 비교** 등을 상황에 따라 알맞게 다룬다.

(적용 시 고려 사항 · [2수03-08] · 시각과 시간) 시간의 여러 가지 단위를 지도할 때는 **단위 사이의 관계**를 이해하는 데 중점을 두고, **지나친 단위 환산은 다루지 않는다**.

#### 3~4학년군

[4수03-01 · 도형의 기초] **직선, 선분, 반직선**을 이해하고 구별할 수 있다.

[4수03-02 · 도형의 기초] **각과 직각**을 이해하고, **직각과 비교하는 활동**을 통하여 **예각과 둔각**을 구별할 수 있다.

[4수03-03 · 도형의 기초] 직선의 **수직 관계**와 **평행 관계**를 이해한다.

[4수03-04 · 평면도형의 이동] 구체물이나 평면도형의 **밀기, 뒤집기, 돌리기** 활동을 통하여 그 **변화**를 이해한다.

[4수03-05 · 평면도형의 이동] 평면에서 점의 이동에 대해 **위치와 방향**을 이용하여 설명할 수 있다.

[4수03-06 · 원의 구성 요소] 원의 **중심, 반지름, 지름**을 이해하고, 그 성질을 안다.

[4수03-08 · 여러 가지 **삼각형**] 여러 가지 모양의 **삼각형**에 대한 **분류 활동**을 통하여 **이등변 **삼각형**, 정**삼각형을 이해하고, **그 성질을 탐구하고 설명할 수 있다**.

[4수03-09 · 여러 가지 **삼각형**] 여러 가지 모양의 **삼각형**에 대한 **분류 활동**을 통하여 **직각**삼각형**, 예각**삼각형**, 둔각**삼각형을 이해한다.

[4수03-10 · 여러 가지 **사각형**] 여러 가지 모양의 **사각형**에 대한 **분류 활동**을 통하여 **직**사각형**, 정**사각형**, 사다리꼴, 평행사변형, 마름모**를 이해하고, **그 성질을 탐구하고 설명할 수 있다**.

[4수03-11] **다각형**과 **정**다각형을 이해한다.

∙[4수03-11] 도형판, 모양 조각 등의 교구를 이용한 **구체적인 조작 활동**을 통해 **다각형**과 **정**다각형을 이해하게 한다.

[4수03-12 · 다각형] 주어진 도형을 이용하여 여러 가지 모양을 만들거나 채우고 **설명할 수 있다**.

(적용 시 고려 사항 · [4수03-01] · 도형의 기초) 직선, 선분, 반직선에 대한 평가에서는 정확한 정의나 표현보다 직선, 선분, 반직선을 **서로 구별할 수 있는지에 중점을 둔다**.

(적용 시 고려 사항 · [4수03-08] · 여러 가지 삼각형) 삼각형의 성질을 탐구하는 활동에서 구체적인 **관찰, 실험, 측정** 등 **귀납적 추론**을 통해 성질을 이해하게 한다.

(적용 시 고려 사항 · [4수03-10] · 여러 가지 사각형) **여러 가지 사각형의 성질**은 **구체적인 조작 활동**을 통하여 간단한 것만 다루고, **여러 가지 사각형 사이의 관계는 다루지 않는다**.

[4수03-13 · 시각과 시간] **1분과 1초의 관계를 이해하고**, 초 단위까지 시각을 읽을 수 있다.

[4수03-14 · 시각과 시간] **실생활 문제 상황과 연결하여** 초 단위까지의 시간의 덧셈과 뺄셈을 할 수 있다.

[4수03-15 · 도형과 측정 3~4학년군] **길이 단위 1mm와 1km**를 알고, 이를 이용하여 길이를 측정하고 **어림**하며 **수학의 유용성을 인식할 수 있다**.

[4수03-16 · 도형과 측정 3~4학년군] **1cm와 1mm, 1km와 1m의 관계**를 이해하고, **길이를 ‘몇 cm 몇 mm’와 ‘몇 mm’, ‘몇 km 몇 m’와 ‘몇 m’로** 다양하게 표현 할 수 있다.

[4수03-17 · 도형과 측정 3~4학년군] **들이 단위 1L와 1mL**를 알고, 이를 이용하여 들이를 측정하고 **어림**하며 **수학의 유용성을 인식할 수 있다**.

[4수03-18 · 도형과 측정 3~4학년군] **1L와 1mL의 관계**를 이해하고, 들이를 ‘**몇 L 몇 mL’와 ‘몇 mL’ 로** 표현할 수 있다.

[4수03-19 · 도형과 측정 3~4학년군] **실생활 문제 상황과 연결하여** 들이의 덧셈과 뺄셈을 할 수 있다.

[4수03-20 · 도형과 측정 3~4학년군] 실생활에서 **무게**를 나타낼 때 사용하는**단위 1g과 1kg**을 알고, 이를 이용하여 **무게**를 측정하고 **어림**하며 수학의 유용성을 인식할 수 있다.

[4수03-20 · 도형과 측정 3~4학년군] 실생활에서 무게를 나타낼 때 사용하는 단위 1g과 1kg을 알고, 이를 이용하여 무게를 측정하고 어림하며 **수학의 유용성을 인식할 수 있다**.

∙[4수03-20 · 도형과 측정 3~4학년군] 초등학교에서는 **무게와 질량의 개념을 엄밀하게 구분하지 않으며**, **무게를 비교하고 측정하는 데에 g, kg의 단위를 사용하게 한다**.

[4수03-21 · 도형과 측정 3~4학년군] **1kg과 1g의 관계**를 이해하고, 무게를 ‘몇 kg 몇 g’과 ‘몇 g’으로 표현할 수 있다.

[4수03-22 · 도형과 측정 3~4학년군] 실생활에서 **무게**를 나타낼 때 사용하는 **단위 1t을 알고**,1t과 1kg의 관계를 이해한다.

[4수03-22 · 도형과 측정 3~4학년군] 실생활에서 무게를 나타낼 때 사용하는 단위 1t을 알고, **1t과 1kg의 관계를 이해한다**.

[4수03-24 · 도형과 측정 3~4학년군] **각의 크기의 단위**인 **1도(°)**를 알고, **각도기**를 이용하여 각의 크기를 측정하고 **어림**할 수 있다.

[4수03-25 · 도형과 측정 3~4학년군] 여러 가지 방법으로 **삼각형과 사각형의 내각의 크기의 합**을 **추론**하고, 자신의 **추론** 과정을 설명할 수 있다.

(적용 시 고려 사항 · [4수03-13] · 시각과 시간) 실제로 재거나 **어림**하는 측정 활동을 통하여 시간, 길이, 들이, 무게, 각도에 대한 **양감**을 기르게 한다.

(적용 시 고려 사항 · [4수03-14] · 시각과 시간) 시간, 길이, 들이, 무게의 단위를 지도할 때 **단위 사이의 관계**를 이해하는 데 중점을 두고, **1km와 1cm의 관계**, **1t과 1g의 관계 등의 지나친 단위 환산**은 다루지 않는다.

(적용 시 고려 사항 · [4수03-17] · 들이) 들이, 무게의 **표준 단위**를 도입하기 전에 표준 단위**의 필요성을 알게 한다**.

#### 5~6학년군

[6수03-01 · 합동과 대칭] **도형의 합동**을 이해하고, 합동인 도형의 성질을 **탐구하고 설명 할 수 있다**.

∙[6수03-01 · 합동과 대칭] **합동인 두 도형에서 대응점, 대응변, 대응각을 각각 찾게 하고 대응변의 길이와 대응각의 크기를 비교하는 활동**을 통해 합동인 도형의 성질을 탐구하고 설명하게 한다.

[6수03-02 · 합동과 대칭] 실생활과 연결하여 **선대칭도형과 점대칭도형을 이해**하고 그릴 수 있다.

[6수03-03] **직육면체와 정육면체를 이해**하고, **구성 요소**와 **성질**을 탐구하고 설명할 수 있다.

[6수03-03 · 직육면체와 정육면체] 직육면체와 정육면체를 이해하고, 구성 요소와 성질을 **탐구하고 설명할 수 있다**.

[6수03-05] **각기둥과 각뿔**을 이해하고, **구성 요소**와 **성질**을 탐구하고 설명 할 수 있다.

[6수03-05 · 각기둥과 각뿔] 각기둥과 각뿔을 이해하고, 구성 요소와 성질을 **탐구하고 설명 할 수 있다**.

[6수03-07 · 원기둥, 원뿔, 구] 원기둥, 원뿔, 구를 이해하고, 구성 요소와 성질을 **탐구하고 설 명할 수 있다**.

[6수03-08 · 원기둥, 원뿔, 구] 원기둥의 **전개도**를 그릴 수 있다.

(적용 시 고려 사항 · [6수03-01] · 합동과 대칭) 무늬 찾기, 종이 겹쳐 오리기, 도장 찍기, 데칼코마니 등 구체적인 조작 활동을 통하여 **도형의 합동의 의미를 알게 한다**.
