지도서 총론 - 2022 개정 초등 통합교과 교과용도서의 이해

개발 방향과 특징

방향 : 교사와 학생이 협업해 만드는 교과서 — 함께 주제를 정하고 수업을 만들며 성취기준을 만난다
교과서 특징 셋 : 주제별 교과서 = 주제를 중심으로 만들어 가는 교과서 지원(월별 한 주제 · 주제는 개발자 예시 · 교실에서 구체화/새로 개발) · 플랫폼형 교과서 = 배움 지도를 완성하며 만들어 가는 교과서 지원(이 플랫폼을 배움 지도로 제시 · 주체성·직접 참여·현재성) · 모듈형 교과서 = 묶음 수업 구성으로 만들어 가는 교과서 지원(수업 묶음 = 데이터베이스 · 창조성·개방성·통합성)
지도서 특징 셋 : 해설서(1부 교과서를 이해하려면) · 설명 자료집(2부 사용하려면 — 수업 설명·자료·수업 이야기) · 창안서(3부 단원을 개발하려면 — 절차·사례·도구) ; 교사 = 국가 교육과정 사용자이자 교실 교육과정 개발자

구성

주제 단원 16 : 1-1 학교(3월 고정)·사람들·우리나라·탐험 / 1-2 하루·약속·상상·이야기(12월 고정) / 2-1 나·자연·마을·세계 / 2-2 계절·인물·물건·기억(12월 고정) · 나머지 13은 권장 시기
성취기준 편성 : 영역 01·02 = 1학기 · 03·04 = 2학기 · 핵심 아이디어별 두 묶음 중 하나는 1학년, 하나는 2학년
이야기 모형 = 학교 수업에서 교사와 학생이 우리 자신의 삶을 이야기하도록 의도(단원 개발 절차 = 단원 학습 모형 = 차시) : 이야기 열기(지금 여기 우리 이야기) → 이야기하기(함께 골라요 / 함께 만들어요) → 이야기 맺기(지금 여기 나의 이야기) ↦ 도입-전개-정리
흐름 : 배움 지도(맨 앞 · 시간 배정 없음 · 매 수업 오늘 할 수업 선택·표시) → 지금 여기 우리 이야기(40~120분) → 함께 골라요 · 함께 만들어요 → 지금 여기 나의 이야기(40~120분)
함께 만들어요 = 우리 반 주제 · 질문으로 수업 · 주제/놀이/안전 수업 만들기(2015 구성 차시 흡수)
함께 골라요 = 주제 수업(20여 개) + 놀이 수업(단원별 최소 8시간 · 기본 움직임 요소 8 균형 · 한 번 더/바꾸어서/만들거나 배워서) + 안전 수업(단원별 최소 4시간 · 01-01 기반 · 7대 안전 중 직업 안전 뺀 여섯 영역)
지도서 활용 : 1부 이해 · 2부 사용(함께 골라요 = 성취기준 정보·개발 안내·발문·준비물·유의점·안전 / 함께 만들어요 = 수업 이야기 + 개발 안내) · 3부 단원 개발
전자저작물 : 배움 지도에서 수업 선택·진도 저장 · PDF·배움 자료·평가지

평가 — 목적에 따른 셋 (Earl, 2003)

학습에 대한 평가(of) : 의도한 것을 학습했는지 — 준거 성취기준 · 평가자 교사/외부 · 마칠 때
학습을 위한 평가(for) : 후속하는 교수·학습을 점검하기 위한 — 전·중·후 · 어려워하는 이유 · 평가자 교사(진단·개별화·자기 평가 정보)
학습으로서의 평가(as) : 평가 자체가 학습 — 실제로 배운 것 포함 · 평가자 학생(자기 평가·진보 검토·전략·목표)
of·for 모두 평가 준거 = 성취기준 · as = 성취기준뿐만 아니라 교수·학습 과정에서 실제로 학생이 배운 것도 준거
지도서 : 단원마다 셋 다(시기·평가자·학습지/관찰/자기 평가) — 성취기준 달성 → of · 수업 설계·유연한 전개 → for · 실제 배운 것·주도성 → as

질문과 대답 (요지)

주제 개발권을 넘겨도 주제별 교과서 유지(교과서 주제 = 예시)
구성 차시 → 「함께 만들어요」 흡수 · 배움 지도 = 오늘 할 수업 고르기·마무리 성찰·일부만 계획 권장
수업 이야기 = 교사 교육과정 지식 발굴·공유 · 개발자·사용자 경계 허물기
입학 초기 적응 = 「학교」 교과서 + 창체 34시간
