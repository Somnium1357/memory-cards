## 학습과제

### 학습과제 단계화

- 시작형 과제 : 제일 저난도, 시작형, 기초 단계
- 확장형 과제 : 복잡성·난이도 ↑
	- 과제 내 확장 : 같은 과제에서
	- 과제 간 확장 : 다른 과제로
- 세련형 과제 : 폼, 느낌과 같은 운동 기능 질적인 향상
- 적용형 과제 : 실제 상황에 적용

### 학습과제의 전달

#### 설명

- 좋은 설명
	- 한번에 하나씩
	- 핵심 기능 들어가게
	- 단서 사용
	- 연상 단어 사용
- 설명은 이해 점검 필요
	- 전체 대상
		- 인지 점검 (이해한 사람 손들기, 엄지 위아래)
		- 구두 점검 (이해했어요? → 예!)
	- 개별 대상
		- 이해력 점검 (한 명 짚어서 설명해보도록)
		- 수행 점검 (‥ 수행해보도록)

#### 시범

- 시범의 종류 : 교사 시범, 동료 시범, 시청각·동영상 자료
- 유의사항
	- 정확
	- 실제와 유사한 상황에서 시범
	- 동료시범 가능
	- 동영상, 시청각 활용 가능
- 좋은 시범이란?
	- 위치
	- 전체 → 부분
	- 정상 → 느린
	- 구두 제시

## 3, 4학년군 운동

### 기본 체력운동

#### 체력운동 기본 움직임 기술

- 운동과 체력
	- 체력
		- 건강 체력
			- 근력 : 근육이 큰 힘을 낼 수 있는 능력
			- 근지구력 : 근육이 오래·지속적으로 힘을 낼 수 있는 능력
			- 심폐 지구력 : 산소를 이용한 운동 지속력
			- 유연성 : 관절 가동 범위
		- 운동 체력
			- 순발력 : 순간적으로 강한 힘
			- 민첩성 : 빠르게, 방향 전환
			- 협응성 : 여러 근육 조화
			- 평형성 : 자세 유지
- 걷기와 달리기 ⇒ 심폐지구력
	- 한 발이 항상 땅에 vs 양 발이 공중
	- 팔
		- 걷기 : L, V 자, 앞뒤로 가볍게 / 힘차게 흔들기
		- 달리기 : ㄴ 자, 리듬에 맞춰
	- 상체
		- 걷기 : 곧게 펴기
		- 달리기 : 5~10° 앞으로 기울이기
	- 발 → 뒤꿈치부터 착지
- 매달리기 ⇒ 근력
	- 손가락 ⇒ 손가락 전체로 쥐기, 엄지가 검지 밖으로
	- 안전 ⇒ 위험하니 모래나 매트, 착지 시 무릎 살짝 굽히기 (착지 일반)
- 버티기와 굽히기 ⇒ 근력 / 유연성
	- 안전 ⇒ 반동 X (스트레칭 일반)
- 밀기와 당기기 ⇒ 근력 / 유연성
- 운동 계획·실천하기
	- 강도
		- 저(쉬움) → 중(→ 유산소, 노래X) → 고(대화X)
	- 빈도, 시간
		- 7560+ : 1주일(7) 5일 이상, 하루 60분 이상

#### 체력운동 기능

- 신체 특성 알아보기
	- 지도: 변화 가능, 개인차 있음
		- 체격 : 몸의 외형
		- 체형 : 신체의 형태
		- 체력 : 운동체력 + 건강체력
- 운동의 단계 알아보기
	- 준비 운동(Warm up) ⇒ 체온 상승, 몸을 부드럽게
		- 방법 : 심장에서 먼 부위부터 (맨손 체조·스트레칭 일반 원리), 자주 사용할 근육
		- 종류 : 동적 스트레칭 (계속 움직임) ⇒ 운동 효율 ↑
	- 본 운동 ⇒ 가장 많은 시간
	- 정리 운동(Cool-down) ⇒ 피로 회복 ; 건너뛰지 않도록 주의
		- 방법 : 많이 사용한 근육 위주
		- 종류 : 정적 스트레칭 (자세 유지) ⇒ 주로 사용한 근육 수축·이완으로 인한 비대칭 해소
- 오래 달리기, 걷기 (심폐지구력) : 바른 걷기·달리기 자세 유지
- 팔굽혀펴기 (근력 + 근지구력)
	- 무릎 대고 팔굽혀펴기 ⇒ 무릎과 팔이 가까워지면 쉬워짐
	- 자세 ⇒ 머리 - 허리 - 다리 일직선, 어깨 - 팔꿈치 일직선
	- 유의점 ⇒ 허리 꺾이면 X(↑ 머리-허리-다리 일직선), 팔꿈치 몸 밖으로 벌리면 X(↑ 어깨-팔꿈치 일직선)
- 윗몸말아올리기 (배의 근력)
	- 자세
		- 발바닥 전체가 바닥에 닿게
		- 손은 무릎에 끝 → 친구 손 닿을 때까지 올라가기
- 왕복달리기 (심폐지구력(→ 긴 거리(15m)), 민첩성(→ 짧은 거리(3m) + 순발력))
	- 자세 : 방향 바꿀 때 중심↓, 속도↓
- PAPS (운동 체력 중심 → 건강 체력 중심)
	- 필수
		- 심폐 지구력 : 오래달리기 (왕복, 걷기), 스텝
		- 유연성 : 앉아 윗몸 앞으로 굽히기, 종합 유연성 (어깨, 몸통, 옆구리, 하체)
		- 근력·근지구력 : 팔굽혀펴기 (남, 여는 무릎), 윗몸말아올리기, 악력
		- 순발력 : 50m 달리기, 멀리뛰기
		- 비만 : BMI (체중(kg) / 키(m)²)

### 건강 운동 및 생활 습관

#### 건강 생활 습관

- 건강한 생활 습관
	- 건강 : 신체, 정신, 사회적 안녕
- 바른 자세로 생활하기
	- 디지털 기기 : 화면과 적당한 거리, 고개 숙이기 X (거북목)
	- 서기와 걷기 : 양발에 같은 힘, 가방 양어깨 수평
	- 물건 들기 : 허리 펴고 무릎 굽히기
- 자세가 몸에 미치는 영향
	- 몸의 변화 : 척추 측만증, 거북 목 (귓구멍이 어깨 앞으로), 골반 변형
- 체중과 체형 관리하기
	- 비만 : 체지방률 기준

#### 운동 생활 습관

- 올바른 운동 생활 습관 : 자기 수준에 맞게
- 맨손체조
	- 정의 : 도구 없이 온몸을 골고루 움직이는 운동
	- 방법 : 심장에서 먼 곳부터, 본 운동과 관련 깊은 부위
	- 원리
		- 낮은 강도부터 점진적으로 강도 ↑
		- 심장에서 먼 부위부터, 모든 부위
		- 작은 부위부터 큰 부위로
		- 자기 수준에 맞게
- 산책·계단 오르기
	- 계단 오르기 자세 : 원칙은 발 ½, 초등은 발 전체
- 주변의 운동기구 활용
	- 유의점 : 나이·키 제한, 이상 여부 확인

	- 운동 : 스트레칭 (정적 / 동적)

### 운동 체력

- 의미와 요소
	- 요소 : 순발력, 민첩성, 평형성, 협응성 ⇒ 운동 상황 하나에 여러 요소 관여
- 순발력
	- 측정
		- 제자리 멀리뛰기 (PAPS)
		- 50m 달리기 (PAPS)
	- 운동 : 주로 구부렸다 순간적으로 펴는 류 (e.g. 줄넘기 2단 뛰기)
	- 유의점 : 착지 시 발 앞꿈치
- 민첩성
	- 측정 : 반복 옆 뛰기 (PAPS X)
	- 운동 : 주로 급격한 방향 전환
- 평형성
	- 측정 : 눈 감고 한 발로 균형잡기 (PAPS X)
	- 운동 : 주로 자세 유지
	- 분류
		- 동적 평형성 : 움직이는 상태에서 중심 유지
		- 정적 평형성 : 정지한 상태에서 균형 유지
- 협응성
	- 측정 : 벽에 공 던지고 받기 (PAPS X)
	- 운동 : 주로 여러 기관 (특히 눈) 간 협응 (e.g. 스포츠 스태킹 – 눈+손)
- 원리
	- 과부하의 원리 : 평소 체력(일상) 이상 강도
	- 점진성의 원리 : 운동량 점차 ↑
	- 반복성의 원리 : 규칙적으로 반복
	- 개별성의 원리 : 개인차 고려
	- 특수성의 원리 : 종목에 맞는 운동
- 계획·실천
	- 계획
		- 빈도
		- 시간
		- 강도
			- 토크 테스트 (저 —(노래)— 중 —(대화)— 고)
			- 심박수 : 0 — 안정 — 목표(60%) — 최대(220-연령)를 눈금으로 놓은 수직선. 안정~최대 구간을 묶어 「여유」, 목표(60%)에서 갈라져 「6:4 내분」

### 성장 및 안전 활동

- 성장 활동
	- 해로운 생활 방식 → 흡연, 음주, 약물 오·남용
- 안전 활동
	- 운동 시 안전사고 대처
		- 3C, Check / Call / Care
		- Care 단계 응급처치 : (P)RICE
			- Protect, Rest, Ice, Compress, Elevate(→ 심장 위로)
	- 수상 안전
		- 수영장 : 심장에서 먼 곳부터 물 묻히기, 준비운동
		- 바다 : 안전선, 해파리 바닷물·생리식염수
		- 강·계곡 : 다이빙 X
		- 대처 : 직접 구조 X
	- 빙상·설상
		- 스케이트 : 시계 반대로, 안전장비
		- 스키 : 직활강 X, 안전장비
	- 일상생활
		- 심폐소생술 : 의식 확인 → 신고 → 가슴 압박 → 기도 확보 → 인공호흡 → 반복
		- 온열 질환 : 일사병 → 열사병
