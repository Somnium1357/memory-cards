## 기초 문식성

### 낱자와 음소

#### 국어의 계열

- 의사소통
	- 음성 언어 - 음소(→ 뜻으로 구별) - 음절(→ 소리로 구별) - 단어 - 문장 - 문단 - 글
		- 음소
			- 자음
			- 모음
		- 음절
			- C+V
			- C+V+C
	- 문자 언어 - 낱자 - 글자 - 단어 - 문장 - 문단 - 글
		- 낱자
			- 자음자
			- 모음자
- "기본자" / "~음" / "~음자" ⇒ 구별해서 기억
- 기본자 (제자 원리상 기본) → 자·모음자 만들어짐 (문자언어)
- 자·모음 → 음성언어 계열

#### 모음과 모음자

- 모음자
	- 제자 원리
		- 기본자 "·, ㅡ, ㅣ" (≒ 천, 지, 인) ⇒ 상형의 원리
		- → 기본자끼리 한번 합성하여 초출자 "ㅗ,ㅏ,ㅜ,ㅓ" ⇒ 합성의 원리
		- → 초출자에 '·' 한번씩 합성하여 "ㅛ,ㅑ,ㅠ,ㅕ"
		- ※ 빠진 모음들은 "합용", 이중모음 표기 (≒ 병서)
- 모음
	- 단모음과 이중모음
		- 단모음: 발음시 조음 기관이 움직이지 않음
		- 이중모음: 발음시 조음 기관이 움직임
	- 단모음의 체계 (⇒ 키위제외해, 금붕어조아)
		- 기준: 혀의 전후 위치, 혀의 높낮이, 입술의 모양

#### 자음과 자음자

- 자음자
	- 제자 원리
		- 기본자 "ㄱ,ㄴ,ㅁ,ㅅ,ㅇ" (≒ 조음 기관 모양) ⇒ 상형의 원리
		- → 기본자에 획을 더하여 가획자
			- ㄱ→ㅋ
			- ㄴ→ㄷ→ㅌ
			- ㅁ→ㅂ→ㅍ
			- ㅅ→ㅈ→ㅊ
			- ㅇ→ㆆ→ㅎ
			- 가획했는데 소리가 세지지 않는 이체자
				- ㆁ
				- ㄹ
				- ㅿ
		- 가획의 원리
	- 병서: 자음 나란히 쓰기
		- 쌍자음 (각자 병서, 같은 거)
		- 겹자음 (합용 병서, 다른 거)
- 자음
	- 자음의 분류 (바다사자가/ㅁㄴㅇ/ㄹ/ㅎ)
	- 분류 기준: 조음 방법, 조음 위치, 세기

#### 삼지적 상관속

- 음소가 세기에 따라 분류, 한국어 음운체계 특징
- 뜻, 어감 구별

#### 한글의 특성

- 문자적 : 표음 문자, 음소 문자 (소리-문자 대응 일대일), 모아쓰기
- 음운 체계적 : 모음 조화, 소리의 길이로 의미 구별, 삼지적 상관속
- ※ 지도 시 유의사항
	- 자음자의 이름 → "C+ㅡ+C", "기역, 디귿, 시옷" 예외
	- 자음자 쓰는 순서 → ㅂ 쓸때 ㅣㅣ 먼저, 그다음 ㅡ. ㅌ 쓸때는 ㅡ 먼저, 마지막 ㄴ 한번에

### 글자와 음절

#### 글자

- 받침이 없는 글자
	- 짜임: 좌우, 상하, 상하우
	- 자형
		- 세로획이 있음 : 기울인 세모형
		- 세로획이 없음 : 바른 세모형
	- ㅜ, ㅠ ⇒ 마름모형
- 받침이 있는 글자
	- 짜임: 좌우 받침, 상하 받침, 상하우 받침
	- 자형
		- 세로획 ㅇ : 네모형
		- 세로획 X : 마름모형

### 단어

#### 음운 현상

- 대치 (음운의 수 그대로)
	- 음절의 끝소리 규칙 (평파열음화)
		- 음절의 끝소리가 평음화·파열음화 (평음화: 된·거센 → 예사, 파열음화: ㅅ,ㅈ→ㄷ)되어 "ㄱ,ㄴ,ㄷ,ㄹ,ㅁ,ㅂ,ㅇ"로 발음
	- 자음 동화
		- 비음화
			- "ㄱ,ㄷ,ㅂ"이 "ㄴ,ㅁ" 앞에서 비음 "ㅇ,ㄴ,ㅁ"으로 바뀌는 현상
		- 유음화
			- "ㄴ"이 유음 "ㄹ"로 바뀌는 현상
	- 된소리되기 (경음화)
		- 받침 뒤의 "ㄱ,ㄷ,ㅂ,ㅅ,ㅈ"가 된소리로 발음됨
	- 구개음화
		- 받침의 "ㄷ,ㅌ"이 "ㅣ"로 시작하는 형식 형태소(→ 조사, 어미, 접사)를 만나 구개음 "ㅈ,ㅊ"으로 발음
- 축약 (음운의 수 줄어듦)
	- 거센소리되기
		- "ㄱ,ㄷ,ㅂ,ㅈ"이 "ㅎ"과 만날 때 거센소리로 발음됨 ("ㅅ" 제외 → 조음방법이 같음)
- 탈락 (음운의 수 줄어듬)
	- 자음군 단순화
		- 음절의 끝소리에 오는 겹받침 중 하나가 탈락
			- 첫째 자음 : 일반적. [넓], [밟] 포함
				- 다만 '밟-'은 자음 앞에서 [밥] : 밟다[밥ː따], 밟는[밤ː는] ⟨교재 자료_기초문식성 26쪽 · 표준발음법 10항 다만⟩
				- 다만 '넓-'은 '넓죽하다[넙쭈카다]', '넓둥글다[넙뚱글다]'에서 [넙] ⟨교재 자료_기초문식성 26쪽 · 표준발음법 10항 다만⟩
			- 둘째 자음 : ㄺ,ㄻ,ㄿ, 단, 'ㄺ'+'ㄱ' → 'ㄺ'는 'ㄹ'로 발음
			- ※ 흙이 [흘기] 같은 연음 현상과 구분 (음운 수)
	- 'ㅎ' 탈락 (후음 탈락)
		- 'ㅎ' + 모음 어미·접미 에서 'ㅎ' 탈락
			- 받침의 'ㅎ' 음가 유지 X ⇒ 특히 받침의 'ㄶ' 구분
				- 않는[안는] : 자음군 단순화
				- 않은[아는] : 'ㅎ' 탈락, 연음
	- 표기반영
		- 'ㄹ' 탈락 : 솔+나무
		- 'ㅡ' 탈락 : 잠그+아
		- 동일 모음 탈락 : 가+아서
- 첨가
	- 'ㄴ' 첨가
		- 앞말이 자음으로 끝나고 뒷말이 'ㅣ,ㅑ,ㅕ,ㅛ,ㅠ'
	- 사잇소리
		- 합성어에서 'ㅅ' 첨가, 된소리/'ㄴ'/'ㄴㄴ'으로 발음

#### 오류 유형

- 음운 단위
	- 평음의 유기음화(거센소리화) : 갈치 → 칼치(X), 갈치(O)
	- 이중 모음의 단모음화 : 뭐더라 → 머더라(X), 뭐더라(O)
	- 중모음의 고모음화 : 그리고 → 그리구(X), 그리고(O)
- 단어 단위
	- 연음 오류 : 빛에 → 비세(X), 비체(O)
	- 동화 오류 : 강릉 → 강릉(X), 강능(O)
	- 된소리되기 오류 : 거꾸로 → 꺼꾸로(X), 거꾸로(O)
	- 첨가 오류 : 금요일 → 금뇨일(X), 그묘일(O)

### 문장

#### 문장의 종류와 문장 부호

- 종류
	- 평서, 의문, 감탄, 청유, 명령
- 문장부호
	- 마침표, 느낌표, 물음표, 쉼표
	- 큰따옴표(→ 직접인용, 말), 작은따옴표(→ 마음속 말, 생각)

#### 문장 성분

- 문장 : 문장 성분 + 종결 어미 + 문장 부호
	- 단어, 어절(→ 띄어쓰기), 구(→ 주술 관계 X), 절(→ 주술 관계 O)
- 주성분
	- 주어 : 누가/무엇이 → 서술어의 주체
	- 서술어 : 어떠하다(→ 형용사) / 어찌하다(→ 동사) / 무엇이다(→ 체언+서술격조사'-이다') → 주어의 상태·동작·성질 풀이
	- 보어 : '되다/아니다' 앞에서 보격 조사 '이/가'와 결합 → 서술어 보충
	- 목적어 : 무엇을 → 서술어의 대상
- 부속 성분
	- 관형어 : 체언을 수식 ⇒ 의존 명사 앞에 오는 경우 필수적
	- 부사어 : 주로 서술어를 수식 ⇒ 서술어의 자릿수에 따라 필수적 (두 자릿수 中 일부, 세 자릿수)
		- 한 자릿수 : 주+술
		- 두 자릿수 : 주+(목/부/보)+술
		- 세 자릿수 : 주+목+부+술
- 독립 성분
	- 독립어 ⇒ 감탄사, 호격 조사

#### 문장의 짜임

- 홑문장
	- 주-술 관계 하나
	- 홑문장의 분류
		- 한자리
			- 주어+서술어 ⇒ 무엇이+어찌하다/어떠하다 : 주어+용언
			- 주어+서술어 ⇒ 무엇이+무엇이다 : 주어+(체언+서술격조사'-이다')
		- 두자리
			- 주어+목적어+서술어 ⇒ 무엇이+무엇을+어찌하다
			- 주어+부사어+서술어 ⇒ 무엇이+무엇에+어떠하다/어찌하다
			- 주어+보어+서술어 ⇒ 무엇이+무엇이(가)+되다/아니다
		- 세자리
			- 주어+부사어+목적어+서술어 ⇒ 무엇이+무엇에게+무엇을+어찌하다
		- '어떠하다'(≒형용사) 서술어는 한자리, 두자리 中 부사어에만
- 겹문장
	- 주술 관계 둘 이상
	- 이어진문장
	- 안은문장

#### 각론

- 띄어 읽기
	- 주어부/서술어부 ⇒ 문장 시작에서 주어까지/주어 뒤부터 문장 끝까지
	- 의미 단위에 따라 어절/어구 단위로
	- 문장 부호에 따라 ⇒ 마침표,느낌표,물음표(⩔), 쉼표(∨), 글 끝에서는 띄어 읽기 X
- 흉내 내는 말(의성어,의태어) ⇒ 부사/부사어
- 꾸며 주는 말(관형어,부사어) ⇒ 관형어-체언, 부사어-용언

### 문단

#### 문단의 구조

- 여러 문장이 모여 하나의 중심 생각을 나타내는 글의 단위
	- 잘 드러난 문장 : 중심 문장
		- 중심 문장 지원 : 뒷받침 문장
- 여러 구조의 문단을 제시해 중심 문장이 반드시 문단 맨 앞이 아님을 지도
	- 두괄식, 미괄식, 양괄식, 무괄식 ; 무괄식은 간추리기 활동

#### 문단의 요건

- 통일성 : 의미적 연결 ; 하나의 중심 내용으로 통일
- 응집성 : 형식적 연결 ; 지시·접속 표현과 같은 담화 표지로 향상

#### 각론

- 지도 내용
	- 문단의 개념
	- 문단의 기능·역할
	- 중심·뒷받침 문장 관계
	- 문단의 형식

### 글

- 유창하게 읽기(읽기 유창성)
	- 자동성, 정확성
	- 표현성 ⇒ 어조, 강세, 속도, 억양 등의 표현 요소 활용 → 분위기 효과적으로 표현하기

## 문법

### 단어

#### 품사

- 2체계, 5기능, 9의미로 단어 분류
- 불변어
	- 체언(주·목·보)
		- 명사 : 의존 명사 → 관형어 필수, 띄어쓰기
		- 대명사 : 지시, 인칭
		- 수사
	- 수식언
		- 부사 : 용언, 문장 전체 수식
		- 관형사 : 체언 수식, 조사 X
	- 독립언 - 감탄사
	- 관계언 - 조사 : 체언 뒤, 서술격 조사(-이다) 가변어
- 가변어
	- 용언
		- 동사
		- 형용사
	- 서술격 조사
- 용언
	- 어간 + 어미(선어말, 어말), 어간 + 다 = 기본형
		- 시제·높임 기능
	- 용언의 활용. (⇒ 사례 보고 이름 매칭)
		- 규칙 활용
			- 기본형 : 어말, 어미 변화 X
			- 'ㄹ' 탈락 : 어간 끝의 'ㄹ'이 'ㄴ'으로 시작하는 어미 앞에서 탈락 (살다 ⊃ 살- + -는 → 사는)
			- 'ㅡ' 탈락 : 'ㅡ'가 '-아'/'-어'로 시작하는 어미 앞에서 탈락 (치르다 → 치르- + 어 → 치러)
		- 불규칙 활용
			- 어간만 바뀜
				- 'ㅅ' : '잇-' + '-어' → 이어 ; 어간 끝 'ㅅ'이 모음 어미 앞 탈락
				- 'ㅂ' : '돕-' + '-아' → 도와 ; ㅂ → ㅗ/ㅜ
				- 'ㄷ' : '걷-' + '-어' → 걸어 ; ㄷ → ㄹ
				- '르' : '흐르-' + '-어' → 흘러 ; 르 → ㄹㄹ
				- '우' : '푸-' + '-어' → 퍼 ; ㅜ 탈락
			- 어미만 바뀜
				- '여' : '일하-' + '-어' → 일하여 ; 어 → 여
				- '러' : '푸르-' + '-어' → 푸르러 ; '어' → '러'
			- 둘다 - 'ㅎ' : '파랗-' + '-아' → 파래

#### 국어사전에서 단어 찾기

- 활용
	- 가변어는 기본형을 찾는다 / 나머지는 기본형이 X (형태가 변하지 않으므로)
- 차례
	- 첫 자음 : (기본→쌍자음), ㄱ~ㅎ (ㄱ,ㄲ,ㄴ,ㄷ,ㄸ~)
	- 모음 : (기본→병서 ; 합자도 다시 순서 맞춰서), (ㅏ,ㅐ,ㅑ,…,ㅜ,ㅝ,ㅞ,ㅟ,…)
	- 받침 : (홑→쌍→겹), (ㄱ,ㄲ,ㄳ,ㄴ,…)

#### 동형이의어와 다의어

- 동형이의어 : 의미 간 유사성 X, 국어사전 뜻풀이 각각 (차다¹, 차다² …)
- 다의어 : 의미 간 유사성 O, 국어사전 중심 의미 → 주변 의미 (눈¹-「1」,「2」,「3」…)

#### 의미 관계

- 유의 관계
	- 항상 대체할 수 있지는 X ; 교체 검증을 통해 지도
- 반의 관계
	- 의미 자질 중 하나만 다름
	- 등급 : 중간 속성 O, 정도 부사 가능
	- 상보 : 중간 속성 X, 정도 부사 불가
	- 관계 : (대체로) 정도 부사 불가. 'X가 A이면 Y가 B이다' 성립
- 상하 관계
	- 포함될 때 의미 관계 ; 상대적

#### 어휘 지도 (명칭, 장점)

- 도구적 관점
	- 국어사전 찾기 : 의미를 정확하게 이해
	- 맥락 활용 지도 : 낱말이 사용되는 상황 파악
- 인지적 관점
	- 어휘 자체가 인지적 능력 ; 어휘 사이 관련성, 배경 지식 형성한다
	- 의미 자질 분석 : 의미 관계, 개념 차이 파악
	- 의미 구조도 그리기 : 공통점·차이점 도식화 ; 차이점·유사점 인식
	- 의미 지도 그리기 : 하나의 주제 중심, 관련된 어휘 연결 ; 배경지식, 계층 위계 구조 이해
- 기타
	- 말놀이
	- 어휘망 그리기 : 의미 관계 그리기
	- 형태 분석하기 : 접두·접미, 어근 분석
	- 단어 연상하기 : 사진·그림으로 기억
		- 단일 단어
		- 여러 단어
	- 시각적 변별 : 비슷한 단어를 시각으로 구별

#### 높임 표현

- 종류
	- 주체 높임
		- 주어를 높임 (-께서, -시, 어휘)
	- 객체 높임
		- 목적어, 부사어 높임 (-께, 어휘)
	- 상대 높임
		- 격식
			- 하십시오 ⇒ 윗사람
			- 하오 ⇒ 비슷
			- 하게 ⇒ 비슷, 아랫사람 존중
			- 해라 ⇒ 아랫사람 하대
		- 비격식
			- 해요 ⇒ 높이는 상황
			- 해 ⇒ 높이기 X
- 사용 방식
	- 관계 : 나이, 지위, 친소
	- 장면 : 공식 / 비공식

#### 지시·접속 표현

- 지시 표현 (가리키는 말)
	- 기능 : 응집성 ↑
	- 사용 방식 : 화자, 청자, 대상의 거리에 따라 표현 결정
- 접속 표현 (이어주는 말)
	- 기능 : 응집성 ↑
	- 사용 방식 : 문장 사이의 의미 관계에 따라 결정

#### 시간 표현

- 과거 시제 (사건시 → 발화시)
	- 선어말 어미 '-었', '-았'
	- 시간을 나타내는 부사어
- 현재 시제 (사건시 = 발화시)
	- 선어말 어미 '-는, -ㄴ', 관형사형 어미 '-는'
	- 시간을 나타내는 부사어
- 미래 시제 (발화시 → 사건시)
	- 선어말 어미 '-겠', 관형사형 어미 '-(으)ㄹ', 의존 명사 결합 '-(으)ㄹ 것'

#### 관용 표현

- 둘 이상의 단어가 합쳐져 새로운 의미를 가지는 것

- 속담 : 비유, 교훈, 풍자성 ↑

- 단계
	- 문제 확인 → 자료 탐색 → 지식 발견 → 지식 적용

## 읽기

### 읽기 과정 모형

#### 상향식 과정 모형 (= 글 중심 모형)

- 의미 구성 = 각 언어 단위의 정확한 해독
- ∴ 읽기 지도 = 해독 지도(→ 의미를 정확히 이해하도록 하는 활동)
- 배경지식, 맥락 영향 설명 불가능 (무의미 단어 문제, 동형이의어 문제)

#### 하향식 과정 모형 (= 독자 중심 모형)

- 의미 구성 = 스키마를 바탕으로 한 독자의 예상·추론, 텍스트는 이를 확인하는 용도
- ∴ 읽기 지도 = 배경지식 활성화, 예측·추론과 같은 읽기 전략 지도
- 미숙한 독자, 배경지식에서 먼 글(=어려운 글), 무작위 단어 나열 문제
- 스키마(≒배경지식)
	- 구조화된 지식
	- 내용 스키마 : 내용 지식
	- 구조 스키마 : 구조·형식에 대한 지식
	- 언어 스키마 : 의미 단위 간의 관계

#### 상호작용 과정 모형

- 의미 구성 = 독해의 과정에서 상향식·하향식 언어 처리가 병렬적으로 작동
- ∴ 읽기 지도 = 상향·하향 절충
- 사전적 설명력을 가진 모형이 아니라 사후적 설명 도구가 될 위험성 (⇒ 오류 진단이 안 됨)

#### 교섭 과정 모형 (= 사회·문화 모형)

- 의미 = 독자나 텍스트 내부가 아니라 읽기 사건에서 의미가 생성(→ 상황 맥락(독자의 자세), 사회문화적 맥락(해석 관습) 영향받음)
- ∴ 읽기 지도 = 대화를 통해 새로운 의미 구성, 비판적·창의적 읽기

### 과정 중심 읽기 지도

- 읽기의 과정을 강조, 각 과정에서 필요한 기능·전략 지도
- cf) 결과 중심 읽기 지도 ⇒ 결과 강조
- 기능 : 무의식적 작용, 사실·추론·감상·창의·비판적 읽기
- 전략 : 의식적 작용, 전략 학습을 통해 기능으로 전이.(= 읽기 활동, 전·중·후로 나뉨)

#### 읽기 전 활동 전략.

- 읽는 목적 설정하기
	- 목적에 따라 글의 종류, 읽는 방법 달라짐
- 미리 보기
	- 제목·목차·머리말 등 미리 보고 배경지식 활성화
- 연상하기
	- 글 안 읽고 내용 떠올리기, 배경지식 활성화
- 예측하기 (cf. 추론하기)
	- 책에서 읽게 될 내용(책에 써있는) 추측하기 ↔ 책에 없는 내용 추론하기
- 배경지식, 내용정리
	- KWL (Know, Want, Learned)
		- 읽기 전체 과정에서 활용, H(How)를 읽기 후 활동에 더하기도
	- SQ3R (Survey, Question, Read, Recite, Review)
		- 훑어보고 → 질문 → 읽기 → 암송 → 다시 읽기
- 설문 조사
	- 배경지식 활성화

#### 읽는 중 활동 전략

- 구조 파악하기
	- 글의 구조 파악, 도해 조직자 사용
- 질문하기
	- 교사 질문 / 학생 질문 생성 전략
	- 사고 수준에 따른 질문 유형
		- 사실적 질문 : 글에 답이 O
		- 추론적 질문 : 글에 드러나지 X
		- 비판적 질문 : 판단·평가
		- 감상적 질문 : 정의적
	- 사고 유형에 따른 질문 유형
		- 폐쇄적 질문
			- 인지·기억적 질문 : 단순 재생
			- 수렴적 사고 질문 : 분석
		- 개방적 질문
			- 확산적 사고 질문 : 다양한 생각 자유롭게
			- 평가적 사고 질문 : 비판·판단
- 추론하기 (cf. 추론적 읽기 기능, 예측하기)
	- 글에 드러나지 않은 내용 추측하기 (cf. 예측하기)
	- 스키마 + 맥락의 실마리 활용
- 중심 내용 파악하기
	- 문단 중심 문장 → 글 중심 내용
- 협의하기
	- 교사-학생 간 / 학생 상호 / 자기 협의(능숙한 독자)
- 메모하기
- 점검하기
	- 초인지(상위인지)에서 나옴, 읽기 과정 통제·조절
		- └ 교사 : 읽기 과정 점검 질문 촉진

#### 읽은 후 활동 전략

- 요약하기
	- 규칙
		- 삭제 : 예시·세부정보 삭제
		- 선택 : 중요내용 선택
		- 대체 : 하위어 나열 → 상위어 대체
		- 구성 : 중심문장 없으면 구성
	- 조건
		- 글쓴이 생각·의도 왜곡 X
		- 자기 언어로 재구성
- 의미 지도 그리기 (cf, 도해 조직자)
	- 내용을 자유롭게 그림으로 표현, 반드시 글의 구조 반영할 필요 X (↔ 도해 조직자)
- 장르 바꾸기
- 비판적 읽기 (기능 & 전략)
	- 준거 : 내용의 타당성(오류X, 일관성), 내용의 공정성(편향X), 자료의 신뢰성
- 창의적 읽기
	- 글쓴이 생각 + 배경지식 → 새로운 내용 구성
	- (ex. 해결책 찾기)

#### 과정 중심 읽기 지도의 원리

- 읽기 전략의 유동적 단계 적용
- 초인지 강조

### 평가

- 선다형 평가 (객관식)
- 빈칸 메우기법 (빈칸에 들어갈 내용)
	- 문맥 + 사전지식 이용 → 사실적 이해, 추론적 이해 평가
	- 정확단어(토씨) / 허용단어 채점
	- 장 : 과정평가, 타당, 신뢰도 ↑
	- 단 : 허용단어 채점시 객관성 문제
- 자유 회상 검사 (기억나는 내용 모두 쓰기)
- 중요도 평정 (중요X … 매우 중요)
	- 글을 의미 단위(보통 문장)로 쪼개고 중요도 판단
- 오독 분석법 (소리내어 읽고~)
	- 음성적으로 잘못 읽는 부분 분석 ; 읽기 과정에 대한 구체적 정보
- 자율적 수정 (아, 이게 아니라~)
	- 학생이 스스로 고쳐 읽는 행위 분석 ; 상위인지적 독해 능력 평가
- 프로토콜 분석
	- 학생의 사고 구술을 녹화·녹음한 자료 ; 초인지 직접 확인
- 관찰법
	- 체크리스트/일화 기록
- 포트폴리오법
- 요약하기 (전략&평가)

## 쓰기

### 쓰기 이론

#### 형식주의 작문 이론

- 개념
	- 쓰기 : 쓰기와 관련된 지식을(→ 장르 규범적 지식, 문법 지식) 글로 실현하는 과정
		- 쓰기는 선조적 (일방 선형적) 과정, 결과물을 중시
- 지도 방법 ⇒ 결과 중심 쓰기 지도
	- 지도 내용 : 장르 규범적 지식, 문법 지식
	- 교사 : 모범적인 텍스트를(→ 쓰기와 관련된 지식이 잘 반영된 텍스트) 분석해 쓰기 지식 전달, 결과물 점검・평가
	- 학생 : 수동적으로 모범적인 텍스트 모방, 반복적인 연습

#### 인지 구성주의 작문 이론

- 개념
	- 쓰기 : 개인이 쓰기 문제 해결 과정을 통해 글을 완성해 가는 과정
		- 쓰기는 회귀적(→ 상위 인지를 통한 조정하기에서 필요 단계로 회귀) 과정. 쓰기 전략과 그 선택을 위한 초인지 강조
- 지도 방법 ⇒ 과정 중심 쓰기 지도
	- 지도 내용 : 쓰기 전략, 상위인지
		- 능숙한 필자 : 수사적 맥락 고려한 독자 중심 글쓰기
		- 미숙한 필자 : 〃 X 자기 중심적 글쓰기
	- 교사 : 사고 구술법 같은 방법으로 조력, 안내
	- 학생 : 능동적으로 의미 구성

#### 사회 구성주의 작문 이론

- 개념
	- 쓰기 : 담화 공동체에서의 상호작용을 통한 의미 구성
		- 담화 규범 : 담화 공동체의 규범 ⇒ 이를 수용하는게 합의 (사회·문화적 맥락에 포함)
- 지도 방법 ⇒ 맥락 중심 쓰기 지도
	- 맥락과 담화 관습을 고려한 실제적 쓰기 결과물 (cf. 형식주의)
	- 교수 방법 ⇒ 쓰기 워크숍 ; 과정-결과 균형, 맥락 안에서 쓰기
	- 교사 : 촉진자, 안내자
	- 학생 : 상호작용을 통해 능동적 의미 구성

#### 장르 중심 작문 이론

- 개념
	- 장르 : 사회・문화적 요구가 반영된 글의 종류
	- 장르 지식 : 장르의 내용・형식적 특성에 대한 지식
- 지도 방법 ⇒ 장르 중심 쓰기 지도
	- 장르 지식과 맥락을 고려한 실제적 쓰기 결과물 (cf. 맥락 중심)
	- 교수 방법 : 책임 이양의 원리
	- 교사 : 촉진자, 안내자
	- 학생 : 장르 지식 이해

#### 대화주의 작문 이론

- 개념
	- 쓰기 : 텍스트를 매개로 한 독자와 필자의 대화 ⇒ 독자 역할 강조
	- 독자 역할
		- 협상 : 역동적인 의미 구성 과정
		- 공저자 : 협상을 통해 같이 의미를 구성하는 지위

### 토의

#### 배경지식

- 개념 : 문제에 대한 최선의 해결책 협의
- 유형
	- 회의
		- 개념 : 의제 채택 → 해결 방안
		- 용어 : 재청 (발언권 불필요)
		- 역할 : 사회자 (발언권 골고루)
	- 패널 토의 : (주로 시사적인 문제) 해결을 위해 청중 앞에서 배심원끼리 의견 교환
	- 심포지엄

### 토론

#### 배경지식

- 개념 : 경쟁적 의사소통 (cf. 토의 - 협력적)
- 논제
	- 유형 - 사실, 가치, 정책 논제
	- 조건 - 중립적인 긍정 평서문, 찬반 대립 O
	- 정책 논제 특징
		- 입증 책임 찬성측 (cf. 반박 책임 반대측) → 변화를 주장하는 논제
		- 필수 쟁점 : 문제 쟁점, 해결 방안 쟁점, 이익 쟁점
- 단계
	- 찬성으로 시작 - 찬성으로 끝 (입증 책임의 부담)
- 유형
	- 고전적
	- 반대 신문 → 폐쇄형 질문 효과적

#### 각론

- 토론하기
	- 절차 : 주장 펼치기 (입론) → 반론하기 → 주장 다지기 (최종변론) → 판정하기
	- 주장·이유·근거 : 근거 - 객관적 자료로 뒷받침 → 이유 - 주장의 까닭 → 주장
	- 유의점 : 상대방이 주장 펼치기에서 말한 내용만 반론
- 주장·이유·근거의 타당성 평가
	- 주장 : 가치·중요한지, 실천 가능한지
	- 이유 : 주장과 밀접한 관련, 다른 사람 수용 가능한지
	- 근거 : 이유·주장과 밀접한 관련, 객관성, 세부 정보 충분

### 대화

#### 배경지식

- 자아 개념 : 다른 사람들이 자기를 어떻게 생각하는지에 대한 스스로의 생각
	- 부정적 → 긍정적 by 칭찬, 긍정적 피드백
- 자아 노출 : 타인에게 자신의 정보 알리는 것 ⇒ 친밀감 형성에 중요
	- 속도·정도 조정 필요
	- 순서 : 사회적 차원 → 개인적 차원
- 나 전달법 : 나를 주어로 생각·감정 전달
- 공감적 듣기
	- 의미·효과 : 분석·비판 X, 상대방 관점에서 이해 ⇒ 대인관계 긍정적 영향
		- cf. 비판적 듣기 - 대인관계 악영향
	- 전략
		- 소극적 듣기 : 집중하기 (집중 확인), 격려하기 (이야기 이어나가도록)
		- 적극적 듣기 : 요약하기 (그대로 요약), 반영하기 (피드백)
- 순서 교대의 원리 : 말차례 지켜 가며 대화 ⇒ 말차례 교환 신호 따라서

#### 각론

- 칭찬의 방법
	- 언어적 강화 : 특성·결과 칭찬
	- 격려 : 과정 칭찬
	- 사회적 인정 : 사회적 영향 칭찬 (~덕분에)

#### 대화의 원리

- 협력의 원리 → 고의로 위반하여 대화 함축
	- 양의 격률 : 필요한 만큼만
	- 질의 격률 : 진실만
	- 관련성의 격률 : 목적·주제와 유관한 것만
	- 태도의 격률 : 간결·조리 있게
- 공손성의 원리
	- 관용 : 화자 혜택 ↓, 부담 ↑
	- 요령 : 청자 부담 ↓, 이익 ↑
	- 찬동 : 청자 비방 ↓, 칭찬 ↑
	- 겸양 : 화자 칭찬 ↓, 비방 ↑
	- 동의 : 이견 ↓, 일치 ↑
