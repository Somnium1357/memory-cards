1.국어 - 쓰기

쓰기 과제의 실제성 (2025 A 국어 3번)
실제성 : 작문 학습 활동이 교실 밖 학습자들의 실제 작문 활동을 반영하는가의 문제
작문의 주제, 목적, 예상 독자를 학습 활동에 구체적으로 구현해야 함
교육과정 쓰기 교수·학습 방법 : 실제로 글을 쓰는 활동 강조
발표·출판 ⇒ 다양한 독자의 반응 경험
실제 삶의 맥락 속 적극적인 필자로 성장
실제성 높이기 : 상황 맥락 구체화
상황 맥락 : 목적, 주제, 독자, 글쓴이의 입장, 매체 등 글 쓰는 상황에 직접 관여하는 맥락
기출 장면 : 「우리 문화재를 보호하자는 주제로 제안하는 글 쓰기」를 「교장 선생님께 제안하는 편지 써서 전달하기」로 수정
실제 독자 : 교장 선생님 (수정 전엔 독자 없음)
매체 : 편지 (수정 전엔 매체 없음)
삶의 문제인 주제 : 우리 학교의 개선해야 할 점 (수정 전 문화재 보호 = 학생 삶과 거리)
채점 키워드 : 독자, 주제, 매체 중 2
쓰기 불안(writing apprehension) : 쓰기 상황을 두려워하고 피하려는 정의적 경향 (2025 A 국어 3번)
기출 장면 : 관찰 기록 「쓰기에 관심이 없는 것인지, 쓰기 불안이 높은 것인지 불분명」
쓰기 흥미 : 쓰기에 대해 가지는 관심과 선호도 (관심 없음 쪽)
정의적 측면 평가 : 일회적 평가보다 누적적으로 평가 (같은 물음의 정답)
같은 문항의 다른 정의적 요인 : 쓰기 효능감 : 쓰기를 성공적으로 수행할 수 있다는 기대와 믿음
설명하는 글 : 정보성 높게 요구되는 장르 (2026 A 국어 2번)
자기 표현적 글(경험한 일, 편지)과 차이
기출 장면 : 「선생님, 쓸 말이 없어요」
원인 : 내용 지식(화제 지식) 부족
「어떻게」가 아닌 「무엇을」 쓸 것인가의 어려움 ⇒ 브레인스토밍만으론 내용 생성 어려움
쓰기 지식의 종류
내용 지식(화제 지식) : 필자가 화제와 관련하여 알고 있는 지식
담화 지식 : 언어 체계 및 언어 표현 맥락에 대한 지식 (맞춤법, 독자, 장르 지식 포함)
