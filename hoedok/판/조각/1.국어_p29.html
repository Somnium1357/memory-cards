2. 근거를 들어 주장하는 글

1) 논설문

개념 : 주장에 대한 이유, 근거를 들어 설득력 있게 쓴 글
주장 : 논증의 목적·결과 (의견)
이유 : 주장의 까닭 (주관적)
근거 (=논거) : 주장·이유를 뒷받침하는 구체적 정보·자료 (객관적)
사실 논거 : 통계, 과학, 상식…
소견 논거 : 전문가 의견, 경험과 진술 등
→
신뢰성 (사실과 부합)
타당성 (논리적 정합)
인용 : 다른 사람 말·글 가져오기
간접 인용 : 출처 밝히기, 인용 부호 X
직접 인용 : 출처 밝히기, 큰따옴표
논증 : 귀납, 연역, 유추
내용 요소
서론 : 문제 상황, 주장
본론 : 이유, 근거
결론 : 요약, 강조
