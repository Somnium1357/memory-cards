조소

1. 조소

조각 : 외부→안으로 파내기
+
소조 : 안→외부로 붙이기
/
환조 : 완전 입체
부조 : 반입체
조형 요소·원리 : 질감, 양감, 비례·균형, 동세
테라코타 : 초벌만 해서 만드는 흙인형

2. 찰흙

반죽 : 내부 기포 제거 → 점성·찰기↑
성질 : 가소성, 접착성, 유연성, 내화성, 변질성
수축성 → 건조 중 갈라짐 · 원인 = 두께가 고르지 않아서 (구멍 10-10)
표현 방법
분석적 : 전체→부분
종합적 : 부분→전체
붙이기 : 긋기, 흠집
뼈대 : 철사, 노끈
토우 : 흙으로 만든 인물상·동물상 (순장용·주술용)
잡상 : 궁궐 지붕 끝 장식 토우 → 궁궐 지키는 수호신 (구멍 10-05)
