우리 몸의 구조와 기능
→모형과 실제 차이 알아두기
근골격계
뼈와 근육
뼈 → 몸의 모양/기관 보호
근육 → 몸 움직이기/기관 보호
★모형/실제 : 모형은 공기가 불어넣어져 움직이지만 실제는 근육 자체가 움직임
소화계
종류
기계적 소화 → 저작 운동, 잘게 쪼개기
화학적 소화 → 소화 흡수(지도X)
소화기관
소화관 : 입, 식도, 위, 작은창자, 큰창자, 항문
작은창자 → 영양소, 수분 흡수
큰창자 → 수분 흡수
항문 → 소화 찌꺼기 배출(배설X)
소화샘 : 간, 쓸개, 이자 → 소화액 분비
호흡계
호흡기관
코, 숨관, 숨관가지, 폐
폐 → 외호흡(혈액과 폐포 사이 기체 교환)
기체 교환 원리 ⇒ 기체 간 농도 차이에 의한 확산
호흡 운동 원리 ⇒ 흉강의 크기 변화(가로막↓, 갈비뼈↑), 폐가 스스로 움직이는 것 X
모형/실제
종이봉투 : 흉강의 크기 변화 X
고무풍선 : 갈비뼈 움직임 X
순환계
순환기관 : 심장, 혈관
혈액 순환 과정
온몸 순환
⇒ 심장→ 동맥→ 모세혈관→ 정맥→ 심장
∴혈관끼리 연결되어있고, 폐쇄혈관계(조직세포X)
모형/실제 : 모형은 혈관끼리 연결X
폐 순환
배설계
배설기관
노폐물 배출 (cf. 소화 찌꺼기 배출)
콩팥, 오줌관, 방광, 요도
콩팥 → 노폐물 여과
오줌 생성 과정 ⇒ 콩팥에서 혈액의 노폐물 여과 (재흡수 지도 X)
모형/실제 : 모형에는 재흡수 과정 X (교사 지식 차원)
운동과 신체 변화
신체 기관의 유기적 관련성 ⇒ 기관은 각각 역할을 하며 유기적으로 관련
기관 : 몸에서 특정한 역할을 수행 + 여러 서로 다른 조직
cf. 혈액, 인대, 힘줄 → 단일 조직, 결합X
