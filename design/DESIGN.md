# 카드앱 디자인 스타일

`cards.html`(아이패드·아이폰 웹앱)이 쓰는 디자인 규칙을 다른 앱에서 가져다 쓸 수 있게 정리했다.
값은 전부 앱에 지금 들어 있는 것이다(2026-10-07 기준).

- **`design/tokens.css`** — 색·글자·모서리·여백 토큰. 이 파일을 넣고 규칙에서 `var(--c-*)` · `var(--t-*)` · `var(--r-*)` · `var(--sp-*)`만 쓰면 테마 셋(화이트·페이퍼·다크)이 같이 따라온다.
- 이 문서 — 토큰을 **어디에 어떻게** 쓰는지. §7이 스터디 현황(방·사람·10분 띠) 화면이다.

기준 기기는 아이패드 11″ 가로(1180×820)가 주이고, 아이폰(402×874)과 데스크탑(1440×900)이 뒤따른다.

---

## 1. 원칙 (부딪치면 위가 이긴다)

1. **애플 기본 앱처럼 보인다.** 시스템 글꼴, 떠 있는 유리 막대·패널, 캡슐 버튼, inset grouped 목록, 동심 모서리.
2. **강조색은 한 화면에 하나.** 나머지 색은 §2.4의 역할로만 쓴다. 장식으로 쓰지 않는다.
3. **숫자는 실데이터만.** 빈 상태에도 지어낸 값을 넣지 않는다. 모르면 `—`.
4. **오래 보는 화면은 조용하게.** 공부 중 띄워 두는 화면은 강조색을 한 톤 낮추고(§2.2), 움직임·빛 번짐을 빼고, 레이아웃이 흔들리지 않게 한다.
5. **정렬은 재서 맞춘다.** 같은 층의 글자·아이콘 왼쪽 x가 같아야 하고, 아이콘은 광학 중심으로 맞춘다.

## 2. 색

### 2.1 테마 셋 — 면과 글자

테마마다 바뀌는 건 면·글자 색뿐이다. 강조색·채점색은 화이트와 페이퍼가 같다.

| 토큰 | 화이트 | 페이퍼 | 다크 | 쓰임 |
|---|---|---|---|---|
| `--c-bg` | #F2F2F7 | #F2EEE6 | #000000 | 화면 바탕 |
| `--c-card` | #FFFFFF | #FBF9F4 | #1C1C1E | 카드·목록 |
| `--c-fill` | #EFEFF4 | #ECE7DD | #2C2C2E | 칩·막대 트랙·꺼진 토글·보조 버튼 |
| `--c-tile` | #FFFFFF | #FBF9F4 | #2C2C2E | 타일 |
| `--c-label` | #1D1D1F | #2B2824 | #F5F5F7 | 본문 |
| `--c-sec` | #6E6E73 | #6E6860 | #98989F | 보조 글자(대비 AA) |
| `--c-ter` | #8E8E93 | #8E877C | #8D8D93 | **아이콘 전용**(글자에 쓰면 AA 미달) |
| `--c-sep` | #E3E3E8 | #E2DCD0 | #38383A | 0.5px 구분선 |
| `--c-chev` | #C4C4C9 | #C7BFB2 | #5A5A5F | 목록 꺾쇠 |

- **유리**(떠 있는 막대·패널): `--c-glass` 면 + `backdrop-filter: blur(24px) saturate(180%)`(`-webkit-` 같이). 테두리 대신 `0 0 0 .5px var(--c-glass-ring)` 윤곽 + `0 8px 28px var(--c-glass-shadow)` 그림자.
- **카드 그림자**: `--sh-card`(보통) · `--sh-big`(화면의 주인공 카드). 페이퍼는 같은 값을 갈색 기운으로, 다크는 그림자 대신 흰 0.5px 윤곽.
- 다크 = 순검정 바탕 + 윤곽선. 흰 바탕 그림은 다크에서 `filter: brightness(.88)`.

### 2.2 강조색 — 바깥 화면 = 기본 톤 · 오래 보는 화면 = 중간 톤

| | 바깥 라이트 | 바깥 다크 | 중간 톤 라이트 | 중간 톤 다크 |
|---|---|---|---|---|
| `--c-acc` 글자·아이콘·진행 | #007AFF | #0A84FF | #2A6AD8 | #6FA3FF |
| `--c-acc-fill` 채움 버튼(흰 글자) | #007AFF | #0A84FF | #2A6AD8 | #3D7BE8 |
| `--c-acc-tint` 옅은 면 | rgba(0,122,255,.10) | rgba(10,132,255,.20) | rgba(42,106,216,.10) | rgba(111,163,255,.18) |

- 화면 루트에 `data-screen="solve"`를 달면 토큰이 중간 톤으로 바뀐다. 이 화면의 채움 버튼엔 빛 번짐(glow)을 주지 않는다.

### 2.3 채점 4색 (다시 · 어려움 · 알맞음 · 쉬움)

| 등급 | 라이트 글자 | 다크 글자 | 면 = 글자색 알파 (라이트 / 다크) |
|---|---|---|---|
| 다시 | #D1453B | #FF7F74 | .11 / .20 |
| 어려움 | #C7731A | #F4AA55 | .13 / .20 |
| 알맞음 | #2A8A52 | #62CC88 | .13 / .18 |
| 쉬움 | #2A6AD8 | #79AEFF | .11 / .22 |

- 버튼 = 옅은 면 + 색 글자 17/700 + **바닥 `inset 0 -3px 0` 글자색 띠**. 테두리·원색 채움은 쓰지 않는다.
- 색만으로 구분하지 않는다 — 늘 글자 라벨이 같이 있다.

### 2.4 시스템 색의 역할

| 색 | 라이트 / 다크 | 역할 |
|---|---|---|
| 파랑 `--c-acc` | §2.2 | 주 동작 · 선택 · 링크 · 「오늘」 · 나 |
| 주황 `--c-orange` | #FF9500 / #FF9F0A | 경고 · 플래그 · 밀림 |
| 초록 `--c-green` | #34C759 / #30D158 | 완료 · 진도 막대 · 켜진 토글 · **공부 중** |
| 빨강 `--c-red` | #FF3B30 / #FF453A | 최근 틀림 · 실패 알림 |
| 보라 `--c-purple` | #AF52DE / #BF5AF2 | 자꾸 틀리는 것 |
| 인디고 `--c-indigo` | #5856D6 / #5E5CE6 | 내일 · 범위 |
| 청록 · 분홍 | #30B0C7 · #FF2D55 / #40C8E0 · #FF375F | 새 분류용 |

- 위험해 보이지만 되돌릴 수 있는 동작(끄기·숨기기)은 빨강이 아니라 회색(`--c-sec`). 되돌릴 수 없는 삭제만 빨강 글자.

### 2.5 스터디 사람 색

- **나 = `--c-acc`**, 친구 = **방에 들어온 순서대로** 초록 → 주황 → 보라 → 분홍 → 청록 → 갈색(`--c-brown` #A2845E) → 인디고, 그다음은 처음부터 돈다.
- 한 사람 = 한 색. 그 사람의 목표 막대 · 오늘 10분 띠 · 「10분 1등」 띠 · 7일 선 그래프 · 찌르기 반짝임이 모두 같은 색이다.
- 상태 점 색은 사람 색과 따로다: 공부 중 = 초록 · 잠시 멈춤/접속 = `--c-acc` · 오프라인 = `--c-sep`(목록에선 빈 점).

## 7. 스터디 현황 화면

### 7.1 사람 줄 (홈 · 스터디 목록)

```
●  이름 나                                   184 / 300장  ›
   공부 중 · 1시간 30분 / 180분 · 교육학::행동주의
```

- 줄 = inset 목록 줄(최소 높이 60 · 왼쪽 20 · 오른쪽 16 · 사이 14).
- 왼쪽 상태 점 12(§2.5) · 이름 17/22(넘치면 말줄임) · 내 줄엔 이름 뒤 작은 「나」 13 `--c-sec`.
- 부제 13/18 `--c-sec` = `상태 · 오늘 시간[ / 목표분][ · 지금 덱]`. 오프라인이면 상태 대신 `마지막 hh:mm`.
- 오른쪽 = 오늘 장수 20/600 `--c-label` + `/ 목표장` 15 `--c-sec` + 꺾쇠.
- 순서: **나 먼저**, 그다음 공부 중 → 잠시 멈춤 → 접속 → 오프라인, 같으면 장수 많은 순.
- 머리에 `n명 접속 중`(오프라인 아닌 사람 + 나).
- 날이 바뀌었는데 친구 숫자가 어제 것이면 `—`로 둔다(어제 숫자를 오늘처럼 보이지 않는다).

### 7.2 공부하면서 띄워 두는 패널 (아이패드 가로 · 옆 레일)

공부 화면 오른쪽 패널을 「피드백 ↔ 스터디」로 바꿔 띄운다. 덮는 창이 아니라 키 입력을 막지 않는다. 스터디일 때 패널 폭은 340이다.

```
임용 같이                          3명 접속 중     ← 방 이름 13/600 sec · 오른쪽 13 sec
10분 1등                                           ← 11/600 sec
[▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁]            ← 칸마다 그 칸 1등의 사람 색
─────────────────────────────────────
● olive                       공부 중 · 방금      ← 점 8 · 이름 17/22 · 상태 13/18(공부 중이면 초록)
  184장    54장      1:30      2                  ← 값 17/22 600 · 단위 12 sec
  오늘     최근 1시간 공부 시간  분당 장수          ← 11/14 sec
  ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━  184 / 300장   ← 막대 4 · 사람 색 · 오른쪽 12 sec
  지금 교육학::행동주의                             ← 13/18 sec · 덱 이름만 label 색
  [▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁]
  04      10      16      22      04              ← 10/12 sec · 불투명 .8
─────────────────────────────────────
방 오늘 261장 · 21:00에 받음                        ← 12/16 sec · 패널 맨 아래
```

- 사람 칸: 안쪽 12/12/14 · 줄 사이 8 · 칸끼리 0.5px `--c-sep` 선. 점 다음 내용은 왼쪽 18 들여 시작 x를 맞춘다.
- 숫자 칸 넷은 `grid` 4열 같은 폭. 값이 0이면 굵기 400 · `--c-sec`로 흐리게, 모르면 `—`.
- 「최근 1시간」 = 지금 칸 포함 10분 칸 여섯의 합. 「분당 장수」 = 오늘 장수 ÷ 공부 분(1분 미만이면 `—`).
- 목표 막대·「지금 덱」 줄은 값이 있을 때만 그린다(없으면 줄이 생기지 않는다).

### 7.3 오늘 10분 띠

- 방 하루(방 시간대의 04:00부터 24시간) = **10분 144칸**을 가로 한 줄 SVG로(`viewBox="0 0 144 10"` · `preserveAspectRatio="none"` · 높이 8 · 반경 2).
- 바탕 = `--c-fill` 한 장 · 활동이 있는 칸 = 폭 .84짜리 막대(칸 사이 틈) · 색 = 그 사람 색(1등 띠는 칸마다 1등의 색).
- **지금 선** = 폭 .4 · `--c-label` · 불투명 .55.
- 축 = 0·36·72·108·144칸 = 04 · 10 · 16 · 22 · 04 (방 시간대 기준).

### 7.4 찌르기 — 칸에 아무것도 얹지 않는다

- 패널의 친구 칸을 **두 번 톡**(같은 칸 · 350ms 안 · 20px 안) 하면 찌른다. 한 번 톡으로는 찌르지 않는다(잘못 누르기 쉽다). 내 칸은 반응하지 않는다.
- 버튼·글자·알약을 칸에 더하지 않는다 — 이름이 잘리고 칸 높이가 사람마다 달라진다.
- 찌르면 그 칸이 **그 사람 색 24% → 0으로 0.8초** 반짝이고, 토스트 「○○님을 콕 찔렀어요」.
- 1분 제한 안이거나 요청 중이면 반짝임 없이 토스트 「같은 사람은 1분에 한 번 찌를 수 있어요」만.
- 패널엔 `touch-action: manipulation`(두 번 톡 확대를 끈다) · 친구 칸엔 `user-select: none` · `-webkit-touch-callout: none`.
- 받은 찌르기 = 토스트 「○○님이 콕 찔렀어요」(여러 번이면 `○○님(2번)`) + 진동 80ms(되는 기기만).

@keyframes poke { from { background: color-mix(in srgb, var(--pk) 24%, transparent); } to { background: transparent; } }

## 8. 상태

- **빈 상태**: 제목 17/600 + 설명 15 `--c-sec` + 보조 캡슐 하나. 삽화 없음.
- **오프라인**: 도구 막대에 주황 알약 32 「오프라인 · n건 대기」만. 띠·모달 없음.
- **못 받음 ≠ 없음**: 서버에서 못 받았으면 0이 아니라 `—`와 「친구 기록을 못 받았어요」. 마지막으로 받은 시각을 같이 쓴다(`hh:mm에 받음`).
- **불러오는 중**: 앱 아이콘 + 한 줄 + 막대. 스피너 없음.

## 9. 문구

- 해요체 · 짧게 · 결과 먼저(「오늘 큐만 비워요 — 범위·성적은 그대로예요」).
- 영어 섞지 않기. 머리글·라벨은 담담하게.
- 날짜: 문장 `9월 23일 (수)` · 좁은 곳 `9/23` · 시각 `21:09`(24시간).
- 숫자 뒤 단위는 붙인다(`526장`) · 조사 앞 띄어쓰기 없음.

## 10. 접근성

- 누름 대상 44 이상. 촘촘한 목록 안 칩·보조 캡슐만 36, 34 미만은 없다.
- 글자 대비 AA 4.5:1(모든 테마). `--c-ter`는 아이콘 전용.
- 아이콘만 있는 버튼엔 `aria-label`, 토글엔 `role="switch"`. 그래프 SVG엔 `aria-label`(예: 「오늘 10분 단위 활동」).

## 11. 새 화면을 만들 때

1. 최상위 화면 / 들어간 화면(맨 위 44 줄 = 유리 원형 「‹」 + 오른쪽 유리 캡슐 동작) / 시트 중 무엇인지 정한다.
2. 색은 §2 역할표에서만 고른다. 새 색이 필요하면 역할부터 정한다.
3. 크기·반경·여백은 §3~§6 값만 쓴다.
4. 아이패드 가로 · 아이폰 × 라이트 · 다크로 그려 보고, 글자 잘림·넘침·34px 미만 버튼이 없는지 본다.
