1) 컴퓨터를 이용한 문제 해결 과정

문제 찾기
→↓
문제 분석하여 문제 상태 정의

→↓
절차적 사고 바탕으로 알고리즘 설계
→↓
프로그래밍

2) 알고리즘

의미 : 절차적 사고로 만들어진 문제 해결 절차
표현
자연어 : 일상 언어
의사 코드 : 자연어를 컴퓨터 언어처럼 표현
순서도 : 기호·도형으로 절차 표현
순서도의 기호
타원 : 시작과 끝
직사각형 : 해야 할 일의 내용
마름모 : 조건의 비교와 판단
화살표 : 일의 처리 과정

3) 언플러그드 활동

의미 : 컴퓨터 없이 알고리즘·CS 원리 학습

성취기준 해설 (성취기준 · 해설)

성취기준 해설

[6실05-01] 해설: 언플러그드 활동 등을 통한 문제 해결 과정을 알고리즘으로 작성하기 위해 자연어, 의사코드, 순서도 등으로 문제 해결 과정을 표현하도록 한다.

2. 프로그래밍

1) 알고리즘의 구조

순차 구조 : 제시된 순서 따라 순차
선택 구조 : 조건에 따라 선택 (if, elif, else)
반복 구조 : 조건 만족/만족할 때까지 반복 (while, while not)

2) 엔트리

방향 : 오브젝트가 기울어진 방향
이동 방향 : 오브젝트 방향과 이동 방향 화살표 사이 각도

3) 컴퓨팅 사고력

⇒컴퓨팅 개념, 원리 기반으로 일상적 문제 해결 능력 ; 추상화 + 자동화

3. 디지털 데이터와 인공지능

성취기준

성취기준

[6실05-04] 디지털 데이터와 아날로그 데이터의 특징을 이해하고, 인공지능에 활용할 수 있는 데이터의 유형이나 형태를 탐색한다. (구멍 09-30)

[6실05-05] 인공지능이 만들어지는 과정을 체험하고, 인공지능이 사회에 미치는 영향을 탐색한다.

1) 데이터 표현 방식

아날로그 : 연속적
디지털 : 이산적

2) 인공지능의 학습

많은 양의 디지털 데이터 사용

3) 기계학습

지도학습 : 문제 + 정답(레이블) 제공 (e.g. teachable machine)
비지도학습 : 문제만 제공
강화학습 : 행동 → 보상

해설 · 적용 시 고려 사항 (성취기준 · 해설 · 적용 시 고려 사항)

성취기준 해설

[6실05-05] 해설: 기계학습이 적용된 간단한 인공지능 도구의 체험을 통해 기계학습의 기본 원리를 이해하고 인공지능으로 인한 사회의 발전과 직업의 변화를 이해하여 인공지능이 사회에 미치는 영향을 탐색할 수 있어야 한다.

적용 시 고려 사항

고려 사항: 다양한 사례로 데이터의 의미를 파악하는 활동을 통해 디지털 소양을 함양하도록 한다.

고려 사항: 인공지능 기술을 단순히 체험하는 것을 넘어 인공지능의 기계 학습 과정을 이해할 수 있도록 지도하여 학생들이 인공지능 소양을 함양할 수 있도록 한다.
