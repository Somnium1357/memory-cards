1) 성장 활동

해로운 생활 방식 → 흡연, 음주, 약물 오·남용

2) 안전 활동

운동 시 안전사고 대처
⇒3C, Check / Call / Care

Protect, Rest, Ice, Compress, Elevate (→ 심장 위로)
수상 안전
수영장 : 심장에서 먼 곳부터 물 묻히기, 준비운동
바다 : 안전선, 해파리 바닷물·생리식염수
강·계곡 : 다이빙 X
대처 : 직접 구조 X
빙상·설상

스키 : 직활강 X, 안전장비
일상생활
