Ⅰ. 과정 - 학습 필수 요건

→MAP (Motivation, Activation, Personalization)
Motivation : 동기 부여
Activation : schemata 활성화
personalization : 개별화

Ⅱ. 유창성과 정확성

유창성 (fluency) : 언어 체계 빠르게 작동 → 합창, 반복 → 의사소통 향상
정확성 (Accuracy) : 언어 체계 부합하게 작동 → feedback 제공 → 통제 연습
모델링 (modeling) : 교사가 말로만 설명하지 않고 과업 수행 방법을 직접 행동으로 보여주는 기법 (구멍 09-22)
