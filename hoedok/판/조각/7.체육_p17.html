종류
앞차기 : 발등
옆차기 : 발날
연습
끝까지 바라보기 : 정확
무릎 들기 : 높은 곳
벽 잡기 : 균형

6) 헤엄치기

동작
숨쉬기 : 물 안에서 코로 내쉬고 밖에서 입으로 들이마시기 ⇒ 횡호흡, 머리가 높아지면 하체가 가라앉음
발차기 : 무릎 펴고 다리 전체로 물 누르듯, 엄지발가락까지 닿듯이
팔젓기 : 손으로 물을 끌어당김
응급처치
과호흡 : 종이봉투로 코와 입 동시에 호흡 (비닐 X)
쥐 : 근육 늘리기
코피 : 머리 앞으로 숙이기

2. 전략형 스포츠 유형별 움직임

⇒영역형, 필드형, 네트형

1) 공 던지기와 잡기

종류
가슴 높이 : 정확하고 빠르게, 가까이
바닥에 튀기기 : 방해를 피해, 거리 2/3 지점에서 튀기도록
머리 위 : 멀리

2) 공차기와 멈추기

종류
낮게 : 가까이, 정확 / 발 안쪽
높게 : 멀리, 강하게 / 발등
⟶
멈추기 : 내밀었던 발을 뒤로 당기기

손

길게 : 빠르게, 한손 가능
