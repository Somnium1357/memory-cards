## 사회과 교수·학습 모형

### 개념 학습 모형

- 개념: 사례 → {속성/분류} → 명명. 논리적 이해
- 구조: 위계 {상위/하위/동위}, 속성 {접합/이접/관계}
	- 접합(결합) 개념 : 여러 속성이 밀접히 결합해 형성 ⟨교재 사회 기본이론서 p60 · 동하 요청 · 09-29⟩
	- 이접 개념 : 독립 속성 중 하나만으로 형성 ⟨교재 사회 기본이론서 p60 · 동하 요청 · 09-29⟩
	- 관계 개념 : 하나가 다른 것 전제 → 상관관계 ⟨교재 사회 기본이론서 p60 · 동하 요청 · 09-29⟩

#### 속성 학습 모형

- 장점 : 논리, 연역적↑
- 단점 : 추상·어려움↓
- "속성" 중심 (2단계)

| 단계       | 결과       |
| -------- | -------- |
| 문제 제기    | (사회 집단)  |
| 속성 제시·정의 | 결+비결     |
| 속성 검토    |          |
| 사례 검토    | 예·비예 검토  |
| 가설 검증    | 사례 보고 판단 |
| 개념 분석    | 유사 개념?   |
| 관련 문제 검토 | 사회문제 적용  |
| 평가       | 평가       |

#### 원형 학습 모형

- 장점 : 개념이 추상·모호 → 구체적 예로 이해↑
- 단점 : 여러 사례가 한 개념으로 분류되는 기준을 제시하기 어렵다 ※동하 09-26 문구 교체(노트 원문: 한 개념에 여러 속성 → 추출 불가)
- 원형(전형적 사례) 중심
- 문제 제기 → 원형 제시 → 비례 제시 → 속성 검토 → 개념 분석 → 관련 문제 → 평가

#### 상황 모형

- 상황: context - 학생 경험, 거리…
- 삶과 연결 but 추상화는?
- 문 → 상황 제시 → 사례 검토 → 속성 검토 → 개 → 문 → 평
	- (※ 마지막 세 칸은 한 음절 축약. 속성 학습 모형 단계와 대응시키면 개=개념 분석, 문=관련 문제, 평=평가)

### 탐구 학습 모형

- 실제이론을 도출한 과정(=탐구 과정) 재현
	- 이론 = 일반화된 지식
	- 과학적 방법(사회과학 이론이니)
		- 어려우니 교사 주도 가능(비중 문제)
	- 문제 → 가설 → 자료 수집·분석 → 결론·일반화
- 콕스
	- 문제 파악 → 가설(→ 잠정적) 설정 → 탐색(→ 계획수립) → 증거 제시(→ 자료 수집·분석) → 일반화
- 뱅크스
	- 문제 제기 → 가설 설정 → 용어 정의·개념화 → 자료 수집 → 자료 분석 → 가설 검증, 일반화
- 가설 검증 자료의 종류 결정 기준 : 개념·변수의 대표성, 수집 가능성 ※구멍 09-28

### 문제 해결 학습 모형

- 일상 문제 = 학생들이 일상생활에서 마주치는 문제
- 일상 문제에 대한 체계적 탐구 → 문제 해결 능력
- 문제 확인 → 원인 파악 → 해결 방안 탐색 → 해결 방안 결정 → 실천

### 의사 결정 학습 모형

- Why? → 사실 문제 + 가치 문제 혼재된 개인적·사회적 문제 해결
- 의사 결정력 함양
- 뱅크스, 합리적 의사 결정 모형
	- 문제 제기 → 사회 탐구(→ 지식 획득) → 가치 탐구(→ 가치 판단(선택)+정당화) → 의사 결정 → 행동
- 의사 결정 매트릭스
	- 문제 정의 → 대안 나열 → 선택 기준 작성(→ 사실·가치 판단 단계) → 대안 평가 → 의사결정
- + pros
	- 행동 실천 있음
	- 의사 결정력 ↑
- − cons
	- 합리적 의사 결정이 옳은가? (내적-절차적 합리성만)
	- 공동체 모두의 이익 아닐수도

### 논쟁 문제 학습 모형

- 의견 대립, 공동체 구성원 다수에게 영향(사회적 문제), 명확한 정답 X
- 의견 대립
	- 용어 정의 문제
	- 사실 문제
	- 가치 문제
- 각 측면에서 입장 선택, 옹호
	- 가치 문제 = 기본 가치, 헌법적 가치, 법률 등 가치 갈등 해결 기준에 입각
- + pros
	- 의사 결정력 함양
- − cons
	- 인지주의적 오류
	- 보수적 규범 주입
	- 공연한 논쟁, 급진적
	- 보편 규칙 찾기 어려움
- 교사의 입장
	- Kelly
		- 배타적 중립형
		- 배타적 편파형
		- 중립적 공정형
		- 신념을 가진 공정형
	- Harwood
		- 옹호 (소개→의견)
		- 관심 (의견→소개)
		- 신념 (의견만)
		- 객관 (의견X, 서술)
		- 공정한 의장 (의견X, 토론)
		- 악마 옹호 (반대의견만)

| 다양\의견 | O          | X          |
| ----- | ---------- | ---------- |
| O · K | 신공         | 중립적 공정     |
| O · H | 옹호, 관심     | 객관, 공정한 의장 |
| X · K | 배타적 편파     | 배타적 중립     |
| X · H | 신념          | —          |

- 문제 제기 → 개념 명료화 → 사실 확인(→ 경험적) → 가치 갈등 해결(대립 가치 분석) → 대안·결론
- 행동 단계 X

### 협동 학습 모형

- 이질적 집단, 긍정적 상호의존, 개별적 책무성 강조
	- (나타나지 않으면 전통적 소집단 학습)
- 수업 모형
	- 장점 추출 → Jigsaw Ⅱ
		- Jigsaw I
		- STAD (집·성·분·모) ※정정 10-09(사회,도덕,음악_기본이론서 p79 · 전사 「오」)
	- Jigsaw I
		- 소집단 구성 → 전문가 학습지 배부(→ Jigsaw Ⅱ 차이) → 전문가 모둠 학습 → 원모둠 학습 → 학습지 작성·정답 확인 → 개별 평가·개별 보상(→ Jigsaw Ⅱ 차이)
	- STAD
		- 소집단 구성 → 안내 학습지 배부 → 모둠 학습 → 학습지 작성·정답 확인 → 개별평가·집단보상(향상 점수), (→ Jigsaw Ⅱ)
	- Jigsaw Ⅱ
		- 소집단 구성 → 전체 학습지 배부(→ 하위주제 = 모둠원 수 맞추기) → 전문가 모둠 학습 → 원모둠 학습 → 학습지 작성·정답 → 개별평가, 집단 보상(향상점수)
		- ※ 향상점수? → 학생이 향상된 정도 점수화
	- +α
		- TGT (Teams - Games - Tournament)
		- TAI (Team Assisted Individualization)
		- GI (Group Investigation)

### 가치 학습 모형

- 가치·태도 학습 for 가치 판단·사회 생활 적응
- ※ 가치 학습 계보
	- 주관적
		- 가치 주입 (교화) : 반복, 암기. 인지주의적 오류
		- 가치 명료화 : 개인적 가치 명료화. 상대주의 문제, 가치 판단 X
	- 객관적
		- 가치 분석
		- 가치 탐구
		- 공통점 : 합리적 가치 판단 목적. 가치 결정력 함양. ／ 차이점 : "평가" ⇒ 내재적 합리만?(=사실 확인, 절차 검증) ／ 외재적 합리도?(=평가, 대안 가치 분석, 대안 검토)
- 가치 명료화
	- 가치 선택 → 가치 존중(=소중히) → 행동
- 가치 탐구(분석)
	- 문제 제기 → 가치 문제·갈등 확인 → 대안 검토·예측 → 가치 선택, 행동.(→ 합리적; 정당화 가능해야)

## 사회과 수업 기법

### 현장 학습

- 교과 - 실제 상황 연결 ⇒ 생생한 이해(목적이 문제해결 : 체험 학습)
- 간접 현장 학습 : 교실로 삶의 현장 들여오기 (초빙)
- 직접 〃 : 삶의 현장 방문하기 (방문)
- ∴ 학습 내용-현실 정합성↑, 협동심, 사회 참여 능력↑
- 유의점
	- 사전 답사·조사 필요
	- 면담 준비 (사진, 녹음기)

### 지도 학습 (지리)

- 도해력 함양이 목표
- 도해력 : 공간 정보 (해석)⇄(가공·변환) 시각 정보
- 유형 : 위치 학습, 방향 학습, 투영법 학습, 기호 학습, 거리 학습

### 사료 학습 (역사)

- 역사적 자료(=사료)를 해석, 당대 사회상 재구성 → 역사적 의미 부여
- 1차 사료 : 당대에 작성
- 2차 사료 : 후대에 작성
- 유의점
	- 사료 신뢰성 판단
	- 번역 정확한지
	- 학습자 발달 단계 맞게. (⇒ 사료 재구성)

### 인물 학습 (역사)

- 인물의 행동에 영향 미친 배경 이해. 결과 분석 ⇒ 인물 입장에서 사고하는 능력
- cf) 민중 역할 강조, 지역사회·여성 인물 소개

### 극화 학습

- 사회 현상을 단순화·추상화하여 학습 ⇒ 가상 상황 구성
	- 단순화, 추상화 : 사실성과의 Trade-off 있음
	- 사회 현상 단순화 : 문제 상황 현실감 있게 인식 → 문제 해결력↑
	- 가상 상황 : 감정 이입 능력↑
- 기준: 규칙·체계·승패 유무
	- 역할놀이 학습 : 역할 배정, 목표X, 체계X
	- 모의 학습 (=시뮬레이션) : 목표O, 체계O, 승패 정함

### 그 외 학습 기법

- 프로젝트 학습 : 학생 스스로 주제 탐구 ⇒ 문제해결력
- 시사 학습 : 새롭게 나타난(=시의성 있는) 주제를 다양한 매체에서 정선 → 재구성하여 학습
	- └ 예전 교육과정에는 신문 활용 학습(NIE) ∴ 흥미↑, 현실-교과 괴리감↓

### 사회과 평가 방법

- 면접법 : 대화로 정보 수집 · 주로 정의적·행동적 영역 평가 ※구멍 09-27
- 구술시험 : 질문-대답 과정 평가(면접법과 유사) · 주로 특정 주제·문제에 대한 인지적 능력 평가 ※구멍 09-27
- 찬반 대립 토론 평가법 : 개인·소집단별 찬반 토론 → 자료의 다양성·충실성 / 토론 내용의 충실성·논리성 / 반대 의견 존중 태도 / 진행 태도 등 종합 평가 ※구멍 09-27
- 연구 보고서법 : 연구 주제에 대해 스스로 자료 수집·분석 → 보고서 제출 (≒ ‘프로젝트법’) ※구멍 09-27

## 사회과 교육의 목표

### 시민성

- 지식
	- 근거에 기반 / 보편타당한 / 인식 (JTB)
	- 사실 → 개념 → 일반화
- 기능
	- : 문제·개념 인식/해결 능력
- 가치·태도
- +α 목표 영역
	- 지식·이해
		- 통합
		- 역사
		- 지리
		- 일반사회
	- 과정·기능
		- 지식·정보 획득/분석/조직/활용능력
		- 사회 참여, 의사 결정, 탐구
	- 가치·태도

### 고차사고력

- 탐구능력 (≒ 문제 해결력)
	- 문제 발견 → 가설 설정 → 자료 수집·분석으로 해결 방법을 스스로 찾는 사고력 ※교재 보강(사회,도덕,음악_기본이론서 p101-102 · 공개 사이트 제보 10-09)
- 의사 결정 능력
	- 여러 대안 중 추구하는 목표에 적합한 것을 선택하는 능력 ※교재 보강(사회,도덕,음악_기본이론서 p101-102 · 공개 사이트 제보 10-09)
- 창의적 사고력
	- 새로운 방법으로 문제를 해결하거나 상황을 변화시켜 독창적인 것을 만드는 능력 ※교재 보강(사회,도덕,음악_기본이론서 p101-102 · 공개 사이트 제보 10-09)
- 비판적 사고력
	- 사물·상황·지식의 정확성·진위를 평가하는 이성적 판단력 ※교재 보강(사회,도덕,음악_기본이론서 p101-102 · 공개 사이트 제보 10-09)
- 메타 인지 능력
	- 자신의 사고 과정이 잘 되고 있는지 반성하는 정신적 작용 ※교재 보강(사회,도덕,음악_기본이론서 p101-102 · 공개 사이트 제보 10-09)

### 사회과 역량

- 창의적 사고력, 비판적 사고력, 문제 해결력 및 의사 결정력, 의사소통 및 협업 능력, 정보 활용 능력

### 사회과 목표 영역

- 지식·이해 → 통합, 지리, 역사, 일반사회
- 과정·기능 → 정보 획득·분석·조직·활용, 탐구 능력, 의사 결정 능력, 사회 참여 능력

### 교육과정 설계의 개요

사회과는 총론에서 비전으로 제시한 '포용성과 창의성을 갖춘 주도적인 사람'과 연계하여 사회과 역량을 **창의적 사고력**, **비판적 사고력**, **문제 해결력 및 의사 결정력**, **의사소통 및 협업 능력**, **정보 활용 능력**으로 설정하였다.

사회과는 '지리 인식', '자연환경과 인간생활', '인문환경과 인간생활', '지속가능한 세계', '정치', '법', '경제', '사회·문화', '역사 일반', '지역사', '한국사' 등의 **영역**을 중심으로 구성되었다.

#### 영역군 (손글씨 라벨 — 지리/일사/역사)

##### 지리 영역군

- 지리 인식 / 자연환경과 인간생활 / 인문환경과 인간생활 / 지속가능한 세계

##### 일반사회 영역군

- 정치 / 법 / 경제 / 사회·문화

##### 역사 영역군

- 역사 일반 / 지역사 / 한국사

사회과의 **지식·이해**에는 학생이 시민의 역량을 형성하기 위해 인간과 공간, 인간과 사회, 인간과 시간 관련 현상을 이해하는 데 필요한 지식으로 구성되었다.

**과정·기능**은 시·공간 속의 인간과 사회현상을 탐구하고, 관련된 여러 가지 문제나 쟁점을 분석하며, 다른 사람 및 집단과 소통하여 해결하는 과정에서 필요한 기능으로 구성되었다.

**가치·태도**는 민주적 기본 가치 및 지구적 가치와 시민이 갖추어야 할 태도로 구성되었다.

### 성격 및 목표

사회과는 학생들이 사회생활에 필요한 **지식**과 **기능**을 익혀 이를 토대로 **시·공간** 속의 인간과 사회현상을 인식하고, 민주 사회의 구성원에게 요구되는 **가치와 태도**를 지님으로써 **시민**로서의 자질을 갖추도록 하는 교과이다.

- 시(시간) : 역사
- 공간 : 지리
- 사회현상 : 일반사회

#### 사회과에서 기르고자 하는 시민

- 사회과에서 기르고자 하는 시민은 인간과 사회현상을 탐구하고 지역사회, 국가, 세계에서의 생활에 참여하는 데 필요한 지식과 기능의 습득을 바탕으로 자율적으로 판단하고 행동한다.
- 또한 공동체 의식을 가지고 타자를 존중하고 배려하면서 개인적, 사회적 문제를 합리적으로 해결하는 능력을 갖추어 개인의 성장을 도모하고, 지역사회·국가·세계의 발전에 기여한다.

#### 사회과 교과 역량

**창의적 사고력**은 새롭고 가치 있는 아이디어를 생성하는 능력을 의미하며, **비판적 사고력**은 사태를 분석적으로 평가하는 능력을 의미한다.

**문제 해결력 및 의사 결정력**은 다양한 사회적 문제를 해결하기 위해 합리적으로 결정하는 능력을 의미하며, **의사소통 및 협업** 능력은 자신의 견해를 분명하게 표현하고 타인과 효과적으로 상호 작용하는 능력을 의미한다.

또한 **정보 활용** 능력은 다양한 자료와 테크놀로지를 활용하여 정보를 수집, 해석, 활용, 창조할 수 있는 능력을 의미한다.

사회과는 학생들이 **시민으로서의 자질**을 함양할 수 있도록 사회현상에 관한 기초적 지식을 습득함은 물론, 지리, 역사, 제 사회과학의 기본 개념과 원리를 발견하고 탐구하는 능력을 익혀 우리 사회의 특징과 세계의 여러 모습을 종합적으로 이해하게 한다.

#### 세부 목표 (5)

(5) 인간과 사회현상을 파악하는 데 필요한 지식과 정보를 **획득**, **분석**, **조직**, **활용**하는 능력을 기르며, 공동체 생활과 관련된 여러 문제를 합리적으로 해결하기 위한 **탐구 능력**, **의사 결정 능력** 및 **사회 참여 능력**을 기른다.

### 내용 체계 · 핵심 아이디어

#### 지리 인식

장소는 다른 장소와 차별되는 자연적⋅인문적 성격을 지니며, 특정 장소에 따른 **장소감**은 개인이나 집단에 따라 다양하다.

지표 세계는 **장소적 성격의 동질성**, **기능적 상호 관련성**, **지역민의 인지** 등의 측면에서 다양하게 구분되며, 이렇게 구분된 지역은 고유한 **지역성**이 나타난다.

#### 자연환경과 인간생활

지표상에는 다양한 기후 특성이 나타나며, 기후 환경은 특정 지역의 **생활양식**에 중요하게 작용한다.

#### 지속가능한 세계

조화를 이루며 살아가려는 인간의 신념 및 활동은 지구환경의 **지속가능성**을 가능하게 한다.

#### 정치

다양한 정치 주체가 정치과정에 참여하며, 민주주의는 **여러 제도와 시민 참여**를 통해 실현된다.

#### 경제

가계와 기업은 **합리적 선택**을 통해 소비와 금융, 생산 등의 경제활동에 참여하면서 각자의 역할을 수행한다.

시장에서 가격은 **수요와 공급**을 통해 결정되고 다양한 요인으로 인해 변동한다.

#### 역사 일반

과거의 모습을 보여주는 자료는 **역사의 증거**로 활용된다.

#### 지역사

문화유산은 **과거와 현재를 이어주는** 자료이다.

지역의 박물관, 기념관, 유적지는 지역의 **정체성**을 보여준다.

### 성취기준

#### 3~4학년

##### 우리가 사는 곳

[4사01-01] 주변 여러 장소에서의 경험과 느낌을 다양한 방식으로 표현하고, 장소감을 나누며 서로 존중하는 태도를 지닌다.

- 성취기준 해설: 이 성취기준은 학생들의 생활이 이루어지는 주변 여러 장소에서의 경험과 느낌을 **글, 그림, 심상지도** 등의 다양한 방식으로 표현하고, 이를 통해 사람마다 장소감의 차이가 나타날 수 있음을 이해하도록 설정한 것이다.

- 성취기준 해설: **장소감**이란 장소에 대한 인지, 감정, 태도, 행동을 포괄하는 것으로 개인이나 집단이 장소에 부여하는 의미나 관심을 뜻한다.

- 적용 시 고려 사항 [4사01]: 우리가 사는 곳의 범위는 **생활권**을 기반으로 하되 여가, 쇼핑을 위한 이동 및 학생의 경험 등 일상생활이 이루어지는 공간 범위를 고려하여 탄력적으로 설정할 수 있다.

##### 일상에서 만나는 과거

[4사02-01] 일상 속에서 시간의 흐름을 경험할 수 있는 사례를 살펴보고, 이를 바탕으로 **역사의 시간 개념**을 이해한다.

[4사02-03] 지역의 변화상을 보여주는 역사 자료를 분석하여 지역 사람들의 달라진 생활 모습을 파악한다.

- 성취기준 해설: 이 성취기준은 지역 사람들의 달라진 생활 모습을 탐구하며 **역사의 변화와 지속**을 이해하도록 설정한 것이다.

- 적용 시 고려 사항: 나와 가족, 학교 등에서 일어난 중요한 일을 조사하여 시간의 흐름에 따라 배열하고 옛 기록이나 일기에서 시간 표현 용어를 찾아보는 등의 활동으로 역사의 시간 개념을 익힌다. 이러한 활동으로 **나와 가족의 삶도 역사의 일부임**을 자연스럽게 이해한다.

##### 사회 변화와 다양한 문화

[4사03-01] 최근 사회 변화의 양상과 특징을 파악하고, 그로 인해 나타난 생활모습의 변화를 탐색한다.

- 성취기준 해설: 이 성취기준은 사례를 통해 **저출산, 고령화, 지능정보화** 등 최근 사회 변화가 가져온 현상과 특징을 파악하고, 그로 인해 우리의 생활 모습이 어떻게 변화되는지 분석하도록 설정한 것이다.

##### 지도로 만나는 우리 지역

[4사05-01] 우리 지역을 표현한 다양한 종류의 지도를 찾아보고, 지도의 요소를 이해한다.

[4사05-02] 지도에서 우리 지역의 위치를 파악하고, 우리 지역의 **지리 정보**를 탐색한다.

- 성취기준 해설: 이 성취기준은 우리 지역을 표현한 다양한 종류의 지도를 탐색하고, 우리 지역의 지도를 활용하여 **방위, 기호와 범례, 축척, 높낮이 표현 방식** 등 지도 제작에 필요한 요소를 파악하도록 설정한 것이다.

- 적용 시 고려 사항 [4사05]: 지도의 요소 이해를 바탕으로 지도를 읽고 해석하는 활동에서 지도를 활용하는 능력을 평가할 수 있다. 이때, **축척 계산**, **방위 기입**, **기호 식별** 등과 같은 지필평가는 지양한다.

##### 경제활동과 지역 간 교류

[4사07-01] **자원의 희소성**으로 인해 경제활동에서 **선택의 문제**가 발생함을 이해하고, 경제활동에서 **합리적 선택**의 방법을 탐색한다.

[4사07-02] **생산**과 **소비** 활동을 파악하고, 인적⋅물적 교류의 사례를 통해 각 지역 및 사람들이 상호 의존 관계를 맺고 있음을 탐색한다.

##### 민주주의와 자치

[4사08-02] 지역에서 이루어지는 민주주의 사례를 통해 **주민 자치와 주민 참여**의 중요성을 파악하고, 지역사회의 문제 해결에 참여하는 태도를 기른다.

##### 다양한 환경과 삶의 모습

- 적용 시 고려 사항 [4사10]: 환경의 이용과 개발로 촌락이었던 곳에도 도시적 요소가 나타나는 도시화의 과정에 중점을 두어 지역 변화를 살펴본다. 이때, 촌락과 도시를 이분법적으로 구분하는 것을 지양하며 촌락과 도시에 고정 관념이나 편견을 갖거나, **환경 결정론적 인식이 발생하지 않도록** 주의한다.

#### 5~6학년

##### 우리나라 지리 탐구

[6사02-01] 우리나라의 계절별 기후 특징을 자료에서 탐구하고, 기후변화로 인한 자연재해의 심각성을 이해한다.

- 적용 시 고려 사항: 기온과 강수량을 나타낸 기후 그래프에서 우리나라의 계절별 기후 특징을 탐구하며, 최근의 기후변화 현황과 원인을 파악한다. 단, 초등학교에서는 **지역별 기후 특징**으로까지 학습 범위를 확대하지 않는다.

##### 법과 인권의 보장

[6사03-01] 일상 사례에서 법의 의미와 역할을 이해하고, 헌법에 규정된 인권이 일상생활에서 구현되는 사례를 조사하여 **인권 친화적 태도**를 기른다.

- 성취기준 해설: 이 성취기준은 우리 생활에 영향을 미치는 법의 의미와 역할을 일상 사례를 통해 이해하고, 헌법에 규정된 인권을 보장하는 다양한 사례를 조사하도록 설정한 것이다. 이를 통해 **준법 태도**와 **인권 의식**을 기르는 데 초점을 맞춘다.

- 적용 시 고려 사항 [6사03]: 헌법에 규정된 기본적 인권의 개념과 조항을 나열하지 않고 **자유**, **평등**, **정치 참여**, **사회 복지** 등 실제 생활에서 보장되는 인권의 사례들을 조사하여 인권 보장이 인간다운 삶을 위해 중요하다는 사실을 인식하도록 한다.

##### 세계의 자연환경

[6사10-01] 세계의 여러 지역의 **지형 경관**을 살펴보고, 이를 통해 다양한 삶의 모습을 이해한다.

##### 시장경제와 국가 간 거래

[6사11-01] 시장경제에서 가계와 기업의 역할을 이해하고, 근로자의 권리와 기업의 **자유 및 사회적 책임**을 탐색한다.

- 성취기준 해설: 이 성취기준은 시장경제의 특징에 대한 이해를 바탕으로 가계와 기업의 역할 및 상호 의존 관계를 파악하고, 근로자의 권리와 기업의 **자유로운 경제활동** 및 **사회적 책임**을 탐색하도록 설정한 것이다.

- 적용 시 고려 사항: 이에 기초해 공정한 시장과 지속가능한 발전을 위해서 근로자의 권리를 보호하고 기업이 자유로운 경제활동 및 사회적 책임(**ESG** 등)을 이행하는 것의 중요성을 인식하는 데 초점을 맞춘다.
