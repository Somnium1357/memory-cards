Ⅰ. 듣기 - 읽기 공통 내용

1. 이해 처리 과정

Bottom-Up : 상향식 이해 처리. 언어 기반 decoding 중심. form 위주. schema 사용 X
Top-down : 하향식 이해 처리. 전체적 이해 중심. meaning 위주. schema 사용
Interactive : 상·하향 모두 사용

2. 과정 중심 지도

전 (Pre)
어휘 지도 (상향식)

동기 부여, 목적 안내
중 (While)
이해에 도움을 주는 활동 (과다한 듣·읽기 X) ⇒ 읽기 shared reading
후 (Post)
이해 확인

Ⅱ. 듣기 지도의 특성

Information transfer : 들은 내용을 다른 형태(그림 고르기·순서 맞추기·표 채우기)로 옮기는 듣기 활동 (선택적 듣기 예시) (구멍 09-21 · 교재 기능별 언어 지도 p305 · 영어 연습문제 해설 p28)
Redundancy : 구어의 특성 — 반복·바꿔 말하기·덧붙이기로 듣는 이에게 처리할 시간을 줌 (e.g. "I mean", "you know") (구멍 10-03)

1. 교실 듣기의 유형

Reactive : 따라 말하기 위해 듣기 · 의미 이해 거의 필요 X (발음 연습)
Responsive : 교사 발화를 즉시 이해하고 적절히 반응
Selective : 긴 담화에서 필요한 특정 정보만 골라 듣기
Intensive : 특정 음소·단어·억양·담화 표지어 구별 (상향식)
Extensive : 긴 강의·이야기의 전체적 의미 파악 (하향식)
Interactive : 대화·토론·역할 놀이에 참여하며 위 유형 모두 · 말하기와 통합

Ⅲ. 읽기 지도의 특성

1. 읽기 단계

Literal comprehension (문자 그대로 내용 파악)
↓
Interpretive (추론·행간의 의미)
↓
Critical (비판적)
↓
Creative (감상·감정)

2. 읽기 유형

Intensive : 한 부분에 집중적 → 문법·구문구조 분석 등 (⊂ 수능 영어)
Extensive : 전체적인 이해 → 주로 흥미로 (⊂ 다독가)
Reading aloud : 실제성↓ (실제로 소리내지 못함), 학생들 주의가 발음으로 감
효과 : 소리와 철자의 관계를 알 수 있다. (구멍 09-21)
Silent reading : 어려움. 실제적
