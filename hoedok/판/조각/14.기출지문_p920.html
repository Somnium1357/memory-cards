5.도덕 - 도덕 심리학적 기초

반두라(밴듀라) (2018 B 도덕 4번)
사회 학습 이론 : 도덕적 행동 학습·도덕성 발달은 관찰·모방·동일시로 이루어짐
모방 : 특정 행동·동작의 재생
동일시 : 모델의 가치·이상·양심 수용
강화·벌 없이도 모범 행동 관찰·모방으로 학습 : 관찰학습
직접 강화 : 필수 요소 X
대리 강화 : 모델이 강화받는 것을 보고 같은 행동 (e.g. 칠판 청소 도운 친구가 칭찬받음)
자기 강화 : 스스로 수행 기준 세우고 자기 수행에 보상·비판
관찰학습 네 과정
주의 : 모델 행동을 주의 깊게 살펴봄
파지 : 시각적·언어적·범주화로 기억에 저장
운동 재생 : 모델 행동을 실제로 수행
동기화 : 결과를 긍정적으로 인식하면 실행
인지적 매개 : 모델이 주는 의미를 인지적으로 파악·수용할 때 학습↑
잘 모방되는 경우 : 같은 성의 모델 · 모델이 보상받음 · 매력적이고 존경받는 모델
