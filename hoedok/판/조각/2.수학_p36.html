수와 연산 - 소수의 사칙연산

1. 소수의 덧셈과 뺄셈

1) 계산 원리

⇒단위소수의 개수로 바꾼 뒤 분배법칙의 역

2) 알고리즘

세로셈
⇒소수점끼리 맞추어 세로로 → 같은 자리끼리 더하기·빼기 → 결과에 소수점 그대로 내려 찍기

3) 보충 지도

받아내림 이해 X ⇒ 수직선으로 지도 (≒ 자연수)

4) 오류

덧셈 : 오른쪽 끝을 맞추어 계산 ⇒ 오른쪽 끝자리에 0 붙이고 자릿수 맞추어 계산
뺄셈 : 빼야 할 수를 그대로 내려 씀 ⇒ 오른쪽 끝자리에 0 붙이고 자릿수 맞추어 계산

2. 소수의 곱셈

1) 계산 원리

⇒분모가 10의 거듭제곱인 분수의 곱셈으로 표현하여 지도
e.g. 0.7 (7×1/10) × 0.5 (5×1/10) = 7/10 × 5/10 = (7×5)/(10×10) = 35/100 = 0.35
① 7×5의 1/100배가 됨
② 피승수·승수가 각각 1/10배 ⇒ 결과가 1/100
→ 이 사실 이해하도록 지도

2) 알고리즘

⇒소수점 무시하고 자연수 곱셈 계산 → 승수·피승수 소수점 아래 자리의 수의 합만큼 곱한 결과의 소수점 왼쪽으로 옮겨 찍기

3. 제수가 자연수인 소수의 나눗셈

1) 계산 원리

⇒분모가 10의 거듭제곱인 분수의 나눗셈으로 표현하여 지도 ; 분자가 나누어떨어지지 않을 때도 분모가 10ⁿ인 동치분수로 바꾸어야 다시 소수 변환이 편리
e.g. 4.2 (42×1/10) ÷ 6 = 42/10 ÷ 6 = (42÷6)/10 = 7/10 = 0.7
①피제수가 1/10배 ⇒ 몫도 1/10배

2) 알고리즘

⇒자연수 나눗셈처럼 소수로 계산
나누어떨어지지 X - 피제수에 0 붙여 계산
몫의 소수점 - 피제수의 자연수부 바로 뒤에서 옮겨 적음
몫의 자연수부가 비어 있음 - 일의 자리에 0 쓰기

3) (자연수) ÷ (자연수) - 수 모형

e.g. 3 ÷ 4 = (2.8 + 0.2) ÷ 4 = 0.7 + 0.05 = 0.75
⇒지도 : 3 = 백 모형 3개 → 4로 나눌 수 X, 십 모형 30개(백 모형이 모두 분해 ⇒ 일의 자리가 0) → 4로 나누면 7 … 2 → 낱개 모형 20개 → 4로 나누면 5개

4. 제수가 소수인 소수의 나눗셈

1) 계산 원리

⇒분수의 나눗셈으로 지도
e.g. 8.24 ÷ 4.12 = 824/100 ÷ 412/100 = 824 (8.24×100) ÷ 412 (4.12×100) = 2
⇒제수와 피제수를 똑같이 100배 하면 몫도 같음 (cf. 제수 자연수에서 알 수 있는 사실)

2) 알고리즘

⇒제수·피제수 소수점을 같은 자리만큼 옮김 → 몫의 소수점은 옮긴 소수점 위치에 맞춤
